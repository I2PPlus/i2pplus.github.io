    package org.klomp.snark.web

    The I2PSnark web interface (i2psnark.war): servlets and helpers for torrent management, file browsing and configuration.

    • Related Packages
      org.klomp.snark
      I2P version of the Snark BitTorrent client, enhanced for I2P: peers are I2P destinations, torrents can be served anonymously as hidden services, and metadata carries I2P-specific comment fields.
      org.klomp.snark.bencode
      Bencode parsing and serialization, the canonical BitTorrent encoding used for torrent files and peer messages.
      org.klomp.snark.comments
      Parsing and formatting of the I2P comment metadata stored in the comment field of torrent files, carrying the I2P destination and other per-torrent data.
      org.klomp.snark.dht
      BitTorrent distributed hash table (DHT) implementation following the Mainline protocol, for trackerless peer discovery.
      org.klomp.snark.standalone
      Command-line client for running Snark without the web interface.
