    org.klomp.snark.web.BridgeVersion
    public final class BridgeVersionextends Object
    Version helpers for the I2PSnark Bridge extension: reads the version from the manifest.json inside the bundled XPI, and compares dotted extension versions numerically so the router can tell whether the installed extension is current.

        public static int compare(String a, String b)
        Compares two dotted version strings numerically by segment; missing or non-numeric segments count as 0. "0.1.1" > "0.1.0", "0.1.10" > "0.1.9", "1.0" > "0.9.99".
        Parameters:

        Returns:
        negative if a is older, zero if equal, positive if a is newer
