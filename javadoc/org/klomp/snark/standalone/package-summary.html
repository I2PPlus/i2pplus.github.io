Package org.klomp.snark.standalone Description

Classes exclusively used in standalone I2PSnark installations, providing functionality not needed when running within the I2P router environment.

This package includes:

  • Standalone launcher and initialization
  • Configuration management for standalone mode
  • Router integration for standalone usage
  • Independent service management

Since 0.9.27.
