Class RunStandalone

  • java.lang.Object
    • org.klomp.snark.standalone.RunStandalone

  • public class RunStandalone
extends Object
    Standalone runner for I2PSnark.

    Launches an embedded Jetty server hosting the I2PSnark web interface independently of the main I2P router. Reads configuration from jetty-i2psnark.xml and i2psnark-appctx.config, parses host/port from the Jetty XML config, and optionally opens the system browser.
