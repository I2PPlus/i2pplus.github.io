Class PeerAcceptor

  1. org.klomp.snark
  2. PeerAcceptor
Search page
    java.lang.Object
    org.klomp.snark.PeerAcceptor
    class PeerAcceptorextends Object
    Accepts incoming connections from peers. The ConnectionAcceptor will call the connection(I2PSocket, InputStream, OutputStream) method when it detects an incoming BT protocol connection. The PeerAcceptor will then create a new peer if the PeerCoordinator wants more peers.

      • readHash

        private static byte[] readHash(InputStream in) throws IOException
        Read ahead to the infohash, throwing an exception if there isn't enough data. Also check the first 20 bytes for the correct protocol here and throw IOE if bad, so we don't hang waiting for 48 bytes if it's not a bittorrent client. The 20 bytes are checked again in Peer.handshake().
        Parameters:
        in - the stream to read the handshake prefix from
        Returns:
        the 20-byte infohash following the protocol header
        Throws:
        IOException - if the leading bytes are not the bittorrent protocol string, or the hash cannot be fully read
