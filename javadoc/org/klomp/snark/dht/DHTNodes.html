org.klomp.snark.dht

Class DHTNodes

  • java.lang.Object
    • org.klomp.snark.dht.DHTNodes

  • class DHTNodes
extends Object
    All the nodes we know about, stored as a mapping from node ID to a Destination and Port.

    And a real Kademlia routing table, which stores node IDs only.
