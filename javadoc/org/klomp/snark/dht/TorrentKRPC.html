Class TorrentKRPC

  • java.lang.Object
    • org.klomp.snark.dht.KRPC
      • org.klomp.snark.dht.TorrentKRPC
  • All Implemented Interfaces:
    I2PSessionListener, I2PSessionMuxedListener, DHT

    public class TorrentKRPC
extends KRPC
    A DHT instance for a single torrent, running on its own transient I2P session and destination. Shares the main instance's routing table, tracker, and blacklist, but generates its own NID, query ports, and token maps, so that tokens issued for one destination can never authorize an announce from another, which would make remote nodes store the wrong peer hash for a torrent.
