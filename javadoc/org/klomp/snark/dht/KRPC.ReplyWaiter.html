      • ReplyWaiter

        public ReplyWaiter(MsgID mID, NodeInfo nInfo, Runnable onReply, Runnable onTimeout)
        Either wait on this object with a timeout, or use non-null Runnables. Any sent data to be remembered may be stored by setSentObject(Object). Reply object may be in getReplyObject().
        Parameters:
        mID - the message ID of the query being awaited
        nInfo - the node the query was sent to, and whose reply is credited
        onReply - must be fast, otherwise set to null and wait on this UNUSED
        onTimeout - must be fast, otherwise set to null and wait on this UNUSED
