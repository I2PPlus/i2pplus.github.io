      • UpdateRunner

        public UpdateRunner(I2PAppContext ctx, UpdateManager umgr, SnarkManager smgr, UpdateType type, List<URI> uris, String newVersion)
        Update runner.
        Parameters:
        ctx - the application context, whose log manager supplies the log
        umgr - the update manager, told when the download completes or fails
        smgr - the SnarkManager, which installs and starts the downloaded torrents
        type - the update category to fetch, e.g. NEWS or PLUGIN
        uris - the mirrors to try in turn when none are configured
        newVersion - the version string the downloaded file must report
