        public ReplyWaiter(int tid, UDPTrackerClient.Tracker tracker, int action, byte[] payload, long toWait)
        Either wait on this object with a timeout, or use non-null Runnables. Any sent data to be remembered may be stored by setSentObject(). Reply object may be in getReplyObject().
        Parameters:
        tid - the transaction id of the request
        tracker - the tracker being queried
        action - the tracker action number
        payload - the request bytes to send
        toWait - the time to wait for the reply, in ms
