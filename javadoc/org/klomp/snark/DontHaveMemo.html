org.klomp.snark

Class DontHaveMemo

  • java.lang.Object
    • org.klomp.snark.DontHaveMemo

  • class DontHaveMemo
extends Object
    Tracks the pieces a peer said it no longer has (BEP 54 dont_have), so the piece is not re-requested from that peer even if it re-announces HAVE, until the remembered state expires.

    The peer's HAVE bitfield is already cleared on dont_have; this additionally suppresses requests once the peer re-sets the bit, avoiding a request/dont_have ping-pong with peers that flap or purge pieces transiently.
