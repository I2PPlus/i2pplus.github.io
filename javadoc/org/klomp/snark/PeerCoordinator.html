Class PeerCoordinator

  • java.lang.Object
    • org.klomp.snark.PeerCoordinator
  • All Implemented Interfaces:
    BandwidthListener, PeerListener

    class PeerCoordinator
extends Object
implements PeerListener, BandwidthListener
    Coordinates peer activities for a single torrent including upload/download management, peer selection, piece distribution, and bandwidth allocation.

    This class manages the core BitTorrent coordination logic:

    • Managing connected peers and their states
    • Choking/unchoking logic for upload slots
    • Piece selection and rarest-first distribution
    • Request queue management and pipeline control
    • Bandwidth distribution among peers
    • Peer Exchange (PEX) for peer discovery
    • DHT integration for trackerless operation
    • Tracker announcements and response processing

    Thread safety: This class uses extensive synchronization for thread-safe peer management. External access to some fields is documented where permitted.

    See Also:
    Peer, PeerState, Storage
