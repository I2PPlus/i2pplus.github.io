    Represents a response from a UDP tracker.
    This class encapsulates the tracker's response including peer lists, interval information, and any error messages.

        public TrackerResponse(int interval, int seeds, int leeches, Set<Hash> peers)
        Builds a successful response from the tracker's swarm statistics.
        Parameters:
        interval - seconds the tracker asks us to wait before the next announce
        seeds - number of complete peers the tracker reports in the swarm
        leeches - number of incomplete peers the tracker reports in the swarm
        peers - the peer hashes returned by the tracker
