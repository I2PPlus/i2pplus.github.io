    java.lang.Object
    org.klomp.snark.MetaInfo
    public class MetaInfoextends Object
    Holds all information extracted from a torrent file.

    This class parses and stores the metadata from .torrent files, including:

    • Tracker announce URLs
    • Info hash for torrent identification
    • File names, sizes, and structure
    • Piece length and piece hashes for integrity verification

    Note: This class has a known limitation where it doesn't propagate custom meta fields into the bencoded info data, and from there to the info_hash. However, it currently works with torrents created by I2P-BT, I2PRufus and Azureus.

      • isRangePadding

        public boolean isRangePadding(long offset, int length)
        True if every byte in the given range lies within BEP 47 padding files.

        Padding bytes are all zeros and are never stored on disk, so chunks or pieces entirely within padding need not be requested from peers (BEP 47).

        Parameters:
        offset - global byte offset into the torrent
        length - number of bytes
        Returns:
        true if the whole range is covered by padding files
