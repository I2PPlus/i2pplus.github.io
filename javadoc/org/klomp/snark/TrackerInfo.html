    java.lang.Object
    org.klomp.snark.TrackerInfo
    class TrackerInfoextends Object
    The data structure for the tracker response. Handles both traditional and compact formats.

    Compact format 1 - a list of hashes - early format for testing. Compact format 2 - One big string of concatenated hashes - official format.

      • getPeers

        private static Set<Peer> getPeers(byte[] l, byte[] my_id, byte[] infohash, MetaInfo metainfo, I2PSnarkUtil util) throws IOException
        One big string of concatenated 32-byte hashes.
        Parameters:
        l - concatenated 32-byte peer hashes, a trailing partial hash being ignored
        my_id - our peer id from the tracker, used by each Peer for its handshake
        infohash - the 20-byte torrent info hash carried by each Peer
        metainfo - the torrent metadata carried by each Peer
        util - supplies the crypto used to decrypt peer ids
        Returns:
        a peer for each whole 32-byte hash in the array, skipping any that fail to parse as a peer ID; a trailing partial hash is ignored
        Throws:
        IOException - declared on the method; every parse failure is caught and skipped
