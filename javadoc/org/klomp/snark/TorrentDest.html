org.klomp.snark

Class TorrentDest

  • java.lang.Object
    • org.klomp.snark.TorrentDest

  • public class TorrentDest
extends Object
    Bundles the transient I2P destination, session, server socket, DHT instance, and UDP tracker client for one torrent, so that all of a torrent's network activity goes out through its own identity. Created lazily when a torrent starts and destroyed when it stops. Not persisted; a new destination is generated on each start.
