      • sendExtension

        private static void sendExtension(Peer peer, String type, byte[] payload)
        Send an extension message to a peer, looking up its message code for the given type in the handshake. Silently ignores peers that did not advertise the extension.
        Parameters:
        peer - the peer to send to
        type - the extension type name (TYPE_* constant)
        payload - the bencoded message payload

      • getHandshake

        public static byte[] getHandshake(int metasize, boolean pexAndMetadata, boolean dht, boolean uploadOnly, boolean comment, String clientName)
        Creates a bencoded extension handshake message.
        Parameters:
        metasize - the metadata size in bytes, or -1 if unknown
        pexAndMetadata - true to advertise PEX and metadata extensions
        dht - true to advertise DHT capability
        uploadOnly - true to advertise upload-only mode (BEP 21)
        comment - true to advertise ut_comment extension
        clientName - the "v" value, or null for the default "I2PSnark"
        Returns:
        bencoded outgoing handshake message

      • sendDontHave

        public static void sendDontHave(Peer peer, int piece)
        Send a BEP 54 lt_donthave message to a peer that advertised support: the piece is no longer available. The payload is the raw 4-byte piece index.
        Parameters:
        peer - the peer to send to
        piece - the piece index
