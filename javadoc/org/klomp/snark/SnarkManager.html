    public class SnarkManagerextends Object implements CompleteListener, ClientApp, I2PSocketManager.DisconnectListener
    Central manager for multiple torrent downloads and the I2PSnark application.

    This class is the core controller that manages:

    • Multiple torrent instances (Snarks) and their lifecycle
    • Configuration management and persistence
    • Peer coordination and bandwidth management
    • Tracker communication and DHT integration
    • Web interface and user interaction
    • Torrent file monitoring and auto-loading
    • Magnet link handling
    • Comments and metadata management

    As a ClientApp, it integrates with the I2P router application framework and can be started, stopped, and monitored through the standard I2P interfaces.

        public String lookupTorrentName(byte[] infoHash, long timeoutMs)
        Self-contained DHT lookup for torrent name without persisting torrent data. Does not store the .torrent file in the snark data directory and does not persist magnet status.         Parameters:

        timeoutMs - max time to wait for metadata (e.g. 60_000 for 1 min, 3_600_000 for 60 min)
        Returns:
        torrent name (MetaInfo.getName()) or null if not found/timeout/interrupted
