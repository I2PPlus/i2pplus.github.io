    Closeable, AutoCloseable
    public class Storageextends Object implements Closeable
    Storage manages torrent data files on disk for I2PSnark.

    This class handles all aspects of storing and retrieving torrent pieces:

    • Creating and managing files/directories for torrent data
    • Reading and writing piece data to disk
    • Tracking downloaded pieces via BitField
    • Validating downloaded pieces against piece hashes
    • File pre-allocation for sparse file support
    • Priority-based file selection for partial downloads
    • File checking and rechecking for data integrity

    Storage implements Closeable and should be properly closed after use. The storage must be checked via check() before reading or writing pieces.

    Thread safety: This class uses synchronized methods and concurrent collections for thread-safe access to file handles and metadata.

      • getFileNames

        public List<String> getFileNames()
        The torrent-relative paths of every file in the torrent, index-aligned with the arrays returned by remaining2().

        BEP 47 padding files are included, as the synthetic name (a number, optionally "-n", under the .pad directory) the metainfo gives them, so that element i of this list describes the same file as element i of the remaining/preview arrays. Callers that must skip padding entries test the name for the .pad directory prefix, or use indexOf(File) and the metainfo attribute list.

        Returns:
        a new list with one entry per torrent file, never null
