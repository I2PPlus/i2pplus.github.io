org.klomp.snark

Class MagnetState

  • java.lang.Object
    • org.klomp.snark.MagnetState

  • class MagnetState
extends Object
    Simple state for the download of the metainfo, shared between Peer and ExtensionHandler.

    Nothing is synchronized here! Caller must synchronize on this for everything!

    Reference: BEP 9
