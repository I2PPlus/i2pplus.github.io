    java.lang.Object
    org.klomp.snark.MagnetState
    class MagnetStateextends Object
    Simple state for the download of the metainfo, shared between Peer and ExtensionHandler.

    Nothing is synchronized here! Caller must synchronize on this for everything!

    Reference: BEP 9

      • saveChunk

        public boolean saveChunk(int chunk, byte[] data, int off, int length) throws Throwable
        Save a chunk of data to the magnet state.
        Parameters:
        chunk - the chunk number to save
        data - the byte array containing the chunk data
        off - the offset in the data array where the chunk starts
        length - the byte count to copy, which must equal the chunk size in a complete file
        Returns:
        true if this was the last piece, false otherwise
        Throws:
        IllegalArgumentException - if not initialized, chunk number is invalid, or length is incorrect
        Exception - if there's an error building the MetaInfo
        StackOverflowError - if the received metadata nests lists or maps deeply enough to exhaust the decoder's recursion
