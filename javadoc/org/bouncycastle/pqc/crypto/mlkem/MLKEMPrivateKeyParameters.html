      • MLKEMPrivateKeyParameters

        public MLKEMPrivateKeyParameters(MLKEMParameters params, byte[] s, byte[] hpk, byte[] nonce, byte[] t, byte[] rho)
        Builds a private key from its already separated components.
        Parameters:
        params - the ML-KEM parameter set this key belongs to
        s - the secret vector
        hpk - the hash of the corresponding public key
        nonce - the 32-byte nonce carried alongside the key material
        t - the public key t component
        rho - the public key rho component

      • MLKEMPrivateKeyParameters

        public MLKEMPrivateKeyParameters(MLKEMParameters params, byte[] s, byte[] hpk, byte[] nonce, byte[] t, byte[] rho, byte[] seed)
        Builds a private key from its components and regeneration seed.
        Parameters:
        params - the ML-KEM parameter set this key belongs to
        s - the secret vector
        hpk - the hash of the corresponding public key
        nonce - the 32-byte nonce carried alongside the key material
        t - the public key t component
        rho - the public key rho component
        seed - the optional seed permitting deterministic regeneration of the key, or null when the key was not generated from one
