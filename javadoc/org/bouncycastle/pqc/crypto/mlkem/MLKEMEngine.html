    org.bouncycastle.pqc.crypto.mlkem.MLKEMEngine
    class MLKEMEngineextends Object
    Core engine for ML-KEM (Module-Lattice Key Encapsulation Mechanism) operations. Implements the cryptographic primitives for key generation, encapsulation, and decapsulation.
