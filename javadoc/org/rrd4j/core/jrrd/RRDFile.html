    Constants
    class RRDFileextends Object implements Constants
    This class is used read information from an RRD file. Writing to RRD files is not currently supported. It uses NIO's RandomAccessFile to read the file

    Currently this can read RRD files that were generated on Solaris (Sparc) and Linux (x86).
