    RrdFileBackend
    public class RrdNioBackendextends ByteBufferBackend implements RrdFileBackend
    Backend which is used to store RRD data to ordinary disk files using java.nio.* package. This is the default backend engine.

    This version buffers all stat files in a single temporary buffer file sequentially, keeping track of each file's offset and length, then flushes all to the mapped file in batch.
