    public class Datasourceextends Object implements RrdUpdater<Datasource>
    Class to represent single datasource within RRD. Each datasource object holds the following information: datasource definition (once set, never changed) and datasource state variables (changed whenever RRD gets updated).

    Normally, you don't need to manipulate Datasource objects directly, it's up to Rrd4j framework to do it for you.

    • Constructor Details

      • Datasource

        Datasource(RrdDb parentDb, DsDef dsDef) throws IOException
        Binds this datasource's storage slots in the RRD and, when a definition is supplied, fills them with it. Passing a null definition leaves every slot holding the zero value, which is how a datasource is opened for reading from an existing file; the other constructor then copies the stored values in.
        Parameters:
        parentDb - the RRD this datasource belongs to, whose backend allocates the storage
        dsDef - definition to initialize the slots from, or null to leave them unset
        Throws:
        IOException - if the storage cannot be allocated or written

      • Datasource

        Datasource(RrdDb parentDb, DataImporter reader, int dsIndex) throws IOException
        Loads an existing datasource from another RRD, copying the definition and the state variables (last value, accumulated value and NaN seconds) from the indexed datasource of the importer.
        Parameters:
        parentDb - the RRD this datasource belongs to, whose backend allocates the storage
        reader - the RRD to copy the datasource from
        dsIndex - position of the datasource to copy within the reader's datasource list
        Throws:
        IOException - if the source datasource cannot be read or the storage written

      • process

        final void process(long newTime, double newValue) throws IOException
        Feeds one sample into the current primary data point, accumulating the rate over the interval since the last sample. Once the sample crosses a step boundary the interval is closed out and written to this datasource's archive, after which accumulation restarts at the boundary.
        Parameters:
        newTime - sample time in seconds since the epoch
        newValue - sample value; samples further apart than the heartbeat are ignored, as are rates that fall outside the configured min/max
        Throws:
        IOException - if the datasource state cannot be read, updated or archived

      • appendXml

        void appendXml(XmlWriter writer) throws IOException
        Writes the datasource as a <ds> element of the XML dump, including the definition fields and the PDP status fields holding the last, accumulated and unknown-second counts. An unknown last value is written as UNKN.
        Parameters:
        writer - the XML writer positioned at the point the ds element starts
        Throws:
        IOException - if a datasource value cannot be read from storage
