    Logging hook for the vendored rrd4j tree.

    This library is built standalone (see apps/jrobin/java/build.xml, which compiles with no classpath), so it cannot reference I2P's LogManager directly. Instead the embedder installs a delegate at startup and the library routes its diagnostics through it. With no delegate installed every call is a no-op, which is the correct default for standalone use.

    Added because rrd4j runs scheduled work whose failure mode is invisible: ScheduledExecutorService.scheduleWithFixedDelay(Runnable, long, long, TimeUnit) cancels all future executions when the task throws, so a single failed flush silently ends all later ones. Without a log line there is no way to tell that from "nothing to write".
