Class ByteBufferBackend

  • java.lang.Object
    • org.rrd4j.core.RrdBackend

  • Direct Known Subclasses:
    RrdByteArrayBackend, RrdMemoryBackend, RrdNioBackend

    public abstract class ByteBufferBackend
extends RrdBackend
    A backend that store and provides access to data using a ByteBuffer, using java internal methods for long, integer and others types.
