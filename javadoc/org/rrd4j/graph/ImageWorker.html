org.rrd4j.graph

Class ImageWorker

  • java.lang.Object
    • org.rrd4j.graph.ImageWorker
  • Direct Known Subclasses:
    BufferedImageWorker, SVGImageWorker

    public abstract class ImageWorker
extends Object
    Abstract base class for image workers in RRD graphs. Provides drawing operations for creating graph images with various output formats. Tracks last paint/stroke/font to avoid redundant state changes that produce duplicate inline styles in SVG output. Default constructor.
