    org.rrd4j.graph.CDef
    class CDefextends Source
    Represents a computed data source (CDEF) in RRD graphs. A CDEF evaluates a Reverse Polish Notation (RPN) expression to compute values from other data sources. Enables mathematical operations and data transformations within the graphing system.
