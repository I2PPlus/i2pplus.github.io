      • countPlottedSeries

        static int countPlottedSeries(List<PlotElement> plotElements)
        Counts the independently plotted series in a graph, which decides whether the lines are drawn solid or dotted.

        Counts Line and Area together. An area counts because it is drawn with an outline, so a graph made of a filled total plus a subset line has two lines on it and the subset must be dotted to match. Stack stays excluded: a stack is one quantity split into bands, not several series.

        Parameters:
        plotElements - the graph's plot elements, may be null
        Returns:
        number of plotted series, zero for an empty or null list

      • valueShadePaint

        private Paint valueShadePaint(Color[] stops)
        Build the vertical gradient that shades a series line by its value.

        The gradient runs from the bottom of the plot area to the top, which is what makes it read by value rather than by position: a point's height above the baseline is its magnitude, so the paint at that height is the colour for that magnitude. Three or more stops need LinearGradientPaint, the only one of the two gradient types that holds an arbitrary number; either way the stops are spread evenly over the span.

        Parameters:
        stops - bottom-to-top colour stops, or null for a flat line
        Returns:
        the gradient paint, or null when no shading was asked for

      • xtrDistinct

        private double[] xtrDistinct(long[] timestamps)
        Converts timestamps to pixel x with one point per sample.

        xtr(long[]) deliberately writes each sample's x twice so that the polyline is forced into a staircase: a horizontal run to each sample, then a vertical jump to the next. That is what gives the plots their stepped look, but it also means every value change lands on a zero-width edge, leaving no horizontal room for a curve to cross. The smoothed renderer needs the undoubled positions so a transition spans the pixels between samples.

        Parameters:
        timestamps - sample timestamps, one per data point and not pre-doubled
        Returns:
        one pixel x per timestamp

      • ytrDistinct

        private double[] ytrDistinct(double[] values)
        Converts values to pixel y with one point per sample.

        The undoubled counterpart of ytr(double[]); see xtrDistinct(long[]) for why the doubled form exists and why the smoothed renderer must not use it. Gaps stay NaN so PathIterator still splits the series where the data does.

        Parameters:
        values - sample values, possibly containing NaN
        Returns:
        one pixel y per value
