    DNS RRSIG (Resource Record Signature) record payload for DNSSEC.
    Contains cryptographic signature covering a set of DNS records to provide authenticity and integrity verification.

        public RRSIG(Record.TYPE typeCovered, int algorithm, byte labels, long originalTtl, Date signatureExpiration, Date signatureInception, int keyTag, DnsName signerName, byte[] signature)
        Create an RRSIG payload.
        Parameters:
        typeCovered - the RR type of the RRset this signature covers.
        algorithm - the DNSSEC signing algorithm number of RFC 4034.
        labels - the number of labels of the owner name of the covered RRset, the wildcard label of a wildcard RRset not counted.
        originalTtl - the TTL in seconds of the covered RRset in the signed zone.
        signatureExpiration - the time from which on the signature expires.
        signatureInception - the time from which on the signature is valid.
        keyTag - the key tag of the DNSKEY which must validate this signature.
        signerName - the owner name of the DNSKEY RRset holding the signing key.
        signature - the signature over the RRSIG RDATA without the signature field and over the covered RRset.
