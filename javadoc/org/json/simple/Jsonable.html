Interface Jsonable

  • All Known Implementing Classes:
    JsonArray, JsonObject

    public interface Jsonable
    Jsonables can be serialized in java script object notation (JSON). Deserializing a String produced by a Jsonable should represent the Jsonable in JSON form.
