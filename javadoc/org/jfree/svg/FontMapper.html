Interface FontMapper

  • All Known Implementing Classes:
    StandardFontMapper

    public interface FontMapper
    An object that can (optionally) translate one font family name to an alternative. A FontMapper is assigned to an SVGGraphics2D instance. The default implementation will map Java logical font names to the equivalent SVG generic font names.
