Package org.jfree.svg.util Description

Utility classes used by the JFreeSVG core library. These provide argument validation, shape copying, gradient paint deduplication keys, and fast double-to-string conversion.

Key Components

  • Args - Argument validation (null checks, array length checks)
  • GraphicsUtils - Shape copying and image conversion utilities
  • GradientPaintKey - HashMap key for java.awt.GradientPaint
  • LinearGradientPaintKey - HashMap key for java.awt.LinearGradientPaint
  • RadialGradientPaintKey - HashMap key for java.awt.RadialGradientPaint
  • RyuDouble - Ryu algorithm for fast double-to-string conversion

Related Packages

  • org.jfree.svg - Core JFreeSVG SVG generation classes
