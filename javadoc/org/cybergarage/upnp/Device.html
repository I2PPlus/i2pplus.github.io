    HTTPRequestListener, SearchListener
    public class Deviceextends Object implements HTTPRequestListener, SearchListener
    Represents a UPnP device in the CyberLink framework.

    This class provides the core functionality for UPnP devices, including:

    • Device description and advertisement via SSDP
    • HTTP server functionality for handling requests
    • Service management and action invocation
    • Event notification and subscription handling
    • Hierarchical device relationships (root/embedded devices)

    A Device can be either a root device or an embedded device within another device. Each device contains services that provide specific functionality through actions and state variables.

    Key features:

    • Automatic device discovery and announcement
    • SOAP-based control message handling
    • GENA-based event notification
    • Multi-homed network interface support
    • NMPR (Network Media Profile Requirements) compliance
