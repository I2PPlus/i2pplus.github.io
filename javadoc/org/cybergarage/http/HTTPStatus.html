org.cybergarage.http

Class HTTPStatus

  • java.lang.Object
    • org.cybergarage.http.HTTPStatus

  • public class HTTPStatus
extends Object
    Represents an HTTP status line with version, status code, and reason phrase. This class provides methods to parse and manipulate HTTP status responses, including common status code constants and utility methods.

        public static final String code2String(int code)
        Converts an HTTP status code to its corresponding reason phrase string.

        This method provides the standard HTTP reason phrases for common status codes. If the status code is not recognized, an empty string is returned.

        Parameters:
        code - the HTTP status code to convert
        Returns:
        the corresponding reason phrase, or empty string if code is not recognized
