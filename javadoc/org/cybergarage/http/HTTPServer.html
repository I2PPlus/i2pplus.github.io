Class HTTPServer

    public class HTTPServer
extends Object
implements Runnable
    HTTP server implementation for the CyberLink HTTP framework.

    This class provides a multithreaded HTTP server that can:

    • Accept incoming HTTP connections
    • Dispatch requests to registered listeners
    • Handle multiple concurrent connections
    • Support both IPv4 and IPv6 addresses

    The server must be initialized using open(InetAddress, int) or open(String, int) before starting. Optionally, HTTPRequestListener instances can be registered to handle incoming requests.
