org.cybergarage.http

Class HTTPHeader

  • java.lang.Object
    • org.cybergarage.http.HTTPHeader

  • public class HTTPHeader
extends Object
    Represents an HTTP header field with a name and value. This class provides methods to parse, manipulate, and extract HTTP headers from various data sources including strings, byte arrays, and readers.
