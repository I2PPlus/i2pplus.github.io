      • ngettext

        public static String ngettext(ResourceBundle catalog, String msgid, String msgid_plural, long n)
        Returns the plural form for n of the translation of msgid.
        Parameters:
        catalog - the ResourceBundle holding the translated message catalogs
        msgid - the key string to be translated, an ASCII string
        msgid_plural - its English plural form
        n - the item count that selects the singular or the plural form
        Returns:
        the translation of msgid depending on n, or msgid or msgid_plural if none is found
