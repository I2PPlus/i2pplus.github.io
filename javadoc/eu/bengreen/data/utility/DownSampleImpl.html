      • downsizeImpl

        protected abstract DownSampler.DataSet downsizeImpl(DownSampler.DataSet sampled, long[] timestamps, double[] values)
        Reduces the source series into the pre-allocated output set. Implementations pick the ranks to keep, write them one slot at a time with setDataSetLine(DownSampler.DataSet, int, long, double), and return that same set; downsize(long[], double[]) has already rejected inputs shorter than the output and mismatched array lengths.
        Parameters:
        sampled - the empty output set allocated by downsize(long[], double[]), holding exactly threshold timestamp and value slots to fill
        timestamps - the full source timestamps in seconds since the epoch, more than threshold in number
        values - the full source values, the same length as timestamps
        Returns:
        the same sampled set, with the threshold chosen ranks written into it
