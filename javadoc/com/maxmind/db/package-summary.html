    package com.maxmind.db

    Reads MaxMind GeoLite2 database files, the format used by the router for GeoIP lookups.

    From MaxMind-DB-Reader-java 1.2.2 (2017-02-17), heavily modified to drop the com.fasterxml.jackson.databind dependency and return POJOs instead.
