Package com.maxmind.geoip

  1. com.maxmind.geoip
Search page
    package com.maxmind.geoip

    Legacy GeoIP country and city lookups from the geoip-database files in /usr/share/GeoIP/, used only on Debian-based systems where that package is installed. See GeoIP.

    From geoip-api-java 1.3.1 (2016-02-08), unmodified except that regionName.java and timeZone.java are omitted.
