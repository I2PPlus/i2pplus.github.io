    This object renders a QR Code as a BitMatrix 2D array of greyscale values.

    Encodes text content into a QR Code barcode using the ZXing library's encoder, supporting various error correction levels and encoding hint types.

        private static BitMatrix renderResult(QRCode code, int width, int height, int quietZone)
        Renders the QR code as a bit matrix, padding with the quiet zone. Note that the input matrix uses 0 == white, 1 == black, while the output matrix uses 0 == black, 255 == white (i.e. an 8 bit greyscale bitmap).
        Parameters:
        code - the QR code to render
        width - the requested width, in modules
        height - the requested height, in modules
        quietZone - the quiet zone width, in modules

        the rendered bit matrix
