Package i2p.susi.dns

  1. i2p.susi.dns
Search page
    package i2p.susi.dns

    The SusiDNS webapp, which is the user interface for the addressbook application and the local naming service (hosts database) implemented in net.i2p.client.naming. This is the webapp named 'addressbook' in the console.

    SusiDNS provides:

    • Managing local address book entries
    • Subscribing to remote address books for automatic updates
    • Import and export of address book data
    • Configuring naming service preferences

    See also: RFC 3490 (IDNA).
