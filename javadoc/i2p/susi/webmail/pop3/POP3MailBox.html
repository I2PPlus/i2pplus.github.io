    NewMailListener
    public class POP3MailBoxextends Object implements NewMailListener
    POP3 client for retrieving email from POP3 servers over I2P. Supports standard POP3 commands, background checking, and delayed deletion. Optimized for high-latency I2P connections with pipelining and idle timeout management.

      • connectToServer

        public boolean connectToServer(NewMailListener nml)
        Connect to pop3 server if not connected. Checks mail if already connected. Non-Blocking unless an action already in progress. This will NOT call any configured NewMailListener, only the one passed in. It will be called with the value true if the connect was successful, false if not. Call getNumMails() to see if there really was any new mail. After the callback is executed, the information on new mails, if any, is available via getNumMails(), getUIDLs(), and getSize(). The connection to the server will remain open, so that new emails may be retrieved via getHeader(String), getBody(), and getBodies(). Failure info is available via lastError().
        Parameters:
        nml - notified once the listing is retrieved, or never on a connect or scan failure
        Returns:
        true if nml will be called back, false on failure and nml will NOT be called back

      • blockingConnectToServer

        boolean blockingConnectToServer()
        Connect to pop3 server if not connected. Does nothing if already connected. Blocking. This will NOT call any configured NewMailListener. After the callback is executed, the information on new mails, if any, is available via getNumMails(), getUIDLs(), and getSize(String). The connection to the server will remain open, so that new emails may be retrieved via getHeader(), getBody(String, Buffer), and getBodies(). Failure info is available via lastError().
        Returns:
        true if connected
