    i2p.susi.webmail.smtp.SMTPClient
    public class SMTPClientextends Object
    SMTP client for sending email through SMTP servers over I2P. Supports command pipelining, attachments, and size limits optimized for I2P. Includes base64 size calculations and 8BITMIME support for efficient I2P mail delivery.

      • capsText

        static String capsText(boolean pipelining, long maxSize, boolean eightBitMime)
        Reports what the server's EHLO response allowed, so a reader can tell why a message was refused on size or sent without pipelining. Each capability is answered yes or no rather than left as a bare phrase, and the wire name is kept beside the prose so the line stays greppable.
        Parameters:
        pipelining - whether the server accepts pipelined commands
        maxSize - the message size limit the server reported, in bytes
        eightBitMime - whether the server accepts unencoded 8-bit bodies
        Returns:
        the multi-line log message

      • sendMail

        public boolean sendMail(String host, int port, String user, String pass, String sender, List<String> recipients, StringBuilder body, List<Attachment> attachments, String boundary)
        Sends one message to an SMTP server, authenticating first when a user name is given. Any failure is appended to the error field rather than thrown.
        Parameters:
        host - the SMTP server to connect to
        port - the SMTP server port to connect to
        user - the AUTH LOGIN user name, base64-encoded on the wire
        pass - the AUTH LOGIN password, base64-encoded on the wire
        sender - the envelope sender, sent as MAIL FROM
        recipients - the envelope recipients, sent as one RCPT TO each
        body - headers and body, without the attachments
        attachments - may be null
        boundary - non-null if attachments is non-null
        Returns:
        true if the server accepted the message, false if any step failed
