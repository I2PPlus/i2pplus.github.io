      • threadedStartup

        private static WebMail.State threadedStartup(WebMail.SessionObject sessionObject, boolean offline, WebMail.State state, String host, int pop3PortNo, String user, String pass)
        Starts one thread to load the emails from disk, and in parallel starts a second thread to connect to the POP3 server (unless user clicked the 'read mail offline' at login). Either could finish first, but unless the local disk cache is really big, the loading will probably finish first. Once the POP3 connects, it waits for the disk loader to finish, and then does the fetching of new emails. The user may view the local folder once the first (loader) thread is done.
        Parameters:
        sessionObject - the session to initialize: caches, mailbox, and credentials are stored here
        offline - true to skip the POP3 connection and read only the disk cache
        state - the current state; ignored, always replaced
        host - the mail server host name to connect to
        pop3PortNo - the POP3 port number, 0-65535
        user - the mailbox user name
        pass - the mailbox password
        Returns:
        LOADING if the disk load is still running, LIST if it finished, AUTH if creating the disk cache failed
