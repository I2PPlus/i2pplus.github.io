      • pageName

        static String pageName(String stateName)
        Plain-language name of the page a state value leads to, for the request log.

        The state names are internal (LIST, SHOW, NEW), and a log line that prints one says nothing to a reader trying to work out why a page came up empty. This maps each to what the browser is about to show. An unknown value falls back to the name itself so the log stays greppable against the code.

        Parameters:
        stateName - the State name, as given by state.name()
        Returns:
        the page description, never null
