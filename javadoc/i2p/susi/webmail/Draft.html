    i2p.susi.webmail.Mail
    i2p.susi.webmail.Draft
    class Draftextends Mail
    Represents a draft email message with attachments and Bcc support. Differences from Mail: - Never multipart, body is always text/plain UTF-8 - Attachments are just headers containing name, type, encoding, and path to file - Bcc is a header
