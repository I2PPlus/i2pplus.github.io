i2p.susi.webmail

Class PersistentMailCache

  • java.lang.Object
    • i2p.susi.webmail.PersistentMailCache

  • class PersistentMailCache
extends Object
    Manages persistent on-disk email cache with custom compressed format. This is a custom format with subdirectories, gzipped files, and the encoded UIDL in the file name. We store either the headers or the full message. No, it is not Maildir format but we could add Maildir-style status suffixes (e.g. ":2.SR") later. Exporting to a Maildir format would be just ungzipping each file to a flat directory. This class should only be accessed from MailCache. TODO cached server caps and config.
