    i2p.susi.webmail.PersistentMailCache
    class PersistentMailCacheextends Object
    Manages persistent on-disk email cache with custom compressed format. This is a custom format with subdirectories, gzipped files, and the encoded UIDL in the file name. We store either the headers or the full message. No, it is not Maildir format but we could add Maildir-style status suffixes (e.g. ":2.SR") later. Exporting to a Maildir format would be just ungzipping each file to a flat directory. This class should only be accessed from MailCache.

      • PersistentMailCache

        public PersistentMailCache(I2PAppContext ctx, String host, int port, String user, String pass, String folder) throws IOException
        Use the params to generate a unique directory name. Does NOT load the mails in. Caller MUST call getMails(String).
        Parameters:
        ctx - supplies the log manager and the base directory
        host - IMAP host, part of the directory name
        port - IMAP port, part of the directory name
        user - mail account name, part of the directory name
        pass - not used; the cache is keyed on account name alone
        folder - on-disk maildir name, one of the DIRS values, e.g. DIR_FOLDER; only DIR_DRAFTS gets an attachment directory
        Throws:
        IOException - if the cache directory cannot be created
