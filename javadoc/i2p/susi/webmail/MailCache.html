    • Constructor Details

      • MailCache

        MailCache(I2PAppContext ctx, POP3MailBox mailbox, String folderName, String host, int port, String user, String pass) throws IOException
        Does NOT load the mails in. Caller MUST call loadFromDisk(NewMailListener).
        Parameters:
        ctx - the application context supplying the logger and the disk cache
        mailbox - non-null for DIR_FOLDER; null otherwise
        folderName - the folder this cache holds, one of the WebMail.DIR_ names
        host - POP3 host, passed through to the disk cache for reconnects
        port - POP3 port, passed through to the disk cache for reconnects
        user - POP3 account name, passed through to the disk cache
        pass - POP3 password, passed through to the disk cache
        Throws:
        IOException - if the persistent cache directory cannot be created

        Fetch any needed data from pop3 server, unless mode is CACHE_ONLY or HEADER_CACHE_ONLY, or this isn't the Inbox. Blocking for a long time unless mode is CACHE_ONLY or HEADER_CACHE_ONLY.

      • getMail

        public boolean getMail(MailCache.FetchMode mode)
        Fetch any needed data from pop3 server. Mail objects are inserted into the requests. After this, call getUIDLs() to get all known mail UIDLs. MUST already be connected, otherwise returns false. Call only on inbox! Blocking.
        Parameters:
        mode - HEADER or ALL only
        Returns:
        true if any were fetched
