    ReadCounter, Closeable, AutoCloseable
    public class EOFOnMatchInputStreamextends PushbackInputStream implements ReadCounter
    InputStream that returns EOF when input matches specified bytes. The reader never sees bytes from a full match. Extends PushbackInputStream for convenience but uses its buffer as a FIFO, not a stack. Do not call unread() methods externally.
