Interface Buffer

  • All Known Implementing Classes:
    FileBuffer, GzipFileBuffer, MemoryBuffer, OutputStreamBuffer, ReadBuffer

    public interface Buffer
    Base interface for data buffers. Data access is primarily through streams, with additional methods available in subclasses.
