    java.lang.Object
    i2p.susi.util.Folder<O>
    Type Parameters:
    O - type of objects stored in this folder
    public class Folder<O>extends Object
    Manages an Object array with paging and sorting support. Create a folder, set contents with setElements(O[]), add comparators with addSorter(), select a sort method with setSortBy(String, Folder.SortOrder), and retrieve the current page with currentPageIterator(). All public methods are synchronized.
