      • RegexOutputStream

        public RegexOutputStream(OutputStream out, String pattern, String replace, String onNoMatch)
        Construct with a literal pattern that may contain a single '*' wildcard.
        Parameters:
        out - MUST be buffered because this writes one byte at a time
        pattern - the only special char recognized is '*' and cannot be at the beginning or end
        replace - the replacement string, ASCII-only, no UTF-8
        onNoMatch - force output of this at the end if no replacement made, or null
