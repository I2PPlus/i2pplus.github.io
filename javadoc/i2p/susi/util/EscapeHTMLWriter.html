Class EscapeHTMLWriter

  • java.lang.Object

    Closeable, Flushable, Appendable, AutoCloseable

    public class EscapeHTMLWriter
extends FilterWriter
    Writer that escapes HTML characters during streaming. Streaming version of DataHelper.escapeHTML(), also escapes '--' for comment safety since '--' is disallowed inside HTML comments.
