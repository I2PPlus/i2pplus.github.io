      net.i2p
      Core I2P package providing fundamental interfaces, version information, and entry points to essential I2P services, centered on I2PAppContext.
      net.i2p.app
      Interfaces for classes to be started and stopped via clients.config.
      net.i2p.client
      Interfaces and factories for the base I2P SDK used to develop applications that communicate through I2P.
      net.i2p.client.datagram
      Provides a standard way for reading and writing messages transferred over I2P so that the recipient has an authenticated mechanism to reply to the sender.
      net.i2p.client.impl
      Internal implementation of the I2P client SDK - the client side of the Invisible Internet Client Protocol (I2CP), separating implementation from the interfaces in net.i2p.client.
      net.i2p.client.naming
      Naming service for resolving human-readable names (such as ident.i2p) into I2P destinations, providing a standard interface without JNDI complexity.
      net.i2p.data
      Common data structures used by the I2P protocols: Destination, LeaseSet, PublicKey, Signature, Certificate and their friends.
      net.i2p.data.i2cp
      The Invisible Internet Client Protocol (I2CP) allows applications simplified access to I2P network without requiring them to deal with the issues involved with the Invisible Internet Network Protocol (I2NP).
      net.i2p.internal
      Internal communication between a router and a client running in the same JVM, using queues instead of socket-based I2CP (the Invisible Internet Client Protocol), to avoid the serialization and socket overhead.
      net.i2p.kademlia
      Generic Kademlia distributed hash table implementation supporting multiple hash algorithms (SHA1, SHA256 and others).
      net.i2p.socks
      SOCKS 4 and SOCKS 5 client protocol implementations, extracted from i2ptunnel for broader use across I2P applications, including SSLEepGet.
      net.i2p.stat
      Statistics collection framework used throughout the router for adaptive operation, monitoring and debugging.
      net.i2p.time
      Time synchronization interface (Timestamper) and the build timestamp.
      net.i2p.update
      Update checking and installation interfaces: update types, version comparison, status reporting and the UpdateManager used by the router and the console to offer updates.
      net.i2p.util
      General utility classes shared across the core libraries and the router.
      Core Crypto
      com.southernstorm.noise.crypto.chacha20
      ChaCha20 is a fast stream cipher; combined with the Poly1305 MAC it forms an authenticated-encryption (AEAD) construction that stays fast even without hardware AES support.
      com.southernstorm.noise.crypto.x25519
      X25519 is a modern elliptic curve Diffie-Hellman function providing high-performance key exchange with strong security guarantees.
      net.i2p.crypto
      Core cryptographic primitives used throughout I2P: symmetric ciphers (AES, ChaCha20), hashes (SHA-1, SHA-256, SHA-384, SHA-512), HMAC and HKDF key derivation, the ElGamal and DSA/EdDSA/RedDSA engines, key and certificate utilities, and the entropy harvester.
      net.i2p.crypto.eddsa
      Java implementation of EdDSA, a digital signature scheme using a variant of elliptic curve cryptography based on Twisted Edwards curves.
      net.i2p.crypto.eddsa.math
      Data structures that define curves and fields, and the mathematical operations on them.
      net.i2p.crypto.eddsa.math.bigint
      Generic elliptic curve mathematical implementation using Java BigIntegers, serving as the reference implementation for curves without specialized optimizations.
      net.i2p.crypto.eddsa.math.ed25519
      Optimized mathematical implementation for Ed25519 using Radix 2^51 field representation for performance on 64-bit processors.
      net.i2p.crypto.eddsa.spec
      Specifications and parameter tables for EdDSA elliptic curves and keys, including the Ed25519 (Curve25519) specification and the named-curve registry.
      net.i2p.crypto.elgamal
      Implementation of the ElGamal public-key cryptosystem for I2P, copied from Bouncy Castle 1.53 and adapted for the I2P security provider.
      net.i2p.crypto.elgamal.impl
      Concrete implementations of ElGamal public and private keys, based on Bouncy Castle 1.53 and modified for the I2P security provider.
      net.i2p.crypto.elgamal.spec
      Parameter specifications and key interfaces for ElGamal, copied from Bouncy Castle 1.53 and adapted for the I2P security provider.
      net.i2p.crypto.provider
      Java Security (JCA) Provider registering I2P's EdDSA signature algorithm with the standard Java security APIs.
      net.i2p.crypto.x25519
      X25519 elliptic curve Diffie-Hellman key exchange (RFC 7748), wrapping Noise's Curve25519 operations with Java Security API parameter specifications.
      net.i2p.crypto.x25519.spec
      Algorithm parameter specifications for the X25519 key agreement and key pair generator.

      Router
      net.i2p.data.i2np
      Low-level messages sent between routers - the Invisible Internet Network Protocol (I2NP).

      The I2P router application handles I2P network communication.

      Interface and framework for applications managed by the router via clients.config.

      Router-side implementation of the Invisible Internet Client Protocol (I2CP): client sessions over plain or TLS sockets, message delivery, and lease and tunnel management on behalf of clients.
      net.i2p.router.crypto
      Router-specific cryptography: ElGamal+AES garlic encryption (ElGamalAESEngine), session key and tag caching for repeated peer communication (TransientSessionKeyManager), router-family shared keys (FamilyKeyCrypto), and the ratchet and pqc subpackages.
      net.i2p.router.crypto.pqc
      Post-quantum hybrid key encapsulation built on the bundled Bouncy Castle ML-KEM primitives.
      net.i2p.router.crypto.ratchet
      The Double Ratchet with X25519 key agreement and ECIES hybrid encryption, used by the NTCP2 and SSU transports for session encryption.
      net.i2p.router.dummy
      Simplified fake implementations of router interfaces (comm system and friends) for testing and embedded builds.
      net.i2p.router.message
      Garlic message creation, parsing and handling, and the outbound message jobs: one-shot sends, source routing and delivery status handling.
      net.i2p.router.networkdb
      Network database message handling shared by all facades: database lookup jobs and local RouterInfo publication.
      net.i2p.router.networkdb.kademlia
      The Kademlia distributed hash table (DHT) network database: lookup, store and explore jobs, the data store, the floodfill variants, and lookup throttling.
      net.i2p.router.networkdb.reseed
      Reseeding: fetching router info lists from reseed servers, web indexes or local files, validating them (signed SU3 update files and unsigned ZIP archives) and processing them to bootstrap into the network.
      net.i2p.router.peermanager
      Peer profiles and capacity calculation, peer test jobs, peer selection for tunnel building, and the database and tunnel history used for peer selection.
      net.i2p.router.startup
      The I2P startup package loads configuration when I2P is started.
      net.i2p.router.sybil
      Offline analysis tools for detecting Sybil attacks and malicious peer coordination by correlating peer relationships.
      net.i2p.router.tasks
      Periodic maintenance jobs: stats coalescing, cryptographic algorithm checks, liveliness marking, out-of-memory handling, thread dumps, the watchdog, graceful shutdown and soft restart, update installation, republishing and config reloading.
      net.i2p.router.time
      Router time synchronization: peer-based clock sync (RouterTimestamper) and an NTP client with time zone support.
      net.i2p.router.transport
      Transport framework: the transport lifecycle and pool management, connection handling and bandwidth throttling for the transports (NTCP2 over TCP, SSU over UDP) that carry I2P messages between routers, plus NAT traversal via UPnP and GeoIP country lookups.
      net.i2p.router.transport.crypto
      Transport-layer key agreement: the X25519 key factory used by the NTCP2 and SSU2 session handshakes for peer authentication and session encryption.
      net.i2p.router.transport.ntcp
      NTCP2, the TCP transport: framed, ratchet-encrypted and mutually authenticated connections between routers.
      net.i2p.router.transport.udp
      SSU2, the UDP transport: datagram sessions with Holepunch peer discovery, plus the older SSU compatibility code.
      net.i2p.router.tunnel
      Tunnel messages and the tunnel layer: the TunnelManagerFacade, tunnel build request and reply processing, and the inbound and outbound tunnel structures.
      net.i2p.router.tunnel.pool
      Tunnel pool management: pool lifecycle, peer selection, build scheduling and failure handling for client and exploratory tunnels.
      net.i2p.router.util
      Router utility classes: CoDel active queue management, time-decaying collections, a diagnostics ring buffer, CIDR matching, and password management.
