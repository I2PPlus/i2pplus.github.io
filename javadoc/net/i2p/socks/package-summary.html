Package net.i2p.socks

  1. i2p
  2. net.i2p.socks
Search page
    package net.i2p.socks

    SOCKS 4 and SOCKS 5 client protocol implementations, extracted from i2ptunnel for broader use across I2P applications, including SSLEepGet. The SOCKS server implementation is in net.i2p.i2ptunnel.socks.

    See also: RFC 1928 (SOCKS5) • RFC 1929.
