net.i2p.data.router

Class RouterKeyGenerator

  • java.lang.Object
    • net.i2p.data.RoutingKeyGenerator
      • net.i2p.data.router.RouterKeyGenerator

  • public class RouterKeyGenerator
extends RoutingKeyGenerator
    Generates routing keys from hashes using date-based modification to prevent Sybil attacks. Transforms input hashes by appending current GMT date (yyyyMMdd format) and computing SHA256. The modification data changes daily at midnight GMT to randomize routing keys consistently. The transformation takes the original hash, appends the bytes of the current mod data, then returns the SHA256 of that concatenation. This makes Sybil attacks much harder as she needs to essentially take over the whole keyspace. Note: generateDateBasedModData() should be called after midnight GMT once per day to generate the correct routing keys.
