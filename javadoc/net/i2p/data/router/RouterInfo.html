    Serializable, DataStructure
    public class RouterInfoextends DatabaseEntry
    Defines the data that a router either publishes to the global routing table or provides to trusted peers.

    For efficiency, the methods and structures here are now unsynchronized. Initialize the RI with readBytes(InputStream), or call the setters and then sign() in a single thread. Don't change it after that.

    To ensure integrity of the RouterInfo, methods that change an element of the RouterInfo will throw an IllegalStateException after the RouterInfo is signed.
