    Serializable, DataStructure
    public class RouterAddressextends DataStructureImpl
    Defines a method of communicating with a router

    For efficiency, the options methods and structures here are unsynchronized. Initialize the structure with readBytes(InputStream), or call the setOptions(). Don't change it after that.

    To ensure integrity of the RouterInfo, methods that change an element of the RouterInfo will throw an IllegalStateException after the RouterInfo is signed.

    Expiration is accepted and returned, but the router MUST write all zeros: the field is ignored on readin and a non-zero value fails the signature check. Implementing expiration, or any other use of the field, requires several releases to propagate because it is backwards-incompatible.

      • HTML_LABELS

        private static final Map<String,String> HTML_LABELS
        Human-readable names for the option keys, for toHtml(). The introducer keys are prefixes that take a slot index, such as ih0, and are looked up without the index. These mirror the option-key constants in the transport packages, which this package cannot reference without a dependency cycle, so keep the two in step by hand.

        Names are deliberately kept to a similar length so the values line up in the console's monospace block.

      • getCost

        public int getCost()
        Retrieve the weighted cost of this address, relative to other methods of contacting this router. The value 0 means free and 255 means really expensive. No value above 255 is allowed.

        Unused before 0.7.12.

        Returns:
        0-255

      • setCost

        public void setCost(int cost)
        Configure the weighted cost of using the address. No value negative or above 255 is allowed.

        WARNING - do not change cost on a published address or it will break the RI sig. There is no check here. Rarely used, use 3-arg constructor.

        NTCP is set to 10 and SSU to 5 by default, unused before 0.7.12.

        Parameters:
        cost - 0-255, where 0 is free and 255 is most expensive

        public String toString()
        Form for logs and peer pages: style, host:port, then the remaining options and cost, sorted by OrderedProperties, wrapped onto a continuation line every LOG_WRAP pairs.       • toHtml

        public String toHtml()
        HTML rendering for the console info page: one key-value pair per line, each side in its own span so the theme can style keys and values apart. Unlike toString() this keeps the option keys the log form omits, names them readably, escapes the values, and orders the lines by the name the reader sees rather than by the option key. The transport style and its host:port stay leading.
        Returns:
        the address as HTML lines, each pair newline terminated

      • _htmlPair

        Appends one <span class=key>label</span> <span class=value>value</span> line, padding the label and escaping the value. There is no punctuation between the two spans - the theme styles the key span, and that styling is what separates the label from the value.
        Parameters:
        buf - the builder the line is appended to
        label - the display name, right-padded to HTML_LABEL_WIDTH
        value - the text to HTML-escape and place in the value span
