    net.i2p.data.router.RouterPrivateKeyFile
    public class RouterPrivateKeyFileextends PrivateKeyFile
    Handles router private key files, extending PrivateKeyFile to provide RouterIdentity access instead of Destination. Maintains the same file format as the parent class while adding router-specific functionality.
