Class GarlicClovePool

  • java.lang.Object
    • net.i2p.data.i2np.GarlicClovePool

  • public class GarlicClovePool
extends Object
    Pool for reusing GarlicClove instances across message parsing. Reduces per-clove allocation in the hot garlic message loop. Cloves are acquired, populated via setters, used, then released back to the pool for reuse. The pool expands dynamically when empty. Thread-safe for single-producer/single-consumer use (typical garlic message parsing pattern). Not safe for concurrent acquire/release.
