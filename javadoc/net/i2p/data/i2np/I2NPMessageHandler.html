        public int readMessage(byte[] data, int offset, int maxLen) throws I2NPMessageException
        Limit the max to read from the data buffer, so that we can use a large buffer but prevent the reader from reading off the end.

        Result is retrieved with lastRead().

        Parameters:
        data - the buffer holding the serialized message
        offset - the index in data at which the message starts
        maxLen - read no more than this many bytes from data starting at offset, even if it is longer must be at least 16
        Returns:
        the number of bytes read from data
        Throws:
        I2NPMessageException - on an unknown type or body
