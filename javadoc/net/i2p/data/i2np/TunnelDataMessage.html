    I2NPMessage
    public class TunnelDataMessageextends FastI2NPMessageImpl
    Defines the message sent between routers as part of the tunnel delivery

    The tunnel ID is changed in-place by TunnelParticipant.send(HopConfig, TunnelDataMessage, RouterInfo), so we can't reuse the checksum on output, but we still subclass FastI2NPMessageImpl so we don't verify the checksum on input... because this is a high-usage class.
