    public class LeaseSet2extends LeaseSet
    Implementation of LeaseSet2 as specified in Proposal 123: New NetDb Entries.

    LeaseSet2 provides several enhancements over the original LeaseSet format:

    • Support for multiple encryption keys with server preference ordering
    • Offline signature support for reduced router load
    • Published and expiration timestamps independent of lease times
    • Options and statistics support
    • Blinded and encrypted LeaseSet support

    Key differences from LeaseSet:

    • Uses getPublished() for version comparison instead of lease dates
    • Supports multiple encryption keys via getEncryptionKeys()
    • Includes offline signing capabilities via setOfflineSignature(long, SigningPublicKey, Signature)
    • Has separate published and expires timestamps

        public void encrypt(SessionKey key)
        Encrypt the gateway and tunnel ID of each lease, leaving the expire dates unchanged. This adds an extra dummy lease, because AES data must be padded to 16 bytes. The fact that it is encrypted is not stored anywhere. Must be called after all the leases are in place, but before sign().
        Overrides:
        encrypt in class LeaseSet
        Parameters:
        key - the session key whose first block is the AES key, with the remainder used to derive the initialization vector
