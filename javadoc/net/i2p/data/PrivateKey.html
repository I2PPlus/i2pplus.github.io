    public class PrivateKeyextends SimpleDataStructure implements Destroyable
    Private (secret) key for the asymmetric encryption of an I2P destination.

    Type and length:

    • The EncType is fixed at construction and never changes, and it determines the length: 256 bytes for the default EncType.ELGAMAL_2048, 32 for EncType.ECIES_X25519. KEYSIZE_BYTES is the default type's length only.
    • For ElGamal the array is the private exponent padded to the key size, which is why hashCode() uses the last 4 bytes - the leading ones are all zero.
    • Call destroy() when the key is no longer needed. That zeroes the array and returns it to the byte cache, so after it the key reports isDestroyed() and length() still returns the type's length but the data is gone.

    Caching:

    • The derived public key is cached in memory: the first toPublic() computes it, later calls return the same PublicKey instance. A key built with the PrivateKey(EncType, byte[], PublicKey) constructor starts with the caller's instance. There is no key cache of any kind here, and no create() factory method - build the key directly, or read it from a PrivateKeyFile.

    Thread safety:

    • Not thread-safe. The data cannot be reassigned once set, but the cached public key and the zeroing done by destroy() are unsynchronized writes to plain fields, and SimpleDataStructure.getData() hands out the backing array. Share a fully populated key, or pass it through a synchronized structure, and do not destroy() or write to the array while another thread may be using it.
