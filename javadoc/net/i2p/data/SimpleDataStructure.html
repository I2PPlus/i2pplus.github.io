    public abstract class SimpleDataStructureextends Object implements DataStructure
    Base class for I2P data structures holding a single byte array in a protected _data field.

    What the base class actually provides:

    • Length: length() is abstract, and subclasses fix it per type - 32 bytes for Hash or SessionKey, 256 for an ElGamal PublicKey, and 20, 32, 64 or 256 for a SigningPublicKey depending on the algorithm. It is a fixed length per subclass, not per instance.
    • Single assignment: setData(byte[]), readBytes(InputStream) and fromBase64(String) all refuse to overwrite non-null data with a RuntimeException, and reject a wrong length. fromByteArray(byte[]) and fromBase64(String) additionally reject null.
    • No copy: getData() and toByteArray() return the backing array itself, not a copy.
    • Encoding: toBase64() and, where a subclass adds it, its own base32 rendering.
    • Comparison: equals(Object) compares the raw arrays without checking the class or length, so two different SimpleDataStructure subclasses of equal length holding equal bytes compare equal (e.g. a 32-byte SessionKey and a 32-byte Hash). hashCode() uses the first 4 bytes only, which requires the data to be random - subclasses with structured data override it.

    Not provided here:

    • No cache: there is no LRU or any other cache in this class. Subclasses that want one supply their own static SDSCache and expose create() factory methods that go through it - see Hash.
    • Not thread-safe: nothing here is synchronized and _data is not volatile, so an instance must be published safely (final field, or a happens-before edge) before other threads read it. Safe sharing applies only to a fully populated instance that nobody mutates - and callers that mutate the array returned by getData() break that.
