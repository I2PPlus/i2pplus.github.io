    public class Hashextends SimpleDataStructure
    A 32-byte SHA-256 hash, used throughout I2P as a destination, router, or tunnel identifier and as an integrity value for hashed data.

    Creating a Hash:

    • create(byte[]) and its siblings go through a static SDSCache and are the preferred way to obtain one. The cache is keyed on the first 4 bytes of the data and holds weak references, so entries disappear under memory pressure; its maximum size is scaled by the JVM's available memory. On a cache hit the byte array passed in is handed back to SimpleByteCache for reuse and must not be touched afterwards.
    • new Hash(byte[]) bypasses the cache entirely. Use create() when the same hash may be built repeatedly.
    • create(InputStream) reads exactly 32 bytes from the stream and wraps them; it does not hash the stream. To hash arbitrary data, use SimpleDataStructure.calculateHash() or a SHA256Generator.

    Rendering:

    • toBase64() caches its result in a volatile field.
    • toBase32() caches its result the same way.

    Comparison:

    • hashCode() is the precomputed value of the first 4 bytes, held in a volatile field. It is not constant-time.
    • equals() is inherited from SimpleDataStructure and is Arrays.equals(byte[], byte[]) - not constant-time, and not class-specific, so another 32-byte SimpleDataStructure such as a SessionKey holding the same bytes compares equal to a Hash.

    Thread safety:

    • The data cannot be reassigned once set, so a Hash that is safely published (constructed and then handed to other threads) can be shared freely; the derived _base64ed, _base32ed and _cachedHashCode fields are volatile. SimpleDataStructure._data itself is neither final nor volatile, so a Hash built by a constructor and published through an unsynchronized data structure may expose stale data.
    • SimpleDataStructure.getData() hands out the backing array, so a caller that mutates it corrupts the cached hash code and the cached Base64 and Base32 strings, as well as any byte cache that shares the array.
