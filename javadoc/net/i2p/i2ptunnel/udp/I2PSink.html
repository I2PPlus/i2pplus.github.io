Class I2PSink

  • java.lang.Object
    • net.i2p.i2ptunnel.udp.I2PSink
  • All Implemented Interfaces:
    Sink

    public class I2PSink
extends Object
implements Sink
    I2P sink implementation that sends datagrams to a fixed destination specified in the constructor.

    Supports both repliable and raw datagram modes. When not in raw mode, data is wrapped with I2PDatagramMaker before sending.
