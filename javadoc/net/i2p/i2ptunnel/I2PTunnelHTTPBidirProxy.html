        public I2PTunnelHTTPBidirProxy(int localPort, Logging l, I2PSocketManager sockMgr, I2PTunnel tunnel, EventDispatcher notifyThis, long clientId)
        Create a bidirectional HTTP proxy tunnel on localPort, reusing the server's existing I2P socket manager. As of 0.9.20 this is fast, and does NOT connect the manager to the router, or open the local socket. You MUST call startRunning() for that.
        Parameters:
        localPort - the local port to bind to
        l - the logger the tunnel and its listeners write through
        sockMgr - the I2P socket manager
        tunnel - the I2P tunnel
        notifyThis - the event dispatcher for notifications
        clientId - the client ID
        Throws:
        IllegalArgumentException - if the I2PTunnel does not contain valid config to contact the router
