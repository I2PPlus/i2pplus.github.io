    class SocketWrapperextends Object implements I2PSocket
    I2PSocket implementation wrapping a standard TCP Socket obtained from an outproxy, which is itself a wrapper around the Orchid stream.

    SOCKS and HTTP tunnels use this so the tunnel framework can treat an outproxy connection as an I2P connection and handle it uniformly. All I2PSocket operations are delegated to the underlying Socket, and the destination is a fixed dummy: there is no I2P destination to report.
