Search page
    package net.i2p.i2ptunnel.socks

    SOCKS 4, 4a and 5 server implementations exposing I2P client tunnels to SOCKS clients. The SOCKS client protocol code is in net.i2p.socks.

    See also: RFC 1928 (SOCKS5) • RFC 1929 (username and password authentication).
