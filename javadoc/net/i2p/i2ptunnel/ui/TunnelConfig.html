    net.i2p.i2ptunnel.ui.TunnelConfig
    public class TunnelConfigextends Object
    Helper class to generate a valid TunnelController configuration from provided settings.

    This class is also used by Android. Maintain as a stable API and take care not to break Android.

        private static Map<String,String> parseCustomOptions(String args)
        Parse the args submitted in the custom options field.

        Modified from EepGet.parseAuthArgs(String) Spaces or tabs separate args. Args may be single- or double-quoted if they contain spaces or tabs. There is no provision for escaping quotes.         args - non-null

        the parsed key-value pairs, empty if none; a key with no value maps to the empty string
