Package net.i2p.i2ptunnel.web Description

Web-based user interface for managing I2PTunnel configurations, implemented as a webapp packaged in i2ptunnel.war.

This package provides:

  • Tunnel creation and configuration forms
  • Tunnel management (start, stop, restart)
  • Tunnel status monitoring
  • Configuration validation
  • Integration with router console

Not maintained as a stable API for external use.
