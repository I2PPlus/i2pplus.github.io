    Packages that use net.i2p.i2ptunnel
    Package
    Description
    net.i2p.i2ptunnel
    Implementation of preconfigured tunnels for clients and servers, including special-purpose tunnels for IRC, SOCKS, HTTP and streaming.
    net.i2p.i2ptunnel.irc
    IRC tunnel support: DCC and CTCP handling for IRC clients using a client tunnel.
    net.i2p.i2ptunnel.socks
    SOCKS 4, 4a and 5 server implementations exposing I2P client tunnels to SOCKS clients.
    net.i2p.i2ptunnel.streamr
    StreamR adaptive-rate streaming tunnel: streams audio and video over a single I2P tunnel, adapting the encoder rate to the measured tunnel bandwidth.
    net.i2p.i2ptunnel.udpTunnel
    Base classes for UDP client and server tunnels, mapping a local UDP port to an I2P tunnel through the sinks and sources in net.i2p.i2ptunnel.udp.
    net.i2p.i2ptunnel.ui
    Public API classes for programmatic tunnel configuration and management, providing a stable API for external applications, including the Android client.
    net.i2p.i2ptunnel.web
    The I2PTunnel configuration web interface (i2ptunnel.war): servlets and helpers for creating and editing tunnels.
    net.i2p.router.web.helpers
    Helpers and handlers for the router console user interface, packaged in routerconsole.war and accessible only from JSP files.
