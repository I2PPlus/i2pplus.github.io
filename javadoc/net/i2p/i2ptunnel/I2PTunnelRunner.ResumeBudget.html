    static final class I2PTunnelRunner.ResumeBudgetextends Object
    Progress-based budget for body-resume cycles. Pure decision state so the I2PTunnelRunner.resumeIncompleteBody(OutputStream) loop stays thin and tests can pin stall-reset and absolute-cap behaviour without a live transfer.

    Only consecutive no-progress cycles count against the size-scaled stall cap (I2PTunnelRunner.stallCycleLimit(long); baseline I2PTunnelRunner.MAX_EMPTY_RECONNECT_CYCLES); any forward progress resets that counter. I2PTunnelRunner.totalCycleLimit(long) bounds total attempts regardless of progress so a pathological trickle still terminates.

      • refundLast

        void refundLast()
        Refund the last consume's stall charge when a resume attempt failed with a transient status (408/502/503/504) rather than a real stall. A gateway timeout must not eat the empty/stall budget, or the next non-Range retry would be blocked for an unrelated reason.

        Only the stall charge is refunded. The total count stays consumed so I2PTunnelRunner.totalCycleLimit(long) remains an absolute cap over ALL attempts; refunding it would let a persistently transient-failing upstream reconnect forever.
