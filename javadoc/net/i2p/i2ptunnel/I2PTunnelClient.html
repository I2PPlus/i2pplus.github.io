    public class I2PTunnelClientextends I2PTunnelClientBase
    Standard I2P client tunnel that forwards local TCP connections to I2P destinations.

    Listens on a local port and creates I2P connections to configured destinations when clients connect. Supports multiple destinations with random selection, configurable read timeouts, and port mapping for services like SMTP and POP.

    Handles destination resolution, connection management, and data forwarding between local client socket and remote I2P destination.

      • I2PTunnelClient

        public I2PTunnelClient(int localPort, String destinations, Logging l, boolean ownDest, EventDispatcher notifyThis, I2PTunnel tunnel, String pkf) throws IllegalArgumentException
        Create a standard client tunnel listening on localPort, forwarding to the given destinations. As of 0.9.20 this is fast, and does NOT connect the manager to the router, or open the local socket. You MUST call startRunning() for that.
        Parameters:
        localPort - if 0, use any port, get actual port selected with getLocalPort()
        destinations - peers we target, comma- or space-separated. Since 0.9.9, each dest may be appended with :port
        l - the logging instance
        ownDest - whether to use an owned destination
        notifyThis - the event dispatcher for notifications
        tunnel - the I2PTunnel instance, supplying the context and listen host
        pkf - the path to a persistent private key file, or null to generate one
        Throws:
        IllegalArgumentException - if the I2PTunnel does not contain valid config to contact the router

    • Method Details

      • setReadTimeout

        public void setReadTimeout(long ms)
        Set the read idle timeout for newly-created connections (in milliseconds). After this time expires without data being reached from the I2P network, the connection itself will be closed.

        Less than or equal to 0 means forever. Default -1 (forever) as of 0.9.36 for standard tunnels, but extending classes may override. Prior to that, default was 5 minutes, but did not work due to streaming bugs.

        Applies only to future connections; calling this does not affect existing connections.

        Parameters:
        ms - the idle timeout in ms; zero or negative means forever
