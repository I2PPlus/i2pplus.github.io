    Incoming connection filter configurable through access list rules.

    Tracks known destinations (defined in access lists) and unknown destinations (recently attempted connections). Reloads access lists from disk when modified to allow user edits. Writes recorder data to disk at intervals when new threshold breaches occur.

      • readRecorderFile

        static AccessFilter.RecorderFileState readRecorderFile(File file) throws IOException
        Read the persisted breached-b32 set for a recorder file, capturing its (lastModified, length) signature at read time.

        The set is the plain set of lines in the file (raw b32 strings); no parsing is done, matching the historic reader. A missing or non-file yields an empty set with valid == false so a later appearance of the file is detected as a change.

        Parameters:
        file - the breach recorder file
        Returns:
        the read set plus its signature
        Throws:
        IOException - on an error reading the file

      • recorderFileUnchanged

        static boolean recorderFileUnchanged(AccessFilter.RecorderFileState cached, File file)
        Whether a recorder file's on-disk signature still matches the one captured when cached was read, i.e. whether the cached breached set can be reused without opening the file again.

        The recorder file is almost always written only by this filter, so on the 5-second sync cycle the file is unchanged and the set is reused. External edits (recreating the file) change the signature and force a re-read, so user changes are still picked up. Misses on a missing file are reported as unchanged so an absent file does not re-read either.

        Parameters:
        cached - the previous AccessFilter.RecorderFileState, or null on first use
        file - the breach recorder file
        Returns:
        true if cached.breached is still current
