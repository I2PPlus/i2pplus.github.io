net.i2p.i2ptunnel

Class TunnelControllerGroup

  • java.lang.Object
    • net.i2p.i2ptunnel.TunnelControllerGroup
  • All Implemented Interfaces:
    ClientApp

    public class TunnelControllerGroup
extends Object
implements ClientApp
    Coordinates tunnel groups within the JVM, managing configuration persistence.

    Loads and stores tunnel configurations to disk, builds new tunnels on request. Entry point from clients.config.
