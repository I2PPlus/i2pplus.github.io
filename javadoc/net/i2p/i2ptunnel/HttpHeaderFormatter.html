    Utility class for formatting HTTP headers.

    This class provides static methods for formatting HTTP headers for both transmission and logging purposes. It handles the conversion of header maps to properly formatted HTTP header strings.

      • formatHeaders

        public static String formatHeaders(Map<String, List<String>> headers, StringBuilder command)
        Formats headers into an HTTP request/response string.

        This method takes a header map and formats it into a properly formatted HTTP header block suitable for transmission. The format is:

        REQUEST_LINE
Header-Name: value
...
        Parameters:
        headers - the HTTP headers map (header name to list of values)
        command - the request/response command line (e.g., "GET / HTTP/1.1")
        Returns:
        the formatted HTTP headers as a string

      • stripLineBreaks

        static String stripLineBreaks(String s)
        Removes CR and LF from a header name, value, or request line.

        Header maps are rebuilt from text that was parsed line by line, so a line break can only reach this point through a value that was constructed elsewhere (a spoofed host, a security header, a server response rewrite). Stripping it keeps a hostile value from splitting the message into extra header lines or an injected body (HTTP response splitting).

        Parameters:
        s - the header name, value, or request line, may be null
        Returns:
        the input with CR and LF removed, or null if null was passed

      • formatHeadersCompact

        public static String formatHeadersCompact(Map<String, List<String>> headers, StringBuilder command)
        Formats headers into a compact string for logging.

        This method creates a compact, human-readable representation of HTTP headers suitable for logging. It filters out sensitive or verbose headers like cookies, authentication headers, and excessive request details.

        The following are excluded from the output:

        • Headers containing "desthash", "destb64", "dnt"
        • Connection, Accept, Cookie, Pragma, Cache-Control headers
        • Referer header with full URL
        • Content-Length: 0
        • User-Agent containing "MYOB"
        • HEAD requests (headers only)

        Long request URLs containing "peer_id" are truncated.

        Parameters:
        headers - the HTTP headers map
        command - the request command line
        Returns:
        a compact string representation suitable for logging

      • formatHeadersForLog

        public static String formatHeadersForLog(Map<String, List<String>> headers, StringBuilder command)
        Formats the request and headers for the log, in the house continuation form. Unlike the wire form this is not what is sent to the server: the base64 and hash forms of the client destination are dropped as repeats of the base32 form, that form is shortened to the eight characters the log viewer links, and over-long values are cut.
        Parameters:
        headers - the HTTP headers map (header name to list of values)
        command - the request command line (e.g., "GET / HTTP/1.1")
        Returns:
        a string of "\n* name: value" lines, never null

      • getHostFromHeaders

        public static String getHostFromHeaders(String headers)
        Extracts the Host header value from raw HTTP headers.

        This method parses raw HTTP header text and extracts the value of the Host header. If the host contains a port number, it is stripped and only the hostname is returned.

        Parameters:
        headers - the raw HTTP headers as a string
        Returns:
        the hostname from the Host header, or null if not found
