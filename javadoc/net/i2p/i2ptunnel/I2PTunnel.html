      • runCommand

        public void runCommand(String cmd, Logging l)
        Parses and executes a tunnel management command.

        This method is the command dispatcher for tunnel management operations. It parses the command string into command name and arguments, then dispatches to the appropriate handler method.

        Supported Commands:

        • help - Display available commands
        • client/server - Create tunnel instances
        • list - List active tunnels
        • close - Close tunnels
        • config - Configure I2CP connection
        • genkeys - Generate destination keys
        Parameters:
        cmd - the command string to execute, format: "commandName arg1 arg2 ..."
        l - the Logging instance for command output
        See Also:
        • runHelp(Logging)
