Package net.i2p.i2ptunnel.localServer Description

Lightweight HTTP server for serving static resources (CSS, images) used by I2PTunnel HTTP client proxy error pages.

This minimal server provides:

  • Static file serving for error page resources
  • CSS styling for error displays
  • Image assets for error pages
  • Basic HTTP request handling

Used exclusively to enhance the user experience when proxy errors occur during HTTP tunneling operations.
