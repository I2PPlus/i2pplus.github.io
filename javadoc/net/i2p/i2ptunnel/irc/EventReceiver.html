    public abstract class EventReceiverextends Object implements EventDispatcher
    An implementation of the EventDispatcher interface for receiving events via in-line notifyEvent(String, Object) only. Does not support chaining to additional dispatchers. Does not support waitEventValue(String). Does not support ignoring.
