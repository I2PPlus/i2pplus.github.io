      • newIncoming

        public int newIncoming(String b32, int port, String type)
        Handle an incoming DCC request from a remote peer. Validates the base32 address and creates a new DCC client tunnel.
        Parameters:
        b32 - the remote DCC server's base32 destination (60 chars, ending in .b32.i2p)
        port - the remote DCC server's I2P port
        type - the DCC type (currently ignored)

      • resumeOutgoing

        public int resumeOutgoing(int port)

        Parameters:
        port - the local DCC client tunnel port to resume
        Returns:

      • acceptIncoming

        public int acceptIncoming(int port)
        Handle an incoming DCC ACCEPT response from the remote peer. Searches for a matching tunnel in complete, active, or incoming states and creates a new incoming connection with the original parameters.
        Parameters:
        port - the remote DCC server's I2P port from the ACCEPT message
        Returns:
        the local DCC client tunnel port for the new connection, or -1 if no match found
