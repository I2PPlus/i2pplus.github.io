    public abstract class I2PTunnelTaskextends EventDispatcherImpl
    Base class for I2P tunnel servers and clients.

    Use caution when extending externally. Should be maintained as stable API, but confirm before use. No startRunning() method; all extending classes implement one.

      • close

        public abstract boolean close(boolean forced)
        Note that the tunnel can be reopened after this by calling startRunning(). This may not release all resources. In particular, the I2PSocketManager remains and it may have timer threads that continue running.

        To release all resources permanently, call destroy().

        Parameters:
        forced - true to interrupt an in-progress build, false to close gracefully
        Returns:
        true if the tunnel was closed and can be reopened by startRunning()

      • destroy

        public boolean destroy()
        Note that the tunnel cannot be reopened after this by calling startRunning(), as it may destroy the underlying socket manager, depending on implementation. This should release all resources.

        The implementation here simply calls close(true). Extending classes should override to release all resources.

        Returns:
        true if every resource was released
