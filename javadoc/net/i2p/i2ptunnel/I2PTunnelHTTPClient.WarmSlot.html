    Request-scoped state machine for one speculative warm socket.

    The slot leases a per-destination connection permit from open(Hash, int, Hash) until the socket is handed to the request by take(Hash, int) or the attempt is abandoned by releaseLease() / cancel(); the releaser callback fires at most once per acquisition. Each attempt carries a generation so a background connect that completes after the slot moved on cannot install its socket or leak its permit into a later attempt — the failure modes of a plain holder: late install after teardown, handing a socket to a different destination, and double or missing permit release. All state is guarded by one lock because the background connect races request teardown.

      • open

        long open(Hash destHash, int port, Hash permit)
        Begin a warm-connect attempt, taking a lease on permit. The lease is owned by the attempt until it installs, fails, or is rejected — install(long, I2PSocket) on success, releaseLease() otherwise.
        Parameters:
        destHash - destination the attempt will connect to
        port - remote port (0 = default)
        permit - connection permit this attempt leases
        Returns:
        the attempt generation, or -1 when the slot is not idle (cancelled, full, or another attempt in flight); on -1 the caller keeps ownership of permit

      • install

        boolean install(long gen, I2PSocket sock)
        Install the socket produced by the attempt for gen. Rejects a stale generation (the attempt already failed or the slot was cancelled) so a late completion can never surface as the request's socket. The caller must close sock and call releaseLease() when this returns false.
        Parameters:
        gen - generation returned by open(Hash, int, Hash)
        sock - the connected socket
        Returns:
        true when installed (slot is now I2PTunnelHTTPClient.WarmSlot.State.FULL), false when the attempt is stale or the slot retired

      • take

        I2PSocket take(Hash destHash, int port)
        Take an installed socket for the request. On a destination/port match the socket is returned and its lease is released. The request already holds its own permit (heldPermitDest), so keeping the warm one would double-count. On a mismatch the socket is discarded rather than handed to a request it was not opened for, and the slot returns to I2PTunnelHTTPClient.WarmSlot.State.OPEN so a fresh attempt can be opened.
        Parameters:
        destHash - destination the caller needs
        port - remote port the caller needs (0 = default)
        Returns:
        the installed socket, or null when the slot is not full or the installed socket was for a different destination/port

      • releaseLease

        void releaseLease()
        Give back the lease held by the current attempt (failed, rejected, or interrupted connect). No-op while a socket is installed. The installed connection keeps its permit until taken or cancelled — and no-op when nothing is held, so it is safe to call from every attempt exit path without counting.

      • cancel

        void cancel()
        Retire the slot: close an installed socket if any and release the permit the slot still holds. An attempt still in flight keeps its lease — it releases it itself when install(long, I2PSocket) rejects it. Idempotent.
