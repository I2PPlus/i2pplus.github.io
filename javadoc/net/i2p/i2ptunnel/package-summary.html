    package net.i2p.i2ptunnel

    Implementation of preconfigured tunnels for clients and servers, including special-purpose tunnels for IRC, SOCKS, HTTP and streaming.

    The entry point is TunnelControllerGroup, started from clients.config; tunnel configuration is stored in i2ptunnel.config. The primary API consists of TunnelControllerGroup and TunnelController; other classes may not be maintained as a stable API.

    • Client tunnels: let external applications connect out to I2P destinations
    • Server tunnels: expose local services to the I2P network
    • HTTP proxy and server tunnels: browser-friendly web access
    • SOCKS tunnels: generic SOCKS proxy for TCP applications
    • IRC tunnels: DCC and CTCP handling for IRC clients
    • StreamR tunnels: adaptive-rate streaming
    • UDP tunnels: datagram bridging for DNS and voice

    The web interface for creating and editing tunnels is in net.i2p.i2ptunnel.web.

    See also: RFC 3986 (URI generic syntax) • RFC 7230 (HTTP/1.1 message syntax).
