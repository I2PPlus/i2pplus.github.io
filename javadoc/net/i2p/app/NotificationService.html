Interface NotificationService

  • All Known Implementing Classes:
    ExternalMain, Main

    public interface NotificationService
    A service to send messages to users. This service is currently provided by desktopgui (when supported and enabled). Other applications may support this interface in the future. Example usage:
         ClientAppManager cmgr = _context.clientAppManager();
     if (cmgr != null) {
         NotificationService ns = (NotificationService) cmgr.getRegisteredApp("desktopgui");
         if (ns != null)
             ns.notify("foo", null, Log.INFO, _t("foo"), _t("message"), "/foo/bar");
     }
