Class RateConstants

  • java.lang.Object
    • net.i2p.stat.RateConstants

  • public final class RateConstants
extends Object
    Centralized rate period constants for memory-optimized statistics collection. This class provides standardized period arrays for rate statistics to ensure consistency across the codebase while minimizing memory footprint.
