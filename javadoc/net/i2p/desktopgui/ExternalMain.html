    Simplified main class for App Context only, requiring only i2p.jar. Provides basic system tray functionality without router.jar dependency. Uses ExternalTrayManager for limited I2P management capabilities.

      • setMacTrayIcon

        private void setMacTrayIcon()
        Unless we do this, when we start DesktopGUI we get a Java coffee cup in the tray. The icon is set by reflection, so there is no compile or runtime dependency on the macOS-only eawt classes; every failure is logged and otherwise ignored, since this is cosmetic. This is the canonical documentation of the macOS integration: Main has a copy of this method. The dock menu, dock icon bounce and application Quit handling are not supported, and no code for them exists. Based on code from https://gist.github.com/bchapuis/1562406 , no apparent license. See also https://stackoverflow.com/questions/6006173/how-do-you-change-the-dock-icon-of-a-java-program
