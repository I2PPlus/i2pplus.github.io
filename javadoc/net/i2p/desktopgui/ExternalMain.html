Class ExternalMain

  • java.lang.Object
    • net.i2p.desktopgui.ExternalMain
  • All Implemented Interfaces:
    ClientApp, NotificationService

    public class ExternalMain
extends Object
implements ClientApp, NotificationService
    Simplified main class for App Context only, requiring only i2p.jar. Provides basic system tray functionality without router.jar dependency. Uses ExternalTrayManager for limited I2P management capabilities.
