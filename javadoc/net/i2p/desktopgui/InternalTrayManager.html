    net.i2p.desktopgui.InternalTrayManager
    class InternalTrayManagerextends TrayManager
    Tray manager for internal use with full router context access. Provides comprehensive I2P management through system tray including restart, shutdown, browser launch, and configuration options. Requires router.jar for complete functionality.
