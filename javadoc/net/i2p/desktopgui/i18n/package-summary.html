Package net.i2p.desktopgui.i18n Description

Internationalization (i18n) support for the Desktop GUI.

This package provides internationalization and localization support for the I2P Desktop GUI application. It handles loading and managing language resources, text translation, and locale-specific formatting.

Features include:

  • Resource bundle management
  • Dynamic language switching
  • Locale detection and configuration
  • Text direction support (LTR/RTL)
  • Pluralization and gender rules
