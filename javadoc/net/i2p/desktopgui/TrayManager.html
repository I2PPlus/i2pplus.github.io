    java.lang.Object
    net.i2p.desktopgui.TrayManager
    Direct Known Subclasses:
    ExternalTrayManager, InternalTrayManager
    abstract class TrayManagerextends Object
    Abstract base class for managing system tray icons and menus for I2P. Handles tray icon lifecycle, notifications, and provides platform-specific menu creation for both AWT and Swing implementations.
