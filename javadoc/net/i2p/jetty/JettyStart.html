    net.i2p.jetty.JettyStart
    All Implemented Interfaces:
    ClientApp
    public class JettyStartextends Object implements ClientApp
    Start Jetty where the args are one or more XML files. Save a reference to the Server so it can be cleanly stopped later. Caller must call startup() This is like XmlConfiguration.main(String[]), which is essentially what org.mortbay.start.Main does.
