    package net.i2p.jetty

    Jetty integration: starts the embedded Jetty server for all I2P webapps. Webapps are deployed as WAR files with JSPs precompiled at build time, request logging goes to the router log, and I2P-specific configuration glue handles ports, redirects and the console's HTTPS requirements.
