    public class SingleFileNamingServiceextends NamingService
    A naming service based on a single file using the "hosts.txt" format. Supports adds, removes, and listeners.

    All methods here are case-sensitive. Conversion to lower case is done in HostsTxtNamingService.

    This does NOT provide .b32.i2p or {b64} resolution. It also does not do any caching. Use from HostsTxtNamingService or chain with another NamingService via MetaNamingService if you need those features.
