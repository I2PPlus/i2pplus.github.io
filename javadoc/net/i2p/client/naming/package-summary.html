    package net.i2p.client.naming

    Naming service for resolving human-readable names (such as ident.i2p) into I2P destinations, providing a standard interface without JNDI complexity.

    • Hostname to Destination resolution
    • hosts.txt file support
    • Subscription-based updates
    • Caching of resolved names

    The implementation is selected by the i2p.naming.impl property: BlockfileNamingService in the router, HostsTxtNamingService for standalone clients.
