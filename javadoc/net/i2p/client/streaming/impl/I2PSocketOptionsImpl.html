      • getConnectTimeout

        public long getConnectTimeout()
        Base time to wait for the ACK from a SYN, in milliseconds.

        The stored value is un-scaled; the effective connect window adds the connect delay on the delayed-SYN path, is scaled by the connect timeout multiplier, and is capped at the absolute max connect timeout, so a stored value above that cap waits no longer than the cap.

        Default 30 seconds.

        Specified by:
        getConnectTimeout in interface I2PSocketOptions
        Returns:
        milliseconds to wait, or a non-positive value for no connect timeout, i.e. the handshake is not given up on a timer
