      • forceRescheduleNow

        public void forceRescheduleNow()
        Force immediate reschedule with minimum delay, cancelling any pending timer. Used by scheduleSoftFailureRetransmit() so that a soft-failure notification triggers a retransmit without waiting for the current RTO to elapse.

        Unlike pushBackRTO(int), this always schedules a new timer event rather than relying on reschedule(..., false) which won't shorten a running timer.

      • pushBackRTOBounded

        public void pushBackRTOBounded(int delayMs)
        Push back the retransmission timer to the given DELAY FROM NOW, but allow the fire time to move EARLIER if the new deadline is earlier than the currently scheduled one. RFC 6298 section 5.3 restarts the timer at the full RTO on every new ACK; with trickle ACKs that keeps deferring an overdue head-of-line retransmission indefinitely (the mid-download freeze). Callers anchor the delay to the oldest unacked packet's send time + RTO so the timer is guaranteed to fire.
        Parameters:
        delayMs - delay from now (the anchored deadline minus now); a value <= 0 forces an immediate fire
