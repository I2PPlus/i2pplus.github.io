      • Worker

        Worker(int shard, int queueCapacity, PacketDispatcher.PacketProcessor processor, I2PAppContext context)
        A shard's worker, not started here - the dispatcher starts the whole array at once so a resize can swap the shards over as a unit.
        Parameters:
        shard - shard index, used only to name the thread
        queueCapacity - entries this shard holds before producers wait
        processor - how to process an entry, from the dispatcher
        context - for the backlog and queue-depth rates, null in tests
