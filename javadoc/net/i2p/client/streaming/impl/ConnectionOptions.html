Class ConnectionOptions

  • All Implemented Interfaces:
    I2PSocketOptions

    class ConnectionOptions
extends I2PSocketOptionsImpl
    Define the current options for the con (and allow custom tweaking midstream).

    Static fields with volatile and class-level setters (e.g., setInitialRTO(int), setMaxWindowSize(int)) are globally shared and adjusted by the Tuner. Per-connection fields are copied from these globals when a new Connection is created.
