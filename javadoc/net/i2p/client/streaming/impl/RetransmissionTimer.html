Class RetransmissionTimer

  • java.lang.Object
    • net.i2p.client.streaming.impl.RetransmissionTimer

  • public class RetransmissionTimer
extends Object
    Per-destination timer for scheduling packet retransmissions. Uses a dedicated SimpleTimer2 (not the router-global one) to isolate streaming timer events from contention with other subsystems.
