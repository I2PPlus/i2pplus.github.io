net.i2p.client.streaming.impl

Class PacketHandler

  • java.lang.Object
    • net.i2p.client.streaming.impl.PacketHandler

  • class PacketHandler
extends Object
    Handles incoming packets by dispatching them to the appropriate connection, server socket, or responding with a reset (RST) packet if no valid connection is found.

    Packet flow: I2PSession -> MessageHandler -> PacketHandler -> ConnectionPacketHandler -> MessageInputStream.
