    net.i2p.client.streaming.impl.PacketHandler
    class PacketHandlerextends Object
    Handles incoming packets by dispatching them to the appropriate connection, server socket, or responding with a reset (RST) packet if no valid connection is found.

    Packet flow: I2PSession -> MessageHandler -> PacketHandler -> ConnectionPacketHandler -> MessageInputStream.

      • workerCountFor

        static int workerCountFor(int cores, String configured, int override)
        Clamped inbound receive worker count for a manager.

        The Tuner's live default wins when positive, so runtime tuning applies to managers created after the adjustment; otherwise a positive configured property value wins (capped at MAX_RECEIVE_WORKERS); otherwise the platform core count is used, floored at 2 for low-core hosts. Package-visible for unit tests.

        Parameters:
        cores - available processors at startup
        configured - raw property value, may be null
        override - Tuner global default, 0 = not armed
        Returns:
        the worker count, in 1..MAX_RECEIVE_WORKERS
