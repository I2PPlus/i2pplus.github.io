    net.i2p.client.streaming.impl.ConnectionPacketHandler
    class ConnectionPacketHandlerextends Object
    Receive a packet for a particular connection - placing the data onto the queue, marking packets as acked, updating various fields, etc.

    I2PSession -> MessageHandler -> PacketHandler -> ConnectionPacketHandler -> MessageInputStream

    One of these is instantiated per-Destination (i.e. per-ConnectionManager, not per-Connection). It doesn't store any state.

      • registerLiveStreamStats

        static void registerLiveStreamStats(StatManager sm)
        Register the live stream RTT and send-window stats.

        Separated from the constructor so a test can register against a fresh StatManager without building a whole handler — the same shape as ConnectionManager.registerRtxRatioStats(StatManager).

        Both are createRequiredRateStat because StatManager silently discards data for a name it was never told about. That failure mode is invisible from the console: the stat reads "not present" rather than wrong, which is how transport.banlistOnUsupportedSigType sat at zero through every signature-type banlisting.

        Parameters:
        sm - stat manager to register with, non-null

      • shouldSampleLiveStreamStats

        static boolean shouldSampleLiveStreamStats(int receiveMsgCount)
        Whether this received message is the one that samples the receive-side size stat and, from it, the live stream RTT and send window.

        One predicate for all three, because the live RTT and window are deliberately written inside the same block as the existing size sample: the cost stays two extra stat writes per sampled message rather than two per packet. Sharing the predicate is what stops the cadences drifting apart later — the mask alone would let a change to one silently leave the other per-packet.

        Pure predicate — no state, no router, safe for unit tests.

        Parameters:
        receiveMsgCount - monotonically increasing count of messages this handler has accepted, 1-based
        Returns:
        true when this message is a sampling point

      • caGrowthCredit

        static long caGrowthCredit(long accum, int effAcked, int caFactor, int windowSize)
        Credit increment for the deterministic congestion-avoidance ratchet. Accumulated in 16.16 fixed-point; each whole unit corresponds to one packet-in-flight increment on the congestion window.

        The expected value equals effAcked / (caFactor * windowSize), which is the probability that the old random gate would have incremented.

        Parameters:
        accum - the 16.16 fixed-point accumulator so far
        effAcked - effective number of packets ACKed this round
        caFactor - congestion-avoidance growth divisor
        windowSize - current congestion window
        Returns:
        the accumulator including this round's credit
