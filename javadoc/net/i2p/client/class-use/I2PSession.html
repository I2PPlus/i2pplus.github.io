    Packages that use I2PSession
    Package
    Description
    net.i2p.client
    Interfaces and factories for the base I2P SDK used to develop applications that communicate through I2P.
    net.i2p.client.datagram
    Provides a standard way for reading and writing messages transferred over I2P so that the recipient has an authenticated mechanism to reply to the sender.
    net.i2p.client.impl
    Internal implementation of the I2P client SDK - the client side of the Invisible Internet Client Protocol (I2CP), separating implementation from the interfaces in net.i2p.client.
    net.i2p.client.streaming
    API, interfaces, and factory for a TCP-like (reliable, authenticated, in order) set of sockets for communicating over IP-like (unreliable, unauthenticated, unordered) I2P messages.
    net.i2p.client.streaming.impl
    Implementation of a TCP-like (reliable, authenticated, in order) set of sockets for communicating over the IP-like (unreliable, unauthenticated, unordered) I2P messages.
    net.i2p.data
    Common data structures used by the I2P protocols: Destination, LeaseSet, PublicKey, Signature, Certificate and their friends.
    net.i2p.i2ptunnel
    Implementation of preconfigured tunnels for clients and servers, including special-purpose tunnels for IRC, SOCKS, HTTP and streaming.
    net.i2p.i2ptunnel.udp
    Datagram plumbing for UDP tunnels: sinks and sources that bridge a local UDP socket and an I2P stream, framing each datagram onto the stream and back.
    net.i2p.sam
    The SAM bridge: a simple text protocol server letting applications in any language use I2P streaming and datagram sessions without implementing the Invisible Internet Client Protocol (I2CP).
    org.klomp.snark
    I2P version of the Snark BitTorrent client, enhanced for I2P: peers are I2P destinations, torrents can be served anonymously as hidden services, and metadata carries I2P-specific comment fields.
    org.klomp.snark.dht
    BitTorrent distributed hash table (DHT) implementation following the Mainline protocol, for trackerless peer discovery.
