    public abstract class I2PSessionImplextends Object implements I2PSession, I2CPMessageReader.I2CPMessageEventListener
    Implementation of an I2P session running over TCP. This class is NOT thread safe - only one thread should send messages at any given time

    Public only for clearCache(). Except for methods defined in I2PSession and I2CPMessageEventListener, not maintained as a public API, not for external use. Use I2PClientFactory to get an I2PClient and then createSession().
