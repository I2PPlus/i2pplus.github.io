        public SessionIdleTimer(I2PAppContext context, I2PSessionImpl session, boolean reduce, boolean shutdown)
        Construct a timer that reduces, shuts down, or both.
        Parameters:
        context - the application context supplying the timer and the log manager
        session - the session whose i2cp options supply the idle thresholds and the reduction quantity
        reduce - if true, cut the session's tunnel quantity back after the idle time
        shutdown - if true, close the session after the idle time
