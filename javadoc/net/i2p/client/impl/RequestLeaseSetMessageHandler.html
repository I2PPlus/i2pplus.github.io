      • ensurePositiveLs2Expiry

        static long ensurePositiveLs2Expiry(long leaseEnd, long published, long now)
        Floor a requested lease end so it remains strictly after both the LS2 published timestamp (second resolution) and the current time, leaving at least MIN_LS2_LEASE_TTL_MS of validity. Without this, a stale or skewed end time makes LeaseSet2.writeHeader() throw "LeaseSet expired", and a floor measured only from a stale published stamp would hand out an already-expired set when the clock has moved on by sign time.
        Parameters:
        leaseEnd - absolute lease end from the router request
        published - LS2 published timestamp, or 0 for LS1 / unset
        now - current time when the floor is computed; the later of published and now sets the margin, so delay between publishing and signing does not shrink it
        Returns:
        leaseEnd if already safely after both instants, else max(published, now) + 1s

        Parameters:

        true if the set can be signed

      • validateLeaseSetRequest

        static String validateLeaseSetRequest(int endpoints, Date endDate)
        Validate a fixed-length LeaseSet request before any state is mutated. An empty request leaves LeaseSet2._expires at 0 and writeHeader would throw "LeaseSet expired"; more than LeaseSet.MAX_LEASES endpoints overflow addLease()'s cap and throw mid-build; a missing end date (0 on the wire) would NPE at msg.getEndDate().getTime(). One clear error keeps the publish floor and clock untouched on every reject.
        Parameters:
        endpoints - number of endpoints in the request
        endDate - requested end date, null when absent on the wire
        Returns:
        the error to propagate, or null if the request is valid

      • signLeaseSet

        protected boolean signLeaseSet(LeaseSet leaseSet, boolean isLS2, I2PSessionImpl session)
        Finish creating and signing the new LeaseSet and submitting it to the router. Reuses cached private keys when available, generates new keys otherwise, and handles offline signatures. Failures during signing are propagated to the session; transient expiry errors do not destroy the session so the router can retry with a fresh lease end time.
        Parameters:
        leaseSet - the unsigned LeaseSet with leases already added
        isLS2 - true for LS2, false for LS1
        session - the I2CP session requesting the LeaseSet
        Returns:
        true if the LeaseSet was signed and handed to the session, false if it was rejected or signing failed; callers use this to advance the monotonic publish floor only on success

      • scheduleSignRetry

        void scheduleSignRetry(I2CPMessage message, I2PSessionImpl session, int attempt)
        Schedule a prompt re-run of a request whose signing failed transiently. Without this, no CreateLeaseSet is sent and the router waits out its 60-second CheckLeaseRequestStatus before retrying. The re-run rebuilds the set against the current clock, so a skewed published stamp or stale lease end is corrected on the next attempt; attempts are bounded and the router's check timeout remains the fallback once they are exhausted.
        Parameters:
        message - the request to re-run
        session - the session the request is for
        attempt - the attempt number just completed (0 for the first)
