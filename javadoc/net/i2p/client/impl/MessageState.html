    net.i2p.client.impl.MessageState
    class MessageStateextends Object
    Contains the state of a payload message being sent to a peer.

    Originally was a general-purpose waiter. Then we got rid of guaranteed delivery. Then we stopped waiting for accept in best-effort delivery. Brought back to life for asynchronous status delivery to the client.

      • MessageState

        public MessageState(I2PAppContext ctx, long nonce, I2PSession session, long expires, SendMessageStatusListener listener)
        Track a sent message's delivery state for asynchronous notification.
        Parameters:
        ctx - the context supplying the clock and log used to time the wait and to report warnings
        nonce - the transaction nonce this message was sent under
        session - the session the message was sent through, also used as the log prefix
        expires - absolute time (not interval)
        listener - notified on each state change while the message has not yet expired
