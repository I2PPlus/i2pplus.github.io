    net.i2p.servlet.RequestWrapper
    public class RequestWrapperextends Object
    Wraps an HttpServletRequest and adds multipart-aware access to the parameters and files of a multipart/form-data request, using the Servlet 3.0 Part API. Only the multipart variants of the accessors are wrapped; everything else is passed straight through. The Servlet API container already parses multipart requests, so this class deliberately does not parse them again. A part larger than the 64KB MAX_STRING_SIZE limit is not read into a String, and an IllegalStateException from the container (which signals an oversized request) is logged and rethrown.
