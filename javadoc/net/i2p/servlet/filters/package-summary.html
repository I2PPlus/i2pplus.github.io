Package net.i2p.servlet.filters Description

Servlet filters for the I2P router console web application, providing authentication, session management, and security header enforcement.

This package contains:

  • AuthFilter - Request authentication and login enforcement
  • SameSiteCookieFilter - Adds SameSite=Lax to all cookies
  • SessionManager - In-memory session store with expiration and rate limiting

Since 0.9.14
