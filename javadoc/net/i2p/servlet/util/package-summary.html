Package net.i2p.servlet.util Description

Utility classes for servlet operations and HTTP request handling. Consolidated from i2psnark, susimail, and router console in 0.9.33.

This package provides common utilities used across multiple I2P web applications:

  • Request processing and validation
  • Response formatting and helpers
  • URL handling and encoding
  • Common HTTP operations
