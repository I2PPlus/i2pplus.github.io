    java.lang.Object
    net.i2p.crypto.SelfSignedGenerator
    public final class SelfSignedGeneratorextends Object
    Generate keys and a selfsigned certificate, suitable for storing in a Keystore with KeyStoreUtil.storePrivateKey(File, String, String, String, PrivateKey, List). All done programatically, no keytool, no BC libs, no sun classes. Ref: RFC 2459, RFC 5280

    This is coded to create a cert that is similar to what comes out of keytool.

    NOTE: Recommended use is via KeyStoreUtil.createKeys(File, String, String, String, String) and related methods. This API may not be stable.

      • skiOffset

        static int skiOffset(byte[] der)
        Index into a DER-encoded SubjectPublicKeyInfo where the SKI/AKI hash input begins, i.e. just past the outer SEQUENCE's tag and length.

        A DER length is short-form when the first length octet has bit 8 clear, and long-form otherwise, in which case that octet's low 7 bits are the number of following length octets - 1 or 2 in practice. Reading the flag bit instead of the count advanced the index by 128, so every DSA and RSA certificate hashed a window starting 127 bytes into the key instead of just past its header. Ed25519's 44-byte SPKI is short-form and was unaffected.

        Parameters:
        der - the DER-encoded SubjectPublicKeyInfo, at least 2 bytes long
        Returns:
        the offset the identifier is hashed from

        private static byte[] getExtensions(byte[] pubbytes, String cname, Set<String> altNames)
        Add the following extensions: 1) Subject Key Identifier 2) Key Usage 3) Basic Constraints 4) Subject Alternative Name As of 0.9.34, adds 127.0.0.1 and ::1 to the SAN also 5) Authority Key Identifier (not necessarily output in that order)

        Ref: RFC 5280.

        Parameters:
        pubbytes - the DER-encoded public key bit string the extension identifier is derived from
        cname - the common name, added to the SANs and used to decide if the cert is a CA
        altNames - the Subject Alternative Names. May be null. May contain hostnames and/or IP addresses. cname, localhost, 127.0.0.1, and ::1 will be automatically added.
        Returns:
        ASN.1 encoded object
