    Elliptic curve utility functions for cryptographic operations.

    This class provides essential mathematical operations for elliptic curve cryptography used throughout I2P, including scalar multiplication, point operations, and curve parameter handling. It supports multiple curve types with optimized implementations for common cryptographic operations.

    Key operations include:

    • Scalar multiplication of curve points
    • Point addition and doubling operations
    • Curve parameter validation and extraction
    • Support for standard NIST curves (P-192, P-256, P-384, P-521)
