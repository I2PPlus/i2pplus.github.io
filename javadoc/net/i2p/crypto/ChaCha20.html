      • _SCRATCH

        private static final ThreadLocal<int[][]> _SCRATCH
        Per-thread scratch pair: [0] is the input state block, [1] is the keystream block.

        Both arrays are strictly internal - they never escape encrypt(byte[], byte[], int, byte[], int, byte[], int, int), so no caller can retain or observe them, and a thread-confined instance is safe. Reentry is impossible: the only callees are ChaChaCore statics and DataHelper.fromLongLE(byte[], int, int), all of which are leaf code with no callbacks back into this class.

        This saves two 128-byte allocations per call; SSU2 protects 2-5 header blocks per packet and NTCP2/LS2 do the same per session.
