        PublicKey getKey(String keyName, String scope, SigType type) throws GeneralSecurityException, IOException
        Get a key. Throws on all errors.
        Parameters:
        keyName - the algorithm the key belongs to, such as ElGamal or ECDSA
        scope - a domain identifier, indicating router update, reseed, etc.
        type - the signature type the key is stored for
        Returns:
        null if none
