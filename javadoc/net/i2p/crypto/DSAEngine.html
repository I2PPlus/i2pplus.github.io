      • _sha1

        private static final ThreadLocal<MessageDigest> _sha1
        Thread-local SHA-1 digest for calculateHash(byte[], int, int) and calculateHash(InputStream), so that a DSA-SHA1 hash does not allocate a fresh SHA1 (a MessageDigestSpi plus a 64 byte pad) each time. Reset on every acquire and never handed outside this class, so there is no state that can leak between calls.

      • _sha512

        private static final ThreadLocal<MessageDigest> _sha512
        Thread-local SHA-512 digest for the EdDSA sign/verify paths, so that each operation does not clone a fresh MessageDigest off the SigType prototype. The engine resets it on every init, and it is never handed outside this class, so no state can leak between calls.
