    public interface ElGamalKey extends DHKey
    Base interface for ElGamal cryptographic keys used in I2P.

    ElGamal is a public-key cryptosystem used in I2P for encrypting session keys and messages. This interface defines the common contract for both ElGamal public and private keys, extending the standard DHKey interface for compatibility with Java's cryptographic architecture.

    Implementations include ElGamalPublicKey and ElGamalPrivateKey which provide the actual cryptographic operations for encryption and decryption.
