    package net.i2p.crypto.elgamal

    Implementation of the ElGamal public-key cryptosystem for I2P, copied from Bouncy Castle 1.53 and adapted for the I2P security provider. Provides the key and parameter interfaces and implementations used for the encryption layer of I2P messages.
