    Implementation of ElGamal private keys.

    This class provides a concrete implementation of the ElGamalPrivateKey interface, representing the private component of an ElGamal key pair. It stores the secret exponent x and the ElGamal parameters (prime p and generator g), and supports PKCS#8 encoding for standardized key storage and transmission.
