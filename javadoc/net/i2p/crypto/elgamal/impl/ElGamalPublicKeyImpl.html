    Implementation of ElGamal public keys.

    This class provides a concrete implementation of the ElGamalPublicKey interface, representing the public component of an ElGamal key pair. It stores the public value y = g^x mod p and the ElGamal parameters (prime p and generator g), and supports X.509 encoding for standardized key storage and transmission.
