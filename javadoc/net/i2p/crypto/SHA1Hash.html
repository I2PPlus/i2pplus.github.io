    public class SHA1Hashextends SimpleDataStructure
    I2P data structure for SHA-1 hash values.

    This class provides a SimpleDataStructure wrapper for 20-byte SHA-1 hashes used throughout I2P for data integrity and identification purposes. It extends SimpleDataStructure to support I2P's serialization framework and provides efficient caching of hash codes.

    Common uses include:

    • Router and destination identifiers
    • Message integrity verification
    • Data structure indexing and lookup
