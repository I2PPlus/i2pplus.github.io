    public enum EncTypeextends Enum<EncType>
    Defines the properties for various encryption types that I2P supports or may someday support.

    All PublicKeys and PrivateKeys have a type. Note that a EncType specifies both an algorithm and parameters, so that we may change primes or curves for a given algorithm.
