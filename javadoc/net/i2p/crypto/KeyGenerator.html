    net.i2p.crypto.KeyGenerator
    public final class KeyGeneratorextends Object
    Comprehensive key generation facility for I2P cryptographic operations.

    This class provides methods to generate various types of cryptographic keys used throughout the I2P network, including:

    • Asymmetric key pairs (ElGamal, DSA, ECDSA, EdDSA, RSA)
    • Symmetric session keys (AES)
    • Key derivation and conversion utilities

    Supports both legacy algorithms (DSA, ElGamal) and modern cryptographic schemes (EdDSA, ECDSA) with configurable parameters for security and performance optimization.
