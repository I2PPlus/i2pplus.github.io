      • loadCert

        public static X509Certificate loadCert(File kd) throws IOException, GeneralSecurityException
        Get the certificate from a X.509 certificate file. Throws if the certificate is invalid (e.g. expired).

        This does NOT check for revocation. This verifies the signature assuming the cert is self-signed. A non-self-issued (chain) cert that fails self-verification only logs a warning, as of 0.9.54; a self-issued cert with a bad signature throws. We do NOT fetch additional certs or attempt to validate a cert up the chain.

        Parameters:
        kd - the certificate file
        Returns:
        non-null, throws on all errors including certificate invalid
        Throws:
        IOException - if the file cannot be read
        GeneralSecurityException - if the certificate is invalid
