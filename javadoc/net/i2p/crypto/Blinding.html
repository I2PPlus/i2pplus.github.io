      • _hkdf

        private static volatile HKDF _hkdf
        Cached HKDF for generateAlpha(I2PAppContext, SigningPublicKey, String), which is called once per blinded destination. HKDF is stateless (it only holds the context, and the context's HMAC256Generator is itself thread-safe), so one instance per context is reusable and saves an allocation per call.

      • _hkdfCtx

        private static volatile I2PAppContext _hkdfCtx

    • Method Details

      • hkdf

        static HKDF hkdf(I2PAppContext ctx)
        Get the shared HKDF for a context. The cached instance is rebuilt if the context differs, so a non-global context never ends up using a HKDF bound to a different one. A racy double build is harmless, as both instances are equivalent.
        Parameters:
        ctx - the app context, non-null
        Returns:
        the shared HKDF, never null
        Throws:
        NullPointerException - if ctx is null
