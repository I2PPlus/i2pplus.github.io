net.i2p.crypto

Class HKDF

  • java.lang.Object
    • net.i2p.crypto.HKDF

  • public final class HKDF
extends Object
    HMAC-based Key Derivation Function (HKDF) implementation using HMAC-SHA256. This class implements the HKDF algorithm as specified in RFC 5869 for deriving cryptographic keys from input key material. It provides secure key expansion functionality essential for I2P's cryptographic operations including session key generation and key derivation.

    Features and capabilities:

    • HMAC-SHA256 based derivation for cryptographic security
    • Support for one or two output keys with optional info parameter
    • Thread-safe operation with no internal state
    • Fixed 32-byte output size for consistency across I2P
    • Reusable instances for performance optimization
    See Also:
    RFC 5869 - HKDF
