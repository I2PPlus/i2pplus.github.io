      • unblind

        public static EdDSAPrivateKey unblind(EdDSAPrivateKey key, EdDSAPrivateKey alpha)
        Unblind an EdDSA private key using alpha, the inverse of blind(EdDSAPrivateKey, EdDSAPrivateKey): subtracts alpha from the blinded scalar mod l. The recovered scalar is the original scalar reduced mod l; it yields the same public key point and signatures as the original.
        Parameters:
        key - must be SigType EdDSA_SHA512_Ed25519
        alpha - the same alpha used to blind the key
        Returns:
        the unblinded private key
