      • EdDSAPrivateKeySpec

        public EdDSAPrivateKeySpec(byte[] a, GroupElement aPoint, EdDSAParameterSpec spec)
        No validation of any parameters other than a. getSeed() and getH() will return null if this constructor is used.
        Parameters:
        a - must be "clamped" (for Ed) or reduced mod l (for Red); it is not validated - an invalid scalar silently yields a wrong public key. The array is copied, later changes by the caller have no effect.
        aPoint - if null, will be derived from a.
        spec - the domain parameters naming the curve and cofactor this key belongs to
