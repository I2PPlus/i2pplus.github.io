    Little-endian encoding implementation for EdDSA field elements using BigInteger.

    This class provides encoding and decoding operations for EdDSA field elements, converting between BigInteger values and their little-endian byte representations. It handles the specific encoding requirements for EdDSA operations including bit masking and constant-time conversions.
