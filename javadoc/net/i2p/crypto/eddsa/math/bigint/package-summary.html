    package net.i2p.crypto.eddsa.math.bigint

    Generic elliptic curve mathematical implementation using Java BigIntegers, serving as the reference implementation for curves without specialized optimizations. Used by Elligator2. For Curve25519 operations the optimized ed25519 implementation is used instead.
