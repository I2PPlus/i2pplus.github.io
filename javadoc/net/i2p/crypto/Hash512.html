Class Hash512

    DataStructure

    public class Hash512
extends SimpleDataStructure
    SHA-512 secure hash algorithm implementation. This class provides the SHA-512 hash algorithm as specified in FIPS PUB 180-4, producing a 64-byte (512-bit) message digest. SHA-512 offers the highest security level in the SHA-2 family with excellent performance characteristics.

    Common uses in I2P include:

    • Maximum security requirements for sensitive operations
    • Long-term cryptographic key derivation
    • Digital signatures with strongest hash protection
    • Integrity verification for critical system components
