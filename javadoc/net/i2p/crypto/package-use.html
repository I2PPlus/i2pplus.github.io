Search page
    Packages that use net.i2p.crypto
    Package
    Description
    com.southernstorm.noise.protocol
    Provides classes for communicating via the Noise protocol.
    gnu.crypto.prng
    Fortuna pseudo-random number generator from GNU Crypto, modified for I2P.
    net.i2p
    Core I2P package providing fundamental interfaces, version information, and entry points to essential I2P services, centered on I2PAppContext.
    net.i2p.client
    Interfaces and factories for the base I2P SDK used to develop applications that communicate through I2P.
    net.i2p.client.datagram
    Provides a standard way for reading and writing messages transferred over I2P so that the recipient has an authenticated mechanism to reply to the sender.
    net.i2p.client.impl
    Internal implementation of the I2P client SDK - the client side of the Invisible Internet Client Protocol (I2CP), separating implementation from the interfaces in net.i2p.client.
    net.i2p.client.streaming
    API, interfaces, and factory for a TCP-like (reliable, authenticated, in order) set of sockets for communicating over IP-like (unreliable, unauthenticated, unordered) I2P messages.
    net.i2p.client.streaming.impl
    Implementation of a TCP-like (reliable, authenticated, in order) set of sockets for communicating over the IP-like (unreliable, unauthenticated, unordered) I2P messages.
    net.i2p.crypto
    Core cryptographic primitives used throughout I2P: symmetric ciphers (AES, ChaCha20), hashes (SHA-1, SHA-256, SHA-384, SHA-512), HMAC and HKDF key derivation, the ElGamal and DSA/EdDSA/RedDSA engines, key and certificate utilities, and the entropy harvester.
    net.i2p.crypto.x25519
    X25519 elliptic curve Diffie-Hellman key exchange (RFC 7748), wrapping Noise's Curve25519 operations with Java Security API parameter specifications.
    net.i2p.data
    Common data structures used by the I2P protocols: Destination, LeaseSet, PublicKey, Signature, Certificate and their friends.
    net.i2p.data.i2cp
    The Invisible Internet Client Protocol (I2CP) allows applications simplified access to I2P network without requiring them to deal with the issues involved with the Invisible Internet Network Protocol (I2NP).
    net.i2p.data.i2np
    Low-level messages sent between routers - the Invisible Internet Network Protocol (I2NP).
    net.i2p.i2ptunnel
    Implementation of preconfigured tunnels for clients and servers, including special-purpose tunnels for IRC, SOCKS, HTTP and streaming.
    net.i2p.router
    The I2P router application handles I2P network communication.
    net.i2p.router.client
    Router-side implementation of the Invisible Internet Client Protocol (I2CP): client sessions over plain or TLS sockets, message delivery, and lease and tunnel management on behalf of clients.
    net.i2p.router.crypto
    Router-specific cryptography: ElGamal+AES garlic encryption (ElGamalAESEngine), session key and tag caching for repeated peer communication (TransientSessionKeyManager), router-family shared keys (FamilyKeyCrypto), and the ratchet and pqc subpackages.
    net.i2p.router.crypto.pqc
    Post-quantum hybrid key encapsulation built on the bundled Bouncy Castle ML-KEM primitives.
    net.i2p.router.crypto.ratchet
    The Double Ratchet with X25519 key agreement and ECIES hybrid encryption, used by the NTCP2 and SSU transports for session encryption.
    net.i2p.router.dummy
    Simplified fake implementations of router interfaces (comm system and friends) for testing and embedded builds.
    net.i2p.router.message
    Garlic message creation, parsing and handling, and the outbound message jobs: one-shot sends, source routing and delivery status handling.
    net.i2p.router.networkdb.kademlia
    The Kademlia distributed hash table (DHT) network database: lookup, store and explore jobs, the data store, the floodfill variants, and lookup throttling.
    net.i2p.router.startup
    The I2P startup package loads configuration when I2P is started.
    net.i2p.router.transport.crypto
    Transport-layer key agreement: the X25519 key factory used by the NTCP2 and SSU2 session handshakes for peer authentication and session encryption.
    net.i2p.router.transport.ntcp
    NTCP2, the TCP transport: framed, ratchet-encrypted and mutually authenticated connections between routers.
    net.i2p.router.transport.udp
    SSU2, the UDP transport: datagram sessions with Holepunch peer discovery, plus the older SSU compatibility code.
    net.i2p.router.tunnel.pool
    Tunnel pool management: pool lifecycle, peer selection, build scheduling and failure handling for client and exploratory tunnels.
    net.i2p.router.web.helpers
    Helpers and handlers for the router console user interface, packaged in routerconsole.war and accessible only from JSP files.
    net.i2p.sam
    The SAM bridge: a simple text protocol server letting applications in any language use I2P streaming and datagram sessions without implementing the Invisible Internet Client Protocol (I2CP).
    net.i2p.util
    General utility classes shared across the core libraries and the router.
    org.klomp.snark
    I2P version of the Snark BitTorrent client, enhanced for I2P: peers are I2P destinations, torrents can be served anonymously as hidden services, and metadata carries I2P-specific comment fields.
    org.klomp.snark.dht
    BitTorrent distributed hash table (DHT) implementation following the Mainline protocol, for trackerless peer discovery.
