net.i2p.crypto

Class SigUtil

  • java.lang.Object
    • net.i2p.crypto.SigUtil

  • public final class SigUtil
extends Object
    Comprehensive utility class for I2P signing keys and digital signatures. This class provides essential methods for converting between I2P's native key formats and standard Java cryptographic key representations, as well as utilities for signature encoding/decoding and key validation.

    Key functionalities include:

    • Conversion between I2P and Java key formats
    • Support for DSA, ECDSA, EdDSA, and RSA algorithms
    • ASN.1 signature encoding and decoding
    • Key validation and rectification
