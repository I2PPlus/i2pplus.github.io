    net.i2p.crypto.SigUtil
    public final class SigUtilextends Object
    Comprehensive utility class for I2P signing keys and digital signatures.

    This class provides essential methods for converting between I2P's native key formats and standard Java cryptographic key representations, as well as utilities for signature encoding/decoding and key validation.

    Key functionalities include:

    • Conversion between I2P and Java key formats
    • Support for DSA, ECDSA, EdDSA, and RSA algorithms
    • ASN.1 signature encoding and decoding
    • Key validation and rectification

      • sigBytesToASN1

        private static byte[] sigBytesToASN1(byte[] sig)
        Encode raw signature bytes (r || s) into ASN.1 DER SEQUENCE format.

        See Standard Algorithm Names

        Convert to BigInteger and back so we have the minimum length representation, as required. r and s are always non-negative.

        Only supports sigs up to about 252 bytes. See code to fix BER encoding for this before you add a SigType with bigger signatures.

        Parameters:
        sig - raw r||s bytes, length must be even
        Returns:
        ASN.1 DER-encoded SEQUENCE { r INTEGER, s INTEGER }
        Throws:
        IllegalArgumentException - if length is odd or encoded size exceeds limits

      • sigBytesToASN1

        public static byte[] sigBytesToASN1(BigInteger r, BigInteger s)
        Encode two BigInteger values (r, s) into an ASN.1 DER SEQUENCE of two INTEGER values. r and s are always non-negative.

        Only supports sigs up to about 65530 bytes. See code to fix BER encoding for this before you add a SigType with bigger signatures.

        The output is an ASN.1 DER SEQUENCE of two INTEGER values, r and s, in that order:

         SEQUENCE ::= { r INTEGER, s INTEGER }

 30 -- tag indicating SEQUENCE
 xx - length in octets

 02 -- tag indicating INTEGER
 xx - length in octets
 xxxxxx - value
        Parameters:
        r - non-negative
        s - non-negative
        Returns:
        ASN.1 DER-encoded SEQUENCE { r INTEGER, s INTEGER }
        Throws:
        IllegalArgumentException - if too big
        See Also:
        • Java Cryptography Architecture Standard Algorithm Name Documentation
        • Abstract Syntax Notation One
