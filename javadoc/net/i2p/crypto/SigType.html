    public enum SigTypeextends Enum<SigType>
    Defines the properties for various signature types that I2P supports or may someday support.

    All Signatures, SigningPublicKeys, and SigningPrivateKeys have a type. Note that a SigType specifies both an algorithm and parameters, so that we may change primes or curves for a given algorithm.

      • getDigestInstance

        public MessageDigest getDigestInstance()
        A private, unshared MessageDigest instance for this signature type, in its initial state.

        A MessageDigest is stateful and not thread safe, so the prototype is never returned directly; it is cloned on every call. Cloning skips the JCA provider lookup (algorithm string hashing plus provider list scanning) that MessageDigest.getInstance(String) performs, and the clone shares no state with the prototype or with any other clone.

        Returns:
        a new digest instance owned by the caller
        Throws:
        UnsupportedOperationException - if not supported
