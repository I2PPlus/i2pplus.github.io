net.i2p.router

Class JobStats

  • java.lang.Object
    • net.i2p.router.JobStats

  • public class JobStats
extends Object
    Collects and maintains statistical data for job execution performance. Tracks run counts, execution times, drop rates, and pending time metrics for job queue monitoring and optimization. Public for router console only. For use by the router only. Not to be used by applications or plugins.
