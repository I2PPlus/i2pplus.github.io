Class Tuner

    Runnable

    public class Tuner
extends SimpleTimer2.TimedEvent
    General-purpose adaptive tuner. Observes network and system stats, adjusts tunable parameters to optimize router performance.

    Runs every 5 seconds via SimpleTimer2. Each tick samples transport worker-stage CPU and updates the transport thread pool params; every 15th-second tick runs the full cycle for all other params. Each parameter implements an AIMD-style feedback loop bounded within safe ranges:

    1. Read observed stat (60s rolling average)
    2. Compute target value from observed stat + cross-references
    3. Clamp target to [min, max]
    4. Apply health-based dampening when system is degraded
    5. Accelerate rollback when param diverges from default
    6. Call applyValue() to push the new value to the router

    New parameters are added by extending Tuner.BaseParam and implementing:

    • applyValue(int) — push value to router subsystem
    • getRuntimeValue() — read current value from subsystem
    • getObservedStat(RouterContext) — read primary signal
    • computeTarget(double) — feedback logic with cross-refs

    Params can be tuned live via the console UI or persisted to autotune.config (separate from router.config). Auto-revert to factory defaults triggers when system health drops below 0.3.
