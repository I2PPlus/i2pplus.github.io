      • createRouterInfo

        RouterInfo createRouterInfo()
        Writes 6 files: router.info (standard RI format), router.keys.dat, and 4 individual key files under keyBackup/

        router.keys.dat file format: This is the same "eepPriv.dat" format used by the client code, as documented in PrivateKeyFile.

        Old router.keys file format: Note that this is NOT the same "eepPriv.dat" format used by the client code.

         - Private key (256 bytes)
 - Signing Private key (20 bytes)
 - Public key (256 bytes)
 - Signing Public key (128 bytes)
 Total 660 bytes

        Caller must hold Router.routerInfoFileLock.

        Returns:
        the created RouterInfo, or null on failure
