      • buildRows

        static List<String[]> buildRows(Map<ClientApp, String[]> clients, Map<String, ClientApp> registered)
        Merge the tracked and registered app maps into one row set of {state, name, class, args}, sorted by name. Tracked apps report their live state and launch args; registered apps that were never tracked report "Registered" with no args. Pure, for unit tests.
        Parameters:

        Returns:
        one row per app, never null
