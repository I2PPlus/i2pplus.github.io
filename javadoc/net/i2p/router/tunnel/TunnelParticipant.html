    net.i2p.router.tunnel.TunnelParticipant
    class TunnelParticipantextends Object
    Participates in a tunnel at an intermediate hop (not gateway or endpoint). Handles message dispatching, bandwidth throttling, fragment reassembly, and next-hop routing.

    Optimized for hosting many tunnels efficiently.
