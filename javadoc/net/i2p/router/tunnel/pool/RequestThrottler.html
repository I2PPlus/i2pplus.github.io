net.i2p.router.tunnel.pool

Class RequestThrottler

  • java.lang.Object
    • net.i2p.router.tunnel.pool.RequestThrottler

  • public class RequestThrottler
extends Object
    Throttles incoming tunnel requests earlier than ParticipatingThrottler, with higher limits and more frequent cleanup. Checks various router characteristics and decides whether to throttle, ban, or disconnect routers based on request count, version, bandwidth, and system load.
