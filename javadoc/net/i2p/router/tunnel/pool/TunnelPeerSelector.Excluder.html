      • _activityWindow

        private final long _activityWindow
        Activity window in ms, computed once per Excluder construction. TunnelPeerSelector.getActivityWindow(RouterContext, double) calls countActivePeers(), which scans every non-failing profile under a read lock; recomputing it per candidate made selection O(candidates × peers). It is constant for one selection.

      • _allowNoSignal

        private volatile boolean _allowNoSignal
        When true, the no-signal check in TunnelPeerSelector.getExclusionReason(Hash, boolean, boolean, double, long) is skipped, allowing untested peers to be considered for tunnel builds. Set by relaxNoSignalExclusions() when peer scarcity demands it.

      • relaxNoSignalExclusions

        int relaxNoSignalExclusions()
        Relax no-signal exclusions under peer scarcity: remove all peers previously excluded for "no-signal" from the underlying set, and set a flag so future contains() calls skip the no-signal check. This allows untested peers to be considered as tunnel candidates when we can't build tunnels due to insufficient proven peers.
        Returns:
        number of peers un-excluded
