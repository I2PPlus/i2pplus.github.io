    • Field Details

      • EPS_ALL_BANNED_STAT

        static final String EPS_ALL_BANNED_STAT
        Counts selections discarded because every candidate was banlisted.

        Exists to keep the discard branch above honest. The change that replaced restoring the banned selection with discarding it was originally justified by a build-capacity figure that no measurement supported, and the branch then recorded 0 occurrences over roughly two hours. Rather than re-assert a benefit, this counter makes the frequency observable so the branch can be re-evaluated on evidence.

        Must be created before use: StatManager.addRateData on an unregistered name silently drops the sample.

        public List<Hash> selectPeers(TunnelPoolSettings settings)
        Returns ENDPOINT FIRST, GATEWAY LAST!!!! In: us .. closest .. middle .. IBGW Out: OBGW .. middle .. closest .. us.
        Specified by:
        selectPeers in class TunnelPeerSelector
        Parameters:
        settings - the tunnel pool settings
        Returns:
        ordered list of Hash objects (one per peer) specifying what order they should appear in a tunnel (ENDPOINT FIRST). This includes the local router in the list. Never null; an empty list means no peers could be selected.
