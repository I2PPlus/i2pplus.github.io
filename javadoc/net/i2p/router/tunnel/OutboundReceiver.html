    TunnelGateway.Receiver
    class OutboundReceiverextends Object implements TunnelGateway.Receiver
    We are the outbound gateway - we created this outbound tunnel. Receive the outbound message after it has been preprocessed and encrypted, then forward it on to the first hop in the tunnel.

    Not used for zero-hop OBGWs.
