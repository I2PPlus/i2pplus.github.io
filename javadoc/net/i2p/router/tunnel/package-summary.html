    package net.i2p.router.tunnel

    Tunnel messages and the tunnel layer: the TunnelManagerFacade, tunnel build request and reply processing, and the inbound and outbound tunnel structures.

    TunnelDispatcher routes each message to the processor for the router's role in the tunnel - inbound gateway or endpoint, outbound gateway or endpoint, or middle hop. Not for use by apps, clients or plugins.
