Class DevSU3UpdateHandler

  • java.lang.Object
    • net.i2p.router.update.DevSU3UpdateHandler
  • All Implemented Interfaces:
    Checker, Updater

    class DevSU3UpdateHandler
extends Object
implements Checker, Updater

    Handles the request to update the router by firing off an EepGet call to download the latest su3 file and display the status.

    After the download completes the su3 is verified, and the zip is extracted and copied to the router directory, and if configured the router is restarted to complete the update process.
