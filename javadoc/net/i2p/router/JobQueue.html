net.i2p.router

Class JobQueue

  • java.lang.Object
    • net.i2p.router.JobQueue

  • public class JobQueue
extends Object
    Prioritizes and executes router jobs with preference for earlier scheduled tasks. Manages job queues, timing, and thread pool execution for router-internal operations only. For use by the router only. Not to be used by applications or plugins.
