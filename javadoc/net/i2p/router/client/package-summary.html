Package net.i2p.router.client Description

Router-side implementation of the I2CP (I2P Client Protocol) interface for application integration.

This package implements the router side of the I2CP interface, which provides the standard API for applications to communicate through the I2P network. The I2CP protocol allows external applications to create destinations, manage tunnels, send and receive messages, and access I2P services without implementing the full router functionality.

Key Components:

  • ClientManager - Manages client connections and sessions
  • ClientConnectionRunner - Handles individual client connections
  • ClientListenerRunner - Accepts and manages new client connections
  • ClientWriterRunner - Writes and formats I2CP messages
  • ClientMessageEventListener - Handles client message events
  • LeaseRequestState - Manages lease requests for clients
  • I2CPMessageQueueImpl - Message queue implementation for client protocol
  • CreateSessionJob - Handles session creation requests
  • RequestLeaseSetJob - Manages lease set requests

Main Functionality:

  • I2CP protocol implementation and message handling
  • Client connection management and authentication
  • Destination creation and management for clients
  • Tunnel creation and management on behalf of clients
  • Message routing between clients and the network
  • Session management and configuration
  • LeaseSet management and renewal
  • Client statistics and monitoring

I2CP Message Types:

  • CreateSession - Establishes new client session
  • DestroySession - Terminates client session
  • RequestLeaseSet - Requests tunnel leases
  • SendMessage - Sends messages through I2P
  • ReceiveMessage - Delivers messages to clients
  • RequestVariableLeaseSet - Manages variable tunnel leases

Usage Notes:

  • Provides the standard interface for I2P applications
  • Client side implementation is in net.i2p.client
  • Essential for application integration with I2P
  • Supports both streaming and datagram communication
