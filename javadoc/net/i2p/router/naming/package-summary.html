    package net.i2p.router.naming

    The router's default naming service, BlockfileNamingService, backed by the Metanotion BlockFile database (net.metanotion) in hostsdb.dat. Resolves hosts.txt and subscription-supplied names to destinations. Registered with the router by the addressbook webapp.
