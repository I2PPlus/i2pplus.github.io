net.i2p.router.message

Class GarlicMessageBuilder

  • java.lang.Object
    • net.i2p.router.message.GarlicMessageBuilder

  • public class GarlicMessageBuilder
extends Object
    Static methods to build GarlicMessages from a GarlicConfig, for both ElGamal/AES and ECIES (X25519 + PQ) encryption schemes. All methods are stateless and thread-safe.
