net.i2p.router.message

Class CloveSet

  • java.lang.Object
    • net.i2p.router.message.CloveSet

  • public class CloveSet
extends Object
    The unwrapped result of decrypting a GarlicMessage: an array of GarlicCloves plus the outer certificate, message ID, and expiration. For ElGamal-encrypted messages the certificate/ID/expiration are serialized inside the clove set; for ECIES-encrypted messages they are synthesized with Certificate.NULL_CERT at construction time.
