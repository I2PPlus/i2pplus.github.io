        Create a new success job that will be fired when the message encrypted with the given session key and bearing the specified tags are confirmed delivered. This is only instantiated if we are expecting a reply.
        Parameters:
        key - may be null
        tags - may be null
        ls - the delivered leaseset or null
        timeout - will be cancelled when this is run, may be null
