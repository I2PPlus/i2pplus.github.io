    static final class Tuner.ThreadCpuTableextends Object
    Thread-id keyed sample state for Tuner.sampleStageCpu(): per live thread, which Tuner.CPU_STAGES entry its name matched and the CPU nanoseconds recorded at the previous sample.

    Open addressed with linear probing. Entries are never deleted one by one: a cycle republishes the still-live ids into a spare table and swaps it in, so a dead thread's stage and baseline leave together.

    • Method Details

      • beginCycle

        void beginCycle(long[] ids, int count)
        Start a sample cycle: carry stage and CPU baseline forward for the given live thread ids and make them the table's contents.

        An id the previous generation did not hold enters UNRESOLVED with NO_CPU; an id no longer reported drops out. A reused id whose predecessor was still live one cycle ago does carry a stale entry forward — Tuner.sampleStageCpu() spots it as a backwards CPU counter and resets the stage.

        Parameters:
        ids - live thread ids from the MXBean
        count - number of valid entries in ids
