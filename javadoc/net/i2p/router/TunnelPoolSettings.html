      • getAllowZeroHop

        public boolean getAllowZeroHop()
        If there are no tunnels to build with, will this pool allow 0 hop tunnels?

        As of 0.9.44, same goes for exploratory: Prior to 0.9.35, generally true for client. As of 0.9.35, generally false for client, but true if getLength() + min(getLengthVariance(), 0) <= 0, OR if getLengthOverride() == 0.

        Returns:
        the allow zero hop

        Returns:

      • getIPRestriction

        public int getIPRestriction()
        How many bytes to match to determine if a router's IP is too close to another's to be in the same tunnel (1-4, 0 to disable)

        Support removed in the ClientPeerSelector in 0.8.6; restored in 0.9.53.

        Returns:
        0-4 Number of bytes to match to determine if peers in the same IP range should not be in the same tunnel. 0 = disable check; 1 = /8; 2 = /16; 3 = /24; 4 = exact IP match
