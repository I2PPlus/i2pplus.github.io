net.i2p.router.web

Class ContentOnly

  • java.lang.Object
    • net.i2p.router.web.ContentOnly

  • public class ContentOnly
extends Object
    Per-request utility for the opt-in console fragment mode. When a page is requested with a contentonly request parameter, only the named elements are rendered and the shared head/sidebar chrome is skipped, so auto-refresh ticks transfer and parse a fraction of the full page. Full-page requests (no contentonly parameter) are unaffected. Pages opt in by gating each refresh target with render(HttpServletRequest, String); the chrome guards in head.jsi and sidebar.jsi are shared by every console page.
