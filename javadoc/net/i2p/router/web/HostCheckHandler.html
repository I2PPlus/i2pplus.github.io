      • originAllowed

        static boolean originAllowed(String origin, String hostHeader, boolean secure)
        Decide whether an Origin header is acceptable for a request to the given Host header. Same-origin is allowed, as is a request where both sides are loopback and the ports match; anything else is rejected.

        Both sides are compared as literal text. Neither header is ever resolved through DNS: a hostname whose A record points at 127.0.0.1 (DNS rebinding) is not loopback here, which is what keeps the localhost allowance from becoming a CSRF bypass. Resolving attacker-supplied host names on the request thread would also hand a slow or hostile resolver control of the Jetty thread pool.

        Parameters:
        origin - the Origin header value, null or empty for a same-origin form POST that carries no Origin
        hostHeader - the Host header value, "host" or "host:port", IPv6 addresses bracketed
        secure - true when the request arrived over TLS, used only for the default port when the Host header omits one
        Returns:
        true if the request is allowed
