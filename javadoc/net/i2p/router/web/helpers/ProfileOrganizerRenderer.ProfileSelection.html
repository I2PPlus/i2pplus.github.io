    private static class ProfileOrganizerRenderer.ProfileSelectionextends Object
    The sorted peer set, hidden-stale count, hide window, and pre-computed tier snapshots from ProfileOrganizerRenderer.loadProfiles(int). The tier sets are local copies taken under the organizer read lock once, so renderers and comparators can use contains() without acquiring any locks.
