      • METRIC_STATS

        private static final Map<String,String[]> METRIC_STATS
        Maps each Tuner subsystem metric identifier (as reported by Tuner.SubsystemScore.details) to the stat that backs it and a value format, so ring tooltips can show live values. Metrics with no backing stat are absent and omitted from the tooltip - a bare identifier without a value tells the reader nothing.

        Format is one of: "ms" (duration average), "pct" (0-100 average), "pct1000" (per-mille average), "count" (events in the last minute), "num" (plain average).

      • metricDetails

        private String[] metricDetails(String[] metrics)
        Resolve a subsystem's metric identifiers to tooltip lines carrying each stat's live value, e.g. "jobQueue.jobLag: 12ms". Metrics with no mapping or no stat are skipped. Returns null when nothing resolves, so the ring simply gets no tooltip instead of an identifier list.
        Parameters:
        metrics - the metric identifiers from the subsystem score, may be null
        Returns:
        tooltip lines, or null if none resolve
