      • statLabel

        static String statLabel(String statName)
        The short name shown beside a stat's checkbox on the configstats page.

        An ordinary stat name is a dotted subsystem path such as tunnel.buildTimeout, and the subsystem is dropped because the section header already states it. A pool's rates are named for the tunnel instead: [harry.i2p] InBps. The first dot there sits inside the name, and cutting at it turned four different services into four identical "i2p] InBps" labels. A prefix carrying a bracket or a space is therefore a name rather than a subsystem, and is shown whole.

        Parameters:
        statName - the stat name, or null
        Returns:
        the display label, never null; null yields the empty string

      • abbreviate

        private static String abbreviate(String label)
        Shorten a stat name to what fits beside its checkbox.

        The rules are ordered rather than alphabetical: receive rewrites to RX, which the later RXBps rule expands again to ReceiveBps, so the chain may not be reordered. Every rule names a stat actually seen on the page. The dotted rules only ever see a name whose subsystem prefix was dropped, a pool name with a dot in it having been returned whole by statLabel(String).

        Parameters:
        label - a stat name, with any subsystem prefix already removed
        Returns:
        the abbreviated label, never null
