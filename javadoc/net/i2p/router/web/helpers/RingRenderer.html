    Reusable SVG ring chart generator for health-ring dashboards. Produces inline SVG markup compatible with the ring CSS in shared.css.

        Render a ring with an explicit color class override. When forcedColor is non-null it is used for the arc/text/plot color instead of the score-derived class (used by MODE_ANOMALY, where color reflects deviation from baseline rather than the raw fill level).

        score - 0.0–1.0 fill level, or < 0 for "collecting" (gray)

        mode - color mode, one of the MODE_* constants
        history - recent data points for sparkline, or null to omit

        forcedColor - explicit CSS class ("green"/"yellow"/"red"/"gray"), or null
        Returns:
        inline SVG markup
