    net.i2p.router.web.helpers.NetDbHelper
    public class NetDbHelperextends FormHandler
    Helper for network database page rendering and form processing. Handles router information searches, filtering, and display operations. Integrates with NetDbRenderer and SybilRenderer for output generation. Extends FormHandler for form submission handling since 0.9.38.
