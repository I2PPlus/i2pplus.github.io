      • closedStreamRateBps

        static double closedStreamRateBps(double avgBytesPerConn, double avgLifetimeMs)
        Convert a byte-count stat's average value and average duration into a bytes/sec rate. The stream lifetime byte stats record each closed connection's total bytes weighted by its lifetime, so avgValue/avgDuration is the mean throughput of the streams that closed in the window. Streams that never close report nothing.
        Parameters:
        avgBytesPerConn - average lifetime bytes per closed connection
        avgLifetimeMs - average closed-connection lifetime in ms
        Returns:
        the average rate in bytes/s, 0 when either input is missing
