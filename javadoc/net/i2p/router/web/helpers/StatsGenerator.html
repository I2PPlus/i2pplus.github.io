      • downloadName

        static String downloadName(String name)
        The download filename offered for a stat's XML export.

        Stat names carry dots, spaces and, for a per-tunnel stat, brackets around a user-supplied nickname, all of which landed in the download attribute verbatim, so a nickname holding a double quote closed the attribute early. Dots and spaces become underscores and anything HTML-significant is escaped; a plain name such as bw.sendRate still reads graphdata_bw_sendRate.xml.

        Parameters:
        name - the stat name as registered
        Returns:
        a filename safe inside a quoted HTML attribute
