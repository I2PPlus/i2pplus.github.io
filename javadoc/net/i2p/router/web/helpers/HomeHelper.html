  • java.lang.Object
    • net.i2p.router.web.HelperBase
      • net.i2p.router.web.helpers.HomeHelper

  • public class HomeHelper
extends HelperBase
    Helper for router console home page and configuration. Renders main dashboard with service links, favorites, monitoring, and quick access to router management features. Supports both /home and /confighome pages.
