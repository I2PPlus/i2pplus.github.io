      • hideUnreachable

        private Collection<App> hideUnreachable(Collection<App> apps)
        Drop sites that are gone from the Sites of Interest listing.

        Applies only to the favourites shown on the home and sitemap pages. The config table is left complete so a link that is merely down can still be seen and removed.

        A site is dropped when the naming service cannot resolve it, or when the addressbook checker's last probe of it failed. A site that resolves but has not been probed yet is kept, so a cold results file does not empty the page. Links that are not I2P names - clearnet, and the console's own paths - are never dropped, since neither source can judge them.

        Parameters:
        apps - the configured links
        Returns:
        those that should still be shown
