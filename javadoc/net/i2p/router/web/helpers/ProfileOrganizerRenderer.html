      • loadProfiles

        private ProfileOrganizerRenderer.ProfileSelection loadProfiles(int mode)
        Load, filter, and sort the profiles for the given mode. Modes 1 and 2 drop peers that do not match the tier. Mode 3 keeps all peers in binary hash order. Modes 0-2 hide inactive peers not heard from within a cutoff that scales with the candidate count (4h above 500, 2h above 1000, 1h above 2000, 30m above 3000, 15m above 4000, 10m above 5000) to keep the displayed table manageable; mode 3 has no cutoff.
        Parameters:
        mode - 0 = all; 1 = fast; 2 = high capacity (non-fast); 3 = floodfill
        Returns:
        the sorted set, the hidden-stale profile count, and the hide window (zero for mode 3)

        Exclude ourself and profiles never heard from. With requireTunnelHistory, also exclude profiles that have never participated in a tunnel build (neither agreed to nor rejected a build request).
        Parameters:

        peer - the candidate peer's hash
        us - our own router hash, never valid
        requireTunnelHistory - true for modes 0-2, false for mode 3
        Returns:
        true if the peer is not us and has been heard from, and when requireTunnelHistory is set also has tunnel build history

        private void renderProfileRings(Writer out, int mode, ProfileOrganizerRenderer.ProfileSelection sel) throws IOException
        Render the profile summary rings above the profile table: eight rings per page.
