      • getAnomaly

        private HealthHelper.Anomaly getAnomaly(String name, double greenThreshold)
        Evaluate a stat against the router's own baseline (10m and 1h averages). A value near the router's normal range is green. Progressively larger deviations go yellow then red. When no baseline can be formed yet the result is "gray" (collecting) with a null detail.

        When the current value is at or below greenThreshold the result is unconditionally green — the absolute value is so small it cannot reasonably be called a regression even if the baseline is even smaller.

        Parameters:
        name - stat name (e.g. "udp.avgRTO")
        greenThreshold - absolute value below which the result is always green (0 to disable)
        Returns:
        anomaly result with color class and a human-readable detail line

      • bwUtilization

        static double bwUtilization(double sendBps, double recvBps, int inLimit, int outLimit)
        Bandwidth utilization: the worst of the two directions, each measured against its own cap, so a saturated outbound link reads 100% even with an idle inbound one. A direction with a 0 cap (unlimited) contributes 0.
        Parameters:
        sendBps - current send rate in bytes/s
        recvBps - current receive rate in bytes/s
        inLimit - inbound cap in bytes/s, 0 for unlimited
        outLimit - outbound cap in bytes/s, 0 for unlimited
        Returns:
        utilization 0.0-1.0+, may exceed 1.0 when over cap
