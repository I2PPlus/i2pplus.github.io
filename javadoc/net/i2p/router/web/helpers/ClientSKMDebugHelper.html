    net.i2p.router.web.helpers.ClientSKMDebugHelper
    public class ClientSKMDebugHelperextends Object
    Renders every client ratchet session key manager as one table, with a thead/tbody/tfoot section per client as on the update manager page, so the columns align across all clients. Inbound tag sets, outbound sessions and outbound tag sets share the column grid. Cells that do not apply to a row's kind show an em-dash. The tfoot carries the client's session counters. Clients whose SKM has no ratchet part (plain ElGamal) keep their own tag-status rendering below the table.

      • peerRenderer

        private static java.util.function.Function<String,String> peerRenderer()
        Turns a base64 key-hash cell into a destination reference: the peer of a client session is a destination, never a router, so no router-info markup (flag, bandwidth) applies and there is nothing to look up. Shows the short hash with the full hash as title. Falls back to the label itself when it is not a hash (e.g. the "null" key).
        Returns:
        a function mapping the cell text to html

        Build one thead/tbody/tfoot section. The title is pre-escaped html. The cell at peerCol is passed through peerRenderer (trusted html, e.g. a router-info reference) instead of being escaped. Package-visible for testing.

        title - the client title html

        columns - the translated header row html
        peerCol - index of the peer column, or -1 for none
        peerRenderer - renders the peer cell html, or null to escape it
        Returns:
        the section html, never null
