Class GraphHelper

  • java.lang.Object
    • net.i2p.router.web.FormHandler
      • net.i2p.router.web.helpers.GraphHelper

  • public class GraphHelper
extends FormHandler
    Renders the graphs list (/graphs.jsp) and the single-stat page (/graph.jsp), plus the graph display configuration form. Stateless across requests except for per-request form state set via the setXxx() accessors; preferences are read from context properties.
