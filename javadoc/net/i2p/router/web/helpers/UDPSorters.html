    • Method Details

      • getComparator

        static Comparator<PeerState> getComparator(int sortFlags)
        Select the comparator for a column, reversing it for a descending sort.
        Parameters:
        sortFlags - one of the FLAG_ columns in this class; the magnitude picks the comparator and the sign sets the direction
        Returns:
        comparator ordering PeerState by that column, or descending if sortFlags is negative; FLAG_ALPHA is the fallback

      • appendSortLinks

        static void appendSortLinks(StringBuilder buf, String urlBase, int sortFlags, String descr, int ascending)
        Append the pair of sort arrows for one column, marking the live direction of a column that is currently sorted on.
        Parameters:
        buf - buffer receiving the spans and anchors
        urlBase - page path the links point at, without a query string; this appends the "?transport=ssu&sort=N" part
        sortFlags - column and direction currently in effect, as passed to getComparator(int)
        descr - localized link title, used for both arrows
        ascending - column this control toggles; FLAG_ALPHA (0) emits a single descending link instead of a toggle
