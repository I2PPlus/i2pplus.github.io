    net.i2p.router.web.helpers.NetDbRenderer
    class NetDbRendererextends Object
    Renders the network database (netdb) information for the router console. Handles router and leaseset listings, search, and statistics. Optimized for performance with parallel rendering and optional reverse DNS lookups.

        mtu - optional MTU value to filter routers
