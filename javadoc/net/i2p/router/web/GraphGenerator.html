net.i2p.router.web

Class GraphGenerator

  • java.lang.Object
    • net.i2p.router.web.GraphGenerator
  • All Implemented Interfaces:
    Runnable, ClientApp

    public class GraphGenerator
extends Object
implements Runnable, ClientApp
    A thread started by RouterConsoleRunner that checks the configuration for stats to be tracked via jrobin, and adds or deletes RRDs as necessary. This also contains methods to generate xml or graph image output. The rendering for graphs is in GraphRenderer. To control memory, the number of simultaneous renderings is limited.
