      • getString

        public static String getString(String s, Object o, I2PAppContext ctx)
        Translate a string with a parameter This is a lot more expensive than getString(s, ctx), so use sparingly.
        Parameters:
        s - string to be translated containing {0} The {0} will be replaced by the parameter. Single quotes must be doubled, i.e. ' -> '' in the string.
        o - parameter, not translated. To translate parameter also, use _t("foo {0} bar", _t("baz")) Do not double the single quotes in the parameter. Use autoboxing to call with ints, longs, floats, etc.
        ctx - supplies the routerconsole.lang property, else current locale
        Returns:
        the translated string, with {0} replaced by the parameter

      • getString

        public static String getString(int n, String s, String p, I2PAppContext ctx)
        Translate a string picking between the singular and the plural form, as the GNU gettext plural-forms rules require.
        Parameters:
        n - the count, used to choose between s and p
        s - singular string, may contain {0} for the count
        p - plural string, may contain {0} for the count
        ctx - supplies the routerconsole.lang property, else current locale
        Returns:
        s or p, per the plural rules for n

      • getDisplayLanguage

        public static String getDisplayLanguage(String langCode, String dflt, I2PAppContext ctx)
        Return the "display language", e.g. "English" for the language specified by langCode, using the current language. Uses translation if available, then JVM Locale.getDisplayLanguage() if available, else default param.
        Parameters:
        langCode - two-letter lower-case language code whose name is wanted, e.g. "en"
        dflt - returned untranslated when the current language is "en", when the bundle has no entry for it, or when the JVM has no display name for langCode in the current language
        ctx - supplies the language to display the name in
        Returns:
        the display language
