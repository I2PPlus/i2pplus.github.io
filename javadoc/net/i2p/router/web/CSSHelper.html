      • _UACache

        private static final Map<String,Boolean> _UACache
        Bounded LRU memo of the "is this a small browser?" decision, keyed on the request User-Agent. The key is a client-supplied string, so an unbounded map would grow with every unique UA ever seen; LHMCache caps it. Wrapped in Collections.synchronizedMap(Map) because LHMCache is unsynchronized and the console serves concurrent requests.
