      • clientIP

        static String clientIP(String forwardedFor, String realIp, String remoteAddr, boolean trustForwarded)
        Choose the address the login blocklist keys on.

        The peer address of the connection is the default. The forwarding headers are attacker-controlled on a directly-reachable console, and honouring them let every attempt with a fresh X-Forwarded-For value look like a new client, so the blocklist never engaged and its map grew one entry per spoofed address. They are read only when an operator has opted in via PROP_TRUST_FORWARDED_FOR, having put a real proxy in front.

        That proxy must OVERWRITE the forwarding header with the address it saw - nginx X-Real-IP from $remote_addr, for example. A proxy that appends instead (nginx $proxy_add_x_forwarded_for, Apache's default) leaves the client's own text as the leftmost entry, which is exactly the fresh-identity bypass the header is not trusted for by default. A value that is not an IP literal is ignored outright, so a hostile header can neither key the blocklist on text of the sender's choosing nor reach the log line verbatim.

        Parameters:
        forwardedFor - the X-Forwarded-For header, a comma-separated chain, or null
        realIp - the X-Real-IP header, or null
        remoteAddr - the peer address of the connection, never null in practice
        trustForwarded - true only when a trusted reverse proxy fronts the console
        Returns:
        the address to rate-limit, never null or empty

      • addPersistedSession

        static String addPersistedSession(String existing, String token, String username, long expiresAt, long now)
        Rebuild the persisted-session list with one session added.

        The list used to be append-only: every login wrote a new entry, nothing ever removed one, and the whole value was rewritten each time - so a router left running accumulated a session token per login in router.config for ever, including ones that had expired and were never loadable again. This drops expired and unreadable entries, replaces an existing entry for the same token instead of adding a second, and caps the list so it cannot grow without bound.

        Pure and static so a test can drive a hostile stored value without a router.

        Parameters:
        existing - the stored value, or null
        token - the session token being added
        username - who the session belongs to
        expiresAt - when it expires in ms, or -1 for no expiry
        now - current time in ms
        Returns:
        the value to store, entries joined with '|'
