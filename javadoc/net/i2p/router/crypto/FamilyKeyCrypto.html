      • MAX_VERIFIED

        static final int MAX_VERIFIED
        Bound on the positive verification cache, in entries. One entry per router whose family signature we have checked, each holding two strings, so the map has to be bounded the same way the negative cache is. Clearing it only costs a re-verification on the next lookup, so the bound is enforced by a clear rather than by an eviction policy.

      • cleanupCaches

        static int[] cleanupCaches(Map<?,?> negative, Map<?,?> verified, int max)
        Run the periodic cache maintenance. The negative cache is cleared outright, since a miss simply re-checks the router. The positive cache is only cleared once it passes its bound - dropping live entries costs a re-verification of every family router on the next lookup, so while it is inside the bound the entries are worth keeping, and the bound is enforced by a clear rather than by tracking which entry to evict.
        Parameters:
        negative - the negative cache
        verified - the positive cache
        max - the bound on the positive cache's entry count
        Returns:
        the entries cleared from each cache, negative first
