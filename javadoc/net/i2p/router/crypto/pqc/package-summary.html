    package net.i2p.router.crypto.pqc

    Post-quantum hybrid key encapsulation built on the bundled Bouncy Castle ML-KEM primitives.

    Hybrid schemes combine X25519 with ML-KEM so that a break of either primitive alone does not expose session keys, protecting long-term confidentiality against future quantum attacks. Not for use by apps, clients or plugins.

    See also: FIPS 203 (ML-KEM) • Bouncy Castle.
