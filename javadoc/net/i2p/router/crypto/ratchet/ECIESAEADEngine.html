      • decryptNewSession

        private CloveSet decryptNewSession(byte[] data, PrivateKey targetPrivateKey, RatchetSKM keyManager) throws DataFormatException
        Scenario 1: New Session Message

        Begin with 80 bytes, ECIES encrypted, containing:

        - 32 byte Elligator2 key
- 32 byte static key
- 16 byte MAC
        And then the data:
        - payload (7 bytes minimum for DateTime block)
- 16 byte MAC
        Parameters:
        data - 103 bytes minimum
        targetPrivateKey - our private key matching the message's encryption type
        keyManager - holds the ephemeral-key replay cache and receives the new session on success
        Returns:
        the decrypted cloves, null if the Elligator2 decode or the handshake fails, or an empty set for a replayed key or a payload with no garlic
        Throws:
