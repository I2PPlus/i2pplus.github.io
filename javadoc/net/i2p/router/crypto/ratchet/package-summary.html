    package net.i2p.router.crypto.ratchet

    The Double Ratchet with X25519 key agreement and ECIES hybrid encryption, used by the NTCP2 and SSU transports for session encryption.

    It provides forward secrecy - compromising current key material does not expose past sessions - and post-compromise security, recovering after a few message exchanges. Not for use by apps, clients or plugins.

    See also: The Double Ratchet Algorithm.
