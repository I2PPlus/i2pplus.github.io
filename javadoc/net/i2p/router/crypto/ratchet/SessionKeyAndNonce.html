    DataStructure
    class SessionKeyAndNonceextends SessionKey
    Session key with nonce and optional handshake state for ratchet message encryption and decryption operations, supporting nonces up to 65535

    This is what is returned from RatchetTagSet.consume(RatchetSessionTag). RatchetSKM puts it in a RatchetEntry and returns it to ECIESAEADEngine.
