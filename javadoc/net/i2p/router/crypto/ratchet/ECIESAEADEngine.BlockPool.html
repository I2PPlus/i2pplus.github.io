      • release

        void release(List<RatchetPayload.Block> blocks)
        Return all blocks to their pools and clear the list.

        A pooled block is handed back with whatever it last carried still reachable from it, so the reference-holding types are cleared on the way in: a GarlicBlock pins the whole clove and everything the clove holds, and a NextKeyBlock pins a live session key. The pools are per-thread, so an uncleared block keeps that object for the life of the transport thread. Every acquire re-arms the field before the block is returned to the caller, so a cleared block is never read.

        Parameters:
        blocks - the block list to recycle, emptied by this call
