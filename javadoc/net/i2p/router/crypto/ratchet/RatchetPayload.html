        public static int processPayload(I2PAppContext ctx, RatchetPayload.PayloadCallback cb, byte[] payload, int off, int length, boolean isHandshake) throws IOException, DataFormatException
        Process a ratchet payload, calling the callback for each block found.
        Parameters:
        ctx - the I2P app context
        cb - the payload callback
        payload - the frame holding the encoded blocks, read from off for length bytes
        off - the offset into the payload
        length - the number of payload bytes to scan, from off to the end of the frame
        isHandshake - true for handshake messages
        Returns:
        the number of blocks processed
        Throws:
        IOException - on I/O error
        DataFormatException - on data format error
