      • processPayload

        public static int processPayload(I2PAppContext ctx, RatchetPayload.PayloadCallback cb, byte[] payload, int off, int length, boolean isHandshake) throws IOException, DataFormatException
        Process a ratchet payload, calling the callback for each block found.
        Parameters:
        ctx - the I2P app context
        cb - the payload callback
        payload - the frame holding the encoded blocks, read from off for length bytes
        off - the offset into the payload
        length - the number of payload bytes to scan, from off to the end of the frame
        isHandshake - true for handshake messages
        Returns:
        the number of blocks processed
        Throws:
        IOException - on I/O error
        DataFormatException - on data format error

      • writePayload

        public static int writePayload(byte[] payload, int off, List<RatchetPayload.Block> blocks)
        Write blocks to a payload buffer.
        Parameters:
        payload - writes to it starting at off
        off - the starting offset
        blocks - the blocks to write, in order, each with its own header
        Returns:
        the new offset

      • toInt4

        private static void toInt4(byte[] target, int offset, int value)
        Big endian. Same as DataHelper.toLong(int, long) for 4 bytes, but allows a negative value.
        Parameters:
        target - the buffer the 4 big endian bytes are written into
        offset - the index of the first of the 4 bytes in target
        value - the value to encode, negative values included
        Throws:
        ArrayIndexOutOfBoundsException - if offset is negative or the 4 bytes at offset run past the end of target
