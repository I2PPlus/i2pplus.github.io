      • SESSION_LIFETIME_MAX_MS

        static final long SESSION_LIFETIME_MAX_MS
        How long unused inbound session tags are kept. A few minutes longer than the outbound tag lifetime, so no reasonable network lag can cause failed decrypts.

        This is also the session idle timeout used by TransientSessionKeyManager.

      • consumeNextAvailableTag

        public RatchetEntry consumeNextAvailableTag(PublicKey target)
        Takes the next outbound session tag and key for sending a message to the target.

        If this returns null, no session is set up yet, and a New Session message should be sent.

        If this returns non-null, the tag in the RatchetEntry will be non-null.

        If the SessionKeyAndNonce contains a HandshakeState, then the session setup is in progress, and a New Session Reply message should be sent. Otherwise, an Existing Session message should be sent.

        Parameters:
        target - the remote router to take the next outbound tag for
        Returns:
        the next available tag, or null
