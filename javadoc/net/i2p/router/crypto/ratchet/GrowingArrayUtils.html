    net.i2p.router.crypto.ratchet.GrowingArrayUtils
    final class GrowingArrayUtilsextends Object
    Helper methods for efficient primitive array growth and insertion. All methods assume that an array's length is its capacity, NOT its element count; the current size is always passed in as a parameter.

        public static int growSize(int currentSize)
        Given the current size of an array, returns an ideal size to which the array should grow. This is typically double the given size, but should not be relied upon to do so in the future.
        Parameters:

        Returns:
