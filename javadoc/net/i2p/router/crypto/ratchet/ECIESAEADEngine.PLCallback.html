      • gotOptions

        public void gotOptions(byte[] options, boolean isHandshake)
        Process an options field from the payload.

        Intentionally a log-only no-op. This router never emits an OPTIONS block (no option bytes are negotiated in createPayload()) and no local state transition, tag, session key, or acknowledgement behavior is defined in terms of OPTIONS, so ignoring a received block is protocol-correct. The length and framing are already validated by the parser.

      • gotTermination

        public void gotTermination(int reason)
        Process a termination field from the payload.

        Intentionally a log-only no-op. Ratchet sessions here end by ratchet key rotation or by the session expiring in RatchetSKM.aggressiveExpire(), never by a peer-sent TERMINATION block, and this router never emits one. The parser already rejects any block following a TERMINATION other than padding, so the framing is enforced without acting on the reason.

        Specified by:
        gotTermination in interface RatchetPayload.PayloadCallback
        Parameters:
        reason - the peer's termination reason code, 0-255

      • gotPN

        public void gotPN(int pn)
        Process a PN field from the payload.

        Intentionally a log-only no-op. The message number block is an optional advisory hint for out-of-order reassembly; ratchet decryption here is authenticated per message and does not dedupe by number, and this router never emits a PN block. Accepting and ignoring it is therefore protocol-correct.

        Specified by:
        gotPN in interface RatchetPayload.PayloadCallback
        Parameters:
        pn - the peer's message number, 0-65535
