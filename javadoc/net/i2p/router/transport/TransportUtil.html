net.i2p.router.transport

Class TransportUtil

  • java.lang.Object
    • net.i2p.router.transport.TransportUtil

  • public abstract class TransportUtil
extends Object
    Utility class providing common transport operations and configurations. This class contains static methods and constants used throughout the transport system for address validation, port management, IPv6 configuration, and network utility functions. Key Features:
    • IPv4 and IPv6 address validation and parsing
    • Port range validation and assignment
    • IPv6 configuration options for transports
    • Firewall and NAT detection utilities
    • Geographic IP filtering and validation
    • Transport-specific constants and defaults
    IPv6 Support:
    • Configuration options for NTCP and SSU transports
    • Address format validation for IPv6
    • Port assignment and range checking
    • Compatibility helpers for mixed IPv4/IPv6 environments
    Network Utilities:
    • Port assignment strategies (random vs. configured)
    • Firewall detection and bypass methods
    • Transport protocol constants and defaults
    • Address type detection and validation
