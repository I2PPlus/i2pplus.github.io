    Utility class providing common transport operations and configurations.

    This class contains static methods and constants used throughout the transport system for address validation, port management, IPv6 configuration, and network utility functions.

    Key Features:

    • IPv4 and IPv6 address validation and parsing
    • Port range validation and assignment
    • IPv6 configuration options for transports
    • Firewall and NAT detection utilities
    • Geographic IP filtering and validation
    • Transport-specific constants and defaults

    IPv6 Support:

    • Configuration options for NTCP and SSU transports
    • Address format validation for IPv6
    • Port assignment and range checking
    • Compatibility helpers for mixed IPv4/IPv6 environments

    Network Utilities:

    • Port assignment strategies (random vs. configured)
    • Firewall detection and bypass methods
    • Transport protocol constants and defaults
    • Address type detection and validation

      • isUsableRouterAddress

        public static boolean isUsableRouterAddress(RouterAddress ra)
        Is the RouterAddress usable for tunnel building?

        SSU requires protocol v2 plus a valid IP/port or an introduction; SSU2 requires a valid IP/port or an introduction; NTCP/NTCP2 require a valid IP/port.

        Lives here rather than in TunnelPeerSelector because both the tunnel selectors and ProfileOrganizer need it, and the latter must not reach into tunnel.pool — that package already depends on peermanager, so the reverse edge would close a cycle.

        Pure decision: no context access, safe for unit tests.

        Parameters:
        ra - the router address to check (non-null)
        Returns:
        true if the address is usable

      • hasUsableTransportAddress

        public static boolean hasUsableTransportAddress(RouterInfo ri)
        Does this RouterInfo carry at least one address we could still send to?

        A peer whose addresses have all expired or become unusable cannot be selected for a build and cannot be pre-connected to, so admitting it to a selection tier only produces a candidate that is guaranteed to fail. Gate promotion on this.

        Pure decision: takes the RouterInfo rather than consulting the netdb, so callers holding an entry do not pay for a second lookup.

        Parameters:
        ri - the router info to check (non-null)
        Returns:
        true if at least one address is usable
