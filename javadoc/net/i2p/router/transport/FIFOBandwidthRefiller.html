    Bandwidth token refiller for FIFO-based bandwidth limiting.

    This thread periodically refills bandwidth token buckets for the FIFOBandwidthLimiter. It runs independently to ensure tokens are available at regular intervals, preventing traffic starvation and maintaining consistent throughput.

    Refill Strategy:

    • Fixed interval token replenishment
    • Configurable refill rates and amounts
    • Separate inbound and outbound bandwidth tracking
    • Participating bandwidth counter (since 0.8.12)
    • Thread-safe operations with atomic counters

    Configuration:

    • Configurable inbound bandwidth limits (KBps)
    • Configurable outbound bandwidth limits (KBps)
    • Adjustable refill intervals and amounts
    • System property integration for defaults

    Thread Safety:

    • Atomic counters for bandwidth tracking
    • Thread-safe refill operations
    • Non-blocking queue operations

    Note: This class was originally created to provide a dedicated thread for bandwidth refilling when the main limiter needed thread resources. As of 0.8.12, it also includes participating bandwidth counter functionality.

    Public only for properties and defaults.
