    public class CommSystemFacadeImpl
extends CommSystemFacade
    Primary implementation of the communication system facade for I2P network operations. This class provides the main interface between the router core and all transport protocols. It coordinates message sending, peer management, address configuration, and network monitoring while abstracting the underlying transport details. Core Responsibilities:
    • Message routing and delivery across all transports
    • Peer connection management and statistics
    • Network address discovery and configuration
    • Bandwidth allocation and monitoring
    • Transport lifecycle management (start/stop/restart)
    • Network reachability testing and reporting
    • Geographic IP filtering and country blocking
    • Communication system status and health monitoring
    Transport Integration:
    • Manages NTCP, UDP, and SSU transports
    • Handles transport selection and failover
    • Coordinates address updates across protocols
    • Provides unified API for router components
    Configuration Features:
    • Transport enable/disable controls
    • Country-based blocking and filtering
    • Proxy configuration and detection
    • Network monitoring and testing options
    • IPv4 and IPv6 addressing support
    Security Features:
    • Geographic IP filtering
    • Country-based access controls
    • Peer reputation and banlist management
    • Transport-specific security policies

      • shutdown

        public void shutdown()
        Cannot be restarted after calling this. Use restart() for that. Gracefully shutdown the communication system. This method performs a clean shutdown of all transport protocols and network operations. It stops accepting new connections, closes existing ones, and performs cleanup of system resources. Shutdown Process:
        • Stop network monitoring
        • Stop all transport protocols
        • Close all active connections
        • Cleanup system resources and caches
        • Save final state and statistics
        Throws:
        IllegalStateException - if not running

      • startup

        public void startup()
        Start the communication system and all transport protocols. This method initializes the communication system, starts all configured transports, and begins network operations. It handles transport discovery, address configuration, and peer management setup. Startup Process:
        • Initialize geographic IP filtering
        • Start network monitoring
        • Register and start all configured transports
        • Begin peer discovery and connection attempts
        • Setup address change notifications
        Throws:
        IllegalStateException - if already running
