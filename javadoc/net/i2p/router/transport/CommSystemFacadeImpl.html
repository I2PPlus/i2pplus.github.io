    public class CommSystemFacadeImplextends CommSystemFacade
    Primary implementation of the communication system facade for I2P network operations.

    This class provides the main interface between the router core and all transport protocols. It coordinates message sending, peer management, address configuration, and network monitoring while abstracting the underlying transport details.

    Core Responsibilities:

    • Message routing and delivery across all transports
    • Peer connection management and statistics
    • Network address discovery and configuration
    • Bandwidth allocation and monitoring
    • Transport lifecycle management (start/stop/restart)
    • Network reachability testing and reporting
    • Geographic IP filtering and country blocking
    • Communication system status and health monitoring

    Transport Integration:

    • Manages NTCP, UDP, and SSU transports
    • Handles transport selection and failover
    • Coordinates address updates across protocols
    • Provides unified API for router components

    Configuration Features:

    • Transport enable/disable controls
    • Country-based blocking and filtering
    • Proxy configuration and detection
    • Network monitoring and testing options
    • IPv4 and IPv6 addressing support

    Security Features:

    • Geographic IP filtering
    • Country-based access controls
    • Peer reputation and banlist management
    • Transport-specific security policies

        public int countActiveSendPeers()
        How many peers we have sent a message to in the last minute.

        Narrower than CommSystemFacade.countActivePeers() in both respects that matter: send only, and a one-minute window rather than the transport's active window. The pair answers different questions - how many peers we can reach against how many we are actually driving traffic to right now.

        The javadoc on this method said "in the last minute" already, while countActivePeers() above it says five. Only the latter is inaccurate: every transport's active window is sixty seconds. The send-only count is the one this declares, per transport.
