    Central coordinator for all I2P transport protocols.

    This class manages the lifecycle, configuration, and coordination of all enabled transport protocols (NTCP, UDP, SSU, etc.). It provides unified access to transport functionality and handles transport-specific operations like address management, peer discovery, and message routing.

    Core Responsibilities:

    • Transport lifecycle management (start/stop/restart)
    • Address discovery and configuration
    • Peer connection management and statistics
    • Message routing between transports
    • UPnP integration for NAT traversal
    • Bandwidth allocation and coordination
    • Transport event handling and notifications

    Transport Support:

    • Built-in transports: NTCP, UDP, SSU
    • Pluggable transport support (incomplete)
    • IPv4 and IPv6 addressing
    • Automatic transport selection and failover

    UPnP Integration: Automatically starts and manages UPnP service for NAT traversal and port forwarding discovery.

    API Access: This class is primarily internal to the router. Only a few methods are public for console and Android integration. External components should use CommSystemFacadeImpl for transport access rather than calling this class directly.

    Note: This is not intended as a public API for external use. Implementation details may change without notice.

      • registerAndStart

        void registerAndStart(Transport t)
        Register and start a pluggable transport.

        This method registers a new pluggable transport (not NTCP or SSU) with the transport manager and starts it if this is the first transport being registered. The method handles validation, initialization, and lifecycle management.

        Process:

        • Validates transport is not built-in (NTCP/UDP)
        • Checks for duplicate transport styles
        • Adds to pluggable transport registry
        • Sets transport event listener
        • Initializes transport addresses
        • Starts transport listening if first transport
        • Rebuilds router info with new addresses
        Parameters:
        t - the transport to register and start
        Throws:
        IllegalArgumentException - if transport is built-in type
        IllegalStateException - if transport style already exists

      • stopAndUnregister

        void stopAndUnregister(Transport t)
        Stop and unregister a pluggable transport.

        This method gracefully shuts down a pluggable transport (not NTCP or SSU) and removes it from the transport registry. The method handles cleanup, listener removal, and address updates.

        Process:

        • Validates transport is not built-in (NTCP/UDP)
        • Removes transport event listener
        • Removes from pluggable transport registry
        • Stops transport listening
        • Removes from main transport registry
        • Rebuilds router info without transport addresses
        Parameters:
        t - the transport to stop and unregister
        Throws:
        IllegalArgumentException - if transport is built-in type

      • getEstablished

        public List<Hash> getEstablished()
        The list of peer hashes with established connections, may be empty.

        The result is an unmodifiable snapshot shared across callers for up to ESTABLISHED_CACHE_TTL ms. Merging cost two list allocations plus two full traversals of the NTCP and SSU connection tables, and BuildRequestor alone calls this up to five times per tunnel build. Every caller (ProfileOrganizer selection, BuildRequestor logging and hop checks, ConnectChecker, ExploratoryPeerSelector, KademliaNetworkDatabaseFacade, and our own outbound maintainer) only reads the list, so sharing is safe; the TTL is well under the 60s maintainer interval, so the only possible effect is a momentarily stale view of which peers are connected.

        Returns:
        unmodifiable list of peer hashes with established connections, may be empty
