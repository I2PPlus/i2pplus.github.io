    public abstract class StrictCountriesextends Object
    Maintains list of countries with strict application restrictions. Maintain a list of countries that may have tight restrictions on applications like ours.

    The country set is stored as a sorted array of case-normalized 2-letter integer keys so contains(String) performs no per-call String allocation (callers such as Router.isHidden check this on the hot path with GeoIP codes that are already lowercase).
