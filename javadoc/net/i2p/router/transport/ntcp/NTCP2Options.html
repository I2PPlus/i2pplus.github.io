      • NTCP2Options

        public NTCP2Options(float sendMin, float sendMax, float recvMin, float recvMax, int sendDummy, int recvDummy, int sendDelay, int recvDelay)
        All params are as named.
        Parameters:
        sendMin - the lowest padding ratio we will send at, 0.0 to 1.0
        sendMax - the highest padding ratio we will send at, 0.0 to 1.0
        recvMin - the lowest padding ratio we will accept, 0.0 to 1.0
        recvMax - the highest padding ratio we will accept, 0.0 to 1.0
        sendDummy - the dummy data rate we send, in bytes per second
        recvDummy - the dummy data rate we will accept, in bytes per second
        sendDelay - the delay we ask the peer to apply, in milliseconds
        recvDelay - the delay we apply ourselves, in milliseconds
