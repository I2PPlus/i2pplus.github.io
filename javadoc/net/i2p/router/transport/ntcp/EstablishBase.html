Class EstablishBase

  • java.lang.Object
    • net.i2p.router.transport.ntcp.EstablishBase

    Direct Known Subclasses:
    InboundEstablishState

    abstract class EstablishBase
extends Object
implements EstablishState
    Base class for NTCP connection establishment. Provides common functionality for NTCP 2 handshake state machines, including cryptographic operations, timing calculations, and peer skew management. Inbound NTCP 2 only - OutboundNTCP2State does not extend this.
