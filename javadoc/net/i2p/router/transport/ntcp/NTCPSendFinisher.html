net.i2p.router.transport.ntcp

Class NTCPSendFinisher

  • java.lang.Object
    • net.i2p.router.transport.ntcp.NTCPSendFinisher

  • class NTCPSendFinisher
extends Object
    Handles asynchronous post-send processing of OutNetMessage using a dynamically resizable thread pool executor with a bounded queue and backpressure. Provides efficient message serialization and prevents resource exhaustion.
