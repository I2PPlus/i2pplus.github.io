    Runnable
    class EventPumperextends Object implements Runnable
    The main NTCP NIO event loop thread responsible for high-throughput, low-latency handling of inbound and outbound NTCP connections using non-blocking I/O.

    This class is optimized for minimal overhead and maximum event dispatch efficiency. All hot paths (e.g., processRead(SelectionKey), processWrite(SelectionKey), runDelayedEvents()) avoid synchronization, allocations, and unnecessary syscalls.

    Key performance characteristics:

    • Fixed 200ms selector timeout for consistent latency
    • Immediate wakeup() on pending I/O
    • Duplicate-free write request tracking via ConcurrentHashSet
    • Spin detection: yields briefly when select() returns repeatedly without blocking
    • Failsafe iteration every 2 seconds to clean stale connections
    • Efficient buffer pooling with bounded size

      • WRITE_BUFSIZE

        private static final int WRITE_BUFSIZE
        Fixed size class for NTCP2 data-phase write frames.

        Each frame carries up to NTCPConnection.BUFFER_SIZE payload bytes plus the 16-byte MAC (see OutboundNTCP2State.MAC_SIZE) and a 2-byte length header. The buffer must be a constant size for pooling: the previous per-frame new byte[2 + framelen] allocation was variable-sized, so every frame smaller than BUF_SIZE escaped the cache and was reallocated on each send.
