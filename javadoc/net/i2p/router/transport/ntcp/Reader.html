net.i2p.router.transport.ntcp

Class Reader

  • java.lang.Object
    • net.i2p.router.transport.ntcp.Reader

  • public class Reader
extends Object
    Pool of running threads which will process any read bytes on any of the NTCPConnections, including decryption of the data read, connection handshaking, parsing bytes into I2NP messages, etc. Provides efficient buffer management and connection lifecycle coordination. Supports dynamic thread count adjustment via adjustThreads().
