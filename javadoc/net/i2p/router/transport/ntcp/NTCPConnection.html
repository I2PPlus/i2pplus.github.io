    Closeable, AutoCloseable
    public class NTCPConnectionextends Object implements Closeable
    Coordinates a connection to a single peer using NTCP 1 or NTCP 2 protocols. Manages the complete connection lifecycle including establishment, message encryption/decryption, bandwidth management, and graceful shutdown.

    Public only for UI peers page. Not a public API, not for external use.

      • _establishmentRtt

        private volatile int _establishmentRtt
        Round trip time of the handshake that established this session, in ms, or 0 when it has not been measured.

        Both NTCP2 establishment paths already compute this to derive clock skew - now - getCreated() at the point the peer's timestamp arrives - but discarded it, so the transport had no latency to report and Transport.getEstimatedRTT(Hash) answered 0 for every NTCP2 peer. With that answer, every consumer of a direct-link latency reading stayed empty: the profile's first-hop RTT was never populated, and the low-latency flag never turned on for NTCP2 peers.

        Measured once, at establishment, and never updated afterwards: it describes the handshake this session was built on, and the profile-level smoothing in PeerProfile.setFirstHopRtt is what carries it forward. Recorded here rather than derived by the reader, so the value has exactly one source per session.
