      • tooManyIntroducers

        static boolean tooManyIntroducers(RouterAddress addr)
        Check whether a peer address declares more introducers than the spec allows. Each introducer requires a tag property, so any tag at or beyond our cap means the peer is out of spec.
        Parameters:
        addr - the peer's transport address
        Returns:
        true if introducer properties beyond MAX_INTRODUCERS are present

      • overCapIntroducerKey

        static boolean overCapIntroducerKey(String msg)
        Check whether a property-order parse error names an introducer property beyond our cap, e.g. "iexp10". Such a peer wrote its introducer options numerically instead of in the required sorted order, which only happens with more introducers than we support.
        Parameters:
        msg - the DataFormatException message
        Returns:
        true if an over-cap introducer key appears in the message

      • getByName

        private static InetAddress getByName(String host)
        Caching version of getByName(host), which is slow. Caches numeric IPs only. As of 0.9.32, will NOT resolve hostnames.

        Unlike InetAddress.getByName(String), we do NOT allow numeric IPs of the form d.d.d, d.d, or d, as these are almost certainly mistakes.

        Parameters:
        host - literal IPv4 or IPv6; if null or hostname, returns null
        Returns:
        InetAddress or null
