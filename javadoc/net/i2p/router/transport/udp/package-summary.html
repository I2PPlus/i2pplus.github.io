    package net.i2p.router.transport.udp

    SSU2, the UDP transport: datagram sessions with Holepunch peer discovery, plus the older SSU compatibility code. Not for use by apps, clients or plugins.

    See also: SSU2 specification • RFC 5681 (congestion control) • RFC 6298 (RTO computation).
