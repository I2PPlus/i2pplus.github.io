    net.i2p.router.transport.udp.PacketBuilder2
    class PacketBuilder2extends Object
    Builds and encrypts SSU2 protocol packets for UDP transport. Handles all SSU2 message types including data packets, session establishment, peer testing, relay requests, and hole punching. Provides packet fragmentation, padding, and encryption for secure UDP communication.

      • handshakePayloadOffset

        static int handshakePayloadOffset(int pqlen)
        Offset within the packet, measured from the start of the long header, where the plaintext payload blocks of a handshake message are staged. Noise writes the ephemeral key, and for the PQ versions the ML-KEM frame, into the message buffer before it reads the payload, so staging the blocks any earlier makes writeMessage() encrypt its own key material as the payload - a well-formed message whose blocks are garbage, with a tag that still verifies.
        Parameters:
        pqlen - the PQ frame length from SSU2Util.pqRequestExtra(int) or SSU2Util.pqCreatedExtra(int), 0 for version 2
        Returns:
        the staging offset from the start of the long header
