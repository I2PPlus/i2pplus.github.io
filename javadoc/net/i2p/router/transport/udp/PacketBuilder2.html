net.i2p.router.transport.udp

Class PacketBuilder2

  • java.lang.Object
    • net.i2p.router.transport.udp.PacketBuilder2

  • class PacketBuilder2
extends Object
    Builds and encrypts SSU2 protocol packets for UDP transport. Handles all SSU2 message types including data packets, session establishment, peer testing, relay requests, and hole punching. Provides packet fragmentation, padding, and encryption for secure UDP communication.
