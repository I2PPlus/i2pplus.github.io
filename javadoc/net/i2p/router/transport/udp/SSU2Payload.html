      • checkBlockOrder

        static void checkBlockOrder(int type, boolean gotPadding, boolean gotTermination, boolean isHandshake, int blocks) throws IOException
        Order-rule guard for the incoming-block scan. Padding must terminate the block list; only padding may follow a termination block; a handshake must start with a DATETIME block. Each violation is a protocol error, thrown as an IOException.
        Parameters:
        type - the current block type byte
        gotPadding - true if a BLOCK_PADDING preceded this block
        gotTermination - true if a BLOCK_TERMINATION preceded this block
        isHandshake - true if this is a handshake frame, where the first block must be DATETIME
        blocks - the number of blocks processed before this one
        Throws:
        IOException - on any ordering violation

      • checkFrameOverflow

        static void checkFrameOverflow(int off, int length, int dataOff, int len, int blocks, int type) throws IOException
        Guard that a block's declared length fits inside the frame. Offsets in the error message are byte positions relative to the frame. The frame contents are deliberately not included, they may be decrypted data. Callers that want a dump log it at DEBUG.
        Parameters:
        off - start of the payload in the array
        length - frame size in bytes
        dataOff - offset of the block's 2-byte length field
        len - the declared block length
        blocks - the zero-based index of this block for the error message
        type - the block type byte for the error message
        Throws:
        IOException - if the block runs past the end of the frame

      • recoverRouterInfo

        DataFormatException - the original parse failure when verification fails
