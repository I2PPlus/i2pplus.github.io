      • pickInbound

        public int pickInbound(RouterAddress current, boolean ipv6, Properties ssuOptions, int howMany)
        Grab a bunch of peers who are willing to be introducers for us that are locally known (duh) and have published their own SSU address (duh^2). The picked peers have their info tacked on to the ssuOptions parameter for use in the SSU RouterAddress.

        Try to use "good" peers (i.e. reachable, active)

        Also, ping all idle peers that were introducers in the last 2 hours, to keep the connection up, since the netDb can have quite stale information, and we want to keep our introducers valid.

        Parameters:
        current - current router address, may be null
        ipv6 - what type is the current address we need introducers for?
        ssuOptions - out parameter, options are added
        howMany - the most introducers to return
        Returns:
        number of introducers added

        void receiveRelayRequest(PeerState2 alice, byte[] data)
        We are Bob and we got this from Alice. Send Alice's RI and a RelayIntro to Charlie, or reject with a RelayResponse to Alice. We should already have a session with Charlie and definitely with Alice.

      • receiveRelayIntro

        void receiveRelayIntro(PeerState2 bob, Hash alice, byte[] data)
        Processes a relay introduction message received from another peer.

        This method is responsible for initiating a HolePunch to the specified destination peer ('Alice') and preparing a RelayResponse to be sent back to the originating peer ('Bob'). It is designed for use with the SSU 2 protocol.

        Parameters:
        bob - the PeerState2 instance representing the peer that sent the relay introduction message
        alice - the Hash object identifying the destination peer ('Alice') to which a HolePunch will be initiated
        data - the byte array containing the data payload of the relay introduction message

      • receiveRelayIntro

        private boolean receiveRelayIntro(PeerState2 bob, Hash alice, byte[] data, int retryCount)
        We are Charlie and we got this from Bob. Bob should have sent us the RI, but maybe it's in the block after this, or maybe it's in a different packet. Check for RI, if not found, return true to retry, unless retryCount is at the limit. Creates the timer if retryCount == 0.

        SSU 2 only.

        Parameters:
        bob - the peer that relayed the introduction to us
        alice - the hash of the peer being introduced
        data - the relay intro payload to forward once Alice's RI is known
        retryCount - the number of retries so far, 0 on first receipt, retried up to 5 times
        Returns:
        false if Alice's RouterInfo is not yet available and the intro should be retried, true if the intro was processed

      • receiveRelayIntro

        private boolean receiveRelayIntro(PeerState2 bob, Hash alice, byte[] data, RouterInfo aliceRI)
        We are Charlie and we got this from Bob. Send a HolePunch to Alice, who will soon be sending us a SessionRequest. And send a RelayResponse to bob.

        SSU 2 only.

        Parameters:
        bob - the peer that relayed the introduction to us
        alice - the hash of the peer being introduced
        data - the signed relay intro payload to validate
        aliceRI - Alice's router info, or null if Bob did not deliver it
        Returns:
        true if a RelayResponse was sent to Bob, false if the intro was invalid or the reply could not be built

      • receiveRelayResponse

        void receiveRelayResponse(PeerState2 peer, int status, byte[] data)
        We are Bob and we got this from Charlie, OR we are Alice and we got this from Bob.

        If we are Bob, send to Alice. If we are Alice, send a SessionRequest to Charlie. We should already have a session with Charlie, but not necessarily with Alice.

        SSU 2 only.

        Parameters:
        peer - the peer that answered our relay request
        status - the status code the peer replied with
        data - the encrypted response, with the nonce and timestamp first

      • receiveHolePunch

        void receiveHolePunch(RemoteHostId charlie, byte[] data)
        We are Alice and we got this from Charlie. Send a SessionRequest to Charlie, whether or not we got the Relay Response already.

        SSU 2 only, out-of-session.

        Parameters:
        charlie - the peer we were relaying to
        data - the encrypted response, with the nonce and timestamp first
