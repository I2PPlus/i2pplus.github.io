net.i2p.router.transport.udp

Class EstablishmentManager

  • java.lang.Object
    • net.i2p.router.transport.udp.EstablishmentManager

  • public class EstablishmentManager
extends Object
    Coordinate the establishment of new sessions - both inbound and outbound. This has its own thread to add packets to the packet queue when necessary, as well as to drop any failed establishment attempts.

      • MAX_IB_ESTABLISH_TIME

        static final AtomicLong MAX_IB_ESTABLISH_TIME
        Kill any inbound that takes more than this. One round trip (Created-Confirmed), possibly two for SSU2 with retry. Tuned to ~3-5x average establish time; the Tuner further adjusts this at runtime.

      • MAX_OB_ESTABLISH_TIME

        static final AtomicLong MAX_OB_ESTABLISH_TIME
        Kill any outbound that takes more than this. Two round trips (Req-Created-Confirmed-Data) for direct; 3 1/2 round trips (RReq-RResp+Intro-HolePunch-Req-Created-Confirmed-Data) for indirect. Tuned to ~3-5x average establish time; the Tuner further adjusts this at runtime.
