    public class EstablishmentManagerextends Object
    Coordinate the establishment of new sessions - both inbound and outbound. This has its own thread to add packets to the packet queue when necessary, as well as to drop any failed establishment attempts.

      • _inboundTokenLifetimeStat

        private volatile RateStat _inboundTokenLifetimeStat
        Cached "udp.inboundTokenLifetime" RateStat handle. Registered in the constructor and never replaced, so it is resolved once rather than on every getInboundToken(RemoteHostId) call: that path is reachable from an unauthenticated inbound Token Request, so the stat lookup (a name-based map get followed by a synchronized read of the Rate) was attacker triggerable. Resolved lazily because a test may construct this manager before the stat exists.

        private final ConcurrentHashMap<RemoteHostId, LinkedBlockingQueue<OutNetMessage>> _queuedOutbound
        Map of RemoteHostId to a bounded, thread-safe queue of OutNetMessage instances for peers whose outbound establishment is pending due to concurrency limits. Each queue is capped at MAX_QUEUED_PER_PEER messages. Thread-safe: no external synchronization required.

        private final ConcurrentHashMap<Long, OutboundEstablishState> _liveIntroductions
        Map of nonce (Long) to OutboundEstablishState. Only for indirect, before we receive the RelayResponse. This is so we can lookup state for the RelayResponse. After we receive the relay response, _outboundStates is keyed by actual IP.

      • _outboundByClaimedAddress

        private final ConcurrentHashMap<RemoteHostId, OutboundEstablishState> _outboundByClaimedAddress
        Map of claimed IP/port to OutboundEstablishState. Only for indirect, before we receive the RelayResponse. This is so we can lookup a pending introduction by IP even before we know the "real" IP, so we can match an inbound packet.
