    class OutboundEstablishState2extends OutboundEstablishState implements SSU2Payload.PayloadCallback
    Data for a new connection being established, where we initiated the connection with a remote peer. In other words, we are Alice and they are Bob.

    SSU2 only.

      • OutboundEstablishState2

        public OutboundEstablishState2(RouterContext ctx, UDPTransport transport, RemoteHostId claimedAddress, RemoteHostId remoteHostId, RouterIdentity remotePeer, boolean needIntroduction, SessionKey introKey, RouterAddress ra, UDPAddress addr, int version) throws IllegalArgumentException
        Prepare to start a new handshake with the given peer.

        Caller must then check OutboundEstablishState.getState() and build a Token Request or Session Request to send to the peer.

        Parameters:
        ctx - the router context
        transport - the UDP transport
        claimedAddress - an IP/port based RemoteHostId, or null if unknown
        remoteHostId - non-null, == claimedAddress if direct, or a hash-based one if indirect
        remotePeer - must have supported sig type
        needIntroduction - should we ask Bob to be an introducer for us? ignored unless allowExtendedOptions is true
        introKey - Bob's introduction key, as published in the netdb
        ra - the router address
        addr - non-null
        version - the SSU2 version
        Throws:
        IllegalArgumentException
