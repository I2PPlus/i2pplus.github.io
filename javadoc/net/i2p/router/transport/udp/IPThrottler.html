    net.i2p.router.transport.udp.IPThrottler
    class IPThrottlerextends Object
    Throttles connection attempts by IP address to prevent abuse. Counts and limits requests from individual IPs within a time window. Supports both IPv4 (direct IP) and IPv6 (hashed first 8 bytes) addresses.
