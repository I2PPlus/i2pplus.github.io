      • RETRANSMIT_DELAY

        protected static final long RETRANSMIT_DELAY
        Flat delay between all retransmits (no exponential backoff). Handshake packets are tiny (~200B) and infrequent per-peer, so the bandwidth cost of flat retransmission is negligible. The OB_MESSAGE_TIMEOUT (2.5s) bounds total retransmits per establishment phase.

        Was 1000ms with exponential doubling (max gap 16s). Reduced to 500ms, now 200ms for sub-100ms message delivery.

      • hasRetried

        public boolean hasRetried()
        Whether the state machine has already scheduled a resend.

        Derived rather than counted: the first send stamps _lastSend with the same clock reading as _establishBegin, so a strictly later stamp means a subsequent send. This is what lets the establishment deadline be extended only once retransmission has genuinely failed, instead of holding every attempt - the overwhelming majority of which are a peer that is simply not there - to the longer budget.

        Returns:
        true if anything has been sent since the state was created
