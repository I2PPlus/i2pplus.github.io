    net.i2p.router.transport.udp.UDPReceiver
    class UDPReceiverextends Object
    Receives raw UDP datagrams off the wire as fast as possible, controlled by the bandwidth limiter and the router's throttle. Pushes received packets into the PacketHandler queue.

    There is a UDPReceiver for each UDPEndpoint. It contains a thread but no queue. Received packets are queued in the common PacketHandler queue.
