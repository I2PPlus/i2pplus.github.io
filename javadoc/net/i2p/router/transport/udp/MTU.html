      • getMTU

        public static int getMTU(InetAddress ia, boolean isSSU2)
        The MTU for the socket interface, if available. Not available for Java 5.

        Note that we don't return the value for the default interface if we can't find the address. Finding the default interface is hard, although we could perhaps just look for the first non-loopback address. But the MTU of the default route probably isn't relevant.

        For SSU2 MTU, values lower than PeerState2.MIN_MTU may be returned, so the caller can determine if SSU2 should be supported.

        Parameters:
        ia - null ok
        isSSU2 - if true, calculate SSU2 MTU
        Returns:
        0 if Java 5, or if not bound to an address; limited to range MIN_MTU to LARGE_MTU for SSU 1.
