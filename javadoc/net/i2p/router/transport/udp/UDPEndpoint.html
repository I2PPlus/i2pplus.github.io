    • Constructor Details

      • UDPEndpoint

        public UDPEndpoint(RouterContext ctx, UDPTransport transport, int listenPort, InetAddress bindAddress)
        Record the settings a later startup() binds the UDP socket with. No socket is opened here, so the address family flags are decided from bindAddress alone; a null address means a dual-stack wildcard.
        Parameters:
        ctx - router context supplying the clock and property source
        transport - may be null for unit testing ONLY
        listenPort - -1 or the requested port, may not be honored
        bindAddress - null ok

      • getSocket

        private DatagramSocket getSocket()
        Open socket using requested port in _listenPort and bind host in _bindAddress. If _listenPort <= 0, or requested port is busy, repeatedly try a new random port.
        Returns:
        null on failure Sets _listenPort to actual port or -1 on failure
