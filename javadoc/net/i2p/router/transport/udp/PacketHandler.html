net.i2p.router.transport.udp

Class PacketHandler

  • java.lang.Object
    • net.i2p.router.transport.udp.PacketHandler

  • class PacketHandler
extends Object
    Pull inbound packets from the inbound receiver's queue, figure out what peer session they belong to (if any), authenticate and decrypt them with the appropriate keys, and push them to the appropriate handler. Data and ACK packets go to the InboundMessageFragments, the various establishment packets go to the EstablishmentManager, and, once implemented, relay packets will go to the relay manager. At the moment, this is an actual pool of packet handler threads, each pulling off the inbound receiver's queue and pushing them as necessary. Supports dynamic thread count adjustment via adjustThreads().
