    private static final class PacketBuilder2.BlockPoolextends Object
    Per-thread pool of payload block objects and the reusable block list. Blocks are used only within PacketBuilder2.buildPacket(List, List, SSU2Sender) for serialization and are never retained after the packet is built, so each thread can clear and refill its own pool across calls without synchronization.
