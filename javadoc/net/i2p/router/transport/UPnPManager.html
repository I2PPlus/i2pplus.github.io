    Universal Plug and Play (UPnP) manager for NAT traversal and port forwarding.

    This class manages UPnP operations to automatically configure port forwarding on UPnP-enabled routers, allowing I2P to work through NAT and firewalls. It bridges between I2P's RouterAddress structures and the external FreeNet UPnP library.

    Core Features:

    • Automatic UPnP device discovery
    • Port forwarding request and management
    • External IP address detection
    • Gateway device mapping and configuration
    • Lease renewal and monitoring
    • Service advertisement for I2P

    UPnP Protocol Support:

    • SSDP (Simple Service Discovery Protocol)
    • HTTP interface for device configuration
    • SOAP-based control messages
    • Event-driven architecture with callbacks

    Integration:

    • Bridges I2P RouterAddress to FreeNet structures
    • Works with TransportManager for address updates
    • Provides callbacks for transport events
    • Handles multiple router discovery protocols

    Configuration:

    • Configurable HTTP and SSDP ports
    • Automatic device selection and fallback
    • Error handling and retry logic
    • Logging and monitoring capabilities

      • rescan

        public boolean rescan()
        Call when IP or network connectivity might have changed. Starts UPnP if previous start failed, else starts a search. Must have called start() first, and not called stop().

        Should be fast. This only starts the search, the responses will come in over the MX time (3 seconds).

        Returns:
        true if a rescan was actually fired off
