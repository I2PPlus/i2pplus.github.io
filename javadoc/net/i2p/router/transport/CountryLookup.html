    Country-code lookup, caching, and strict-country policy for the router.

    Extracted from CommSystemFacadeImpl (2026-09-06) so the country cluster - a per-peer country cache with periodic cleanup, over-capacity eviction, strict-country gating, and startup GeoIP queueing - lives apart from the facade core. The facade retains thin delegation stubs so the public static and commSystem() APIs are unchanged.

    All pure decision logic (cache eviction decisions, memory-independent helpers) is exposed as package-visible static methods so it can be tested without a running router; see CountryLookupDecisionTest.

      • evictExpired

        static int evictExpired(Map<Hash,String> cache, Map<Hash,Long> timestamps, long now, long expiryMs)
        Remove stale and unresolved ("xx") entries from the country cache.

        An entry is expired when its timestamp is strictly older than expiryMs; "xx" (unresolved) entries are always dropped. Called both periodically from getCountry(Hash) and as the first stage of trimToCapacity(Map, Map, long, long, int) so the hot path never recomputes the loop.

        Parameters:
        cache - country cache to drain (entries removed in place)
        timestamps - parallel timestamp map for the same keys
        now - cache age reference in millis
        expiryMs - age threshold in millis (strict >)
        Returns:
        number of entries removed

      • trimToCapacity

        static void trimToCapacity(Map<Hash,String> cache, Map<Hash,Long> timestamps, long now, long expiryMs, int maxSize)
        Bring an over-capacity country cache back under its size bound.

        First advances the expired-entry pass via evictExpired(Map, Map, long, long); if still at or above maxSize, drops the oldest quarter by timestamp. The redundant removeIf()/stream cascade in the original facade is preserved, so hot-path behavior (evict expired first, then oldest) is unchanged.

        Parameters:
        cache - country cache to shrink (entries removed in place)
        timestamps - parallel timestamp map for the same keys
        now - cache age reference in millis
        expiryMs - age threshold in millis for the expired-entry pass
        maxSize - size bound that triggers trimming
