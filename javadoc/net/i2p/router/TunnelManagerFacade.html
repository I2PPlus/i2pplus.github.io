      • ensurePoolsFor

        int ensurePoolsFor(Hash client)
        Run both of a client's pools' ensure logic on demand instead of waiting for the next build-timer interval. Called from the data phase when a send failed for pool-empty reasons (message expired while queued, no tunnels available). A liveness signal that the pools need rebuilding now. Each pool's internal ensure throttle still applies, so a failure storm cannot become a build storm.

        The pool maps are keyed by the local client (source) destination hash, never the remote destination: passing a remote hash finds no pools and silently does nothing.

        Additive ABI: this method and its int return both postdate 0.9.70+ (no release ever shipped a void variant), so implementations and callers only ever saw this signature; callers may still ignore the returned count.

        Parameters:
        client - the LOCAL client destination hash whose pools should rebuild
        Returns:
        how many pools were nudged; 0 when none are registered for the client

      • reportSendFailure

        void reportSendFailure(TunnelInfo tunnel, int status)
        Report a data-phase send failure for a specific tunnel. Called from the I2CP message dispatch path when a message fails through a known tunnel (e.g. expired, local overflow, no tunnels available). Increments the tunnel's failure counter and triggers replacement builds when the threshold is reached, so the pool rotates away from the failing tunnel faster than TestJob alone.
        Parameters:
        tunnel - the outbound tunnel that carried the failed message
        status - the I2CP MessageStatusMessage failure code

      • forceTunnelFailure

        void forceTunnelFailure(TunnelInfo tunnel)
        Force a tunnel to fail immediately and trigger a replacement build. Used when rotation is saturated and the pool has no viable alternative tunnels (e.g., all tunnels in the pool match the cached tunnel). This bypasses the incremental failure counter and directly removes the tunnel, ensuring the pool builds a replacement without waiting for multiple failure reports.
        Parameters:
        tunnel - the outbound tunnel to force-fail
