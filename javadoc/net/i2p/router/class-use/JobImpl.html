    Garlic message creation, parsing and handling, and the outbound message jobs: one-shot sends, source routing and delivery status handling.

    net.i2p.router.startup
    The I2P startup package loads configuration when I2P is started.
    net.i2p.router.sybil
    Offline analysis tools for detecting Sybil attacks and malicious peer coordination by correlating peer relationships.
    net.i2p.router.tasks
    Periodic maintenance jobs: stats coalescing, cryptographic algorithm checks, liveliness marking, out-of-memory handling, thread dumps, the watchdog, graceful shutdown and soft restart, update installation, republishing and config reloading.
