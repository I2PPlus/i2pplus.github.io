    GracefulShutdown manages the router's graceful shutdown/restart lifecycle. Uses configurable timings to control when to re-check state and how long to wait before finalizing a restart/shutdown after signaling.

      • stop

        public void stop()
        Stop the shutdown thread gracefully. Sets the running flag to false and wakes up the thread to allow it to exit cleanly. This should be called during router shutdown to properly terminate the graceful shutdown monitor.
