    Manages the autotune.config file — separate from router.config.

    Stores tuner metadata (value, default, min, max, step) for each param, and is the only file the tuner persists to. Each param's applyValue() sets the runtime value in the live subsystem (streaming, transport, ...) and deliberately does not write router.config, so an auto-tuned value never outlives the tuning decision that produced it and never competes with an operator's router.config entry. The one deliberate router.config write is the one-time legacy cleanup in purgeOldTunerProps(), which deletes pre-autotune.config tuner.* keys and sets the migration marker.

    Writes are throttled: values are marked dirty and flushed to disk at most once per 5 minutes (save()). Use forceSave() for unconditional writes (e.g. shutdown).
