net.i2p.router

Class BanLogger

  • java.lang.Object
    • net.i2p.router.BanLogger

  • public class BanLogger
extends Object
    Dedicated logger for all ban events. Writes to sessionbans.txt in the router's data directory.

    This allows analysis of ban patterns without parsing router.log.
