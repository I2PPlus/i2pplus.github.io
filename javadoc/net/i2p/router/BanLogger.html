    java.lang.Object
    net.i2p.router.BanLogger
    public class BanLoggerextends Object
    Dedicated logger for all ban events. Writes to sessionbans.txt in the router's data directory.

    This allows analysis of ban patterns without parsing router.log.

      • fetchRouterInfo

        private void fetchRouterInfo(Hash hash, String reason, long durationMs)
        Schedule an async network lookup for a RouterInfo that was not locally cached when the ban was logged. When the lookup completes, write a second line to sessionbans.txt with the actual IP, caps, and version, then evict the RouterInfo from the netdb (we only fetched it for logging).

        This is a best-effort operation: silently keep the basic entry on failure.

        Parameters:
        hash - Router hash (non-null)
        reason - reason from the ban
        durationMs - ban length in milliseconds; zero or less logs it as FOREVER

      • getIPFromRouterInfo

        private String getIPFromRouterInfo(RouterInfo router)
        Extract IP address and port from RouterInfo.
        Parameters:
        router - the router whose first address with a host is used, null yields an empty string
        Returns:
        the address as "host:port", with an IPv6 host in brackets, or an empty string when no address has a host

      • writeLog

        private void writeLog(String hashStr, String ip, String reason, String durationStr, String caps, String version, String country, String host)
        Internal method to write the log entry. Skips logging if this IP already has an active ban in sessionbans.txt, or if this hash is already banlisted.
        Parameters:
        hashStr - the router's base64 hash, or "UNKNOWN" for an IP-only ban
        ip - the banned address with port, "UNKNOWN" when it is not known
        reason - the ban reason as shown in the console, HTML markup is stripped
        durationStr - the ban duration already formatted, "FOREVER" for a permanent ban
        caps - the router's capabilities string, null or empty leaves the field blank
        version - the router's version string, null or empty leaves the field blank
        country - the two-letter country code of the IP, null or empty leaves it blank
        host - the hostname or ASN organisation of the IP, null or empty leaves it blank
