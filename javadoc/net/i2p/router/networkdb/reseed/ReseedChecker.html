    java.lang.Object
    net.i2p.router.networkdb.reseed.ReseedChecker
    public class ReseedCheckerextends Object
    Checks whether reseeding of the network database is necessary and initiates reseed requests. This class manages reseed triggers based on network status, router uptime/downtime, peer count, and configuration flags.

    All reseeding must be done through this instance. Access through context.netDb().reseedChecker(), others should not instantiate this class directly.
