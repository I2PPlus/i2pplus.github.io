      • FailedJob

        public FailedJob(RouterContext enclosingContext, RouterInfo peer, boolean penalizePeer)
        Allow the choice as to whether failed searches should count against the peer (such as if we search for a random key).
        Parameters:
        enclosingContext - router context for the job queue and clock
        peer - peer the search was sent to, which is marked failed when the timeout runs out
        penalizePeer - true to record the timeout against the peer profile, false for searches of a random key
