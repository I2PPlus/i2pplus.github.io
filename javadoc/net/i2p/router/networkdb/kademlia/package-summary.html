    package net.i2p.router.networkdb.kademlia

    The Kademlia distributed hash table (DHT) network database: lookup, store and explore jobs, the data store, the floodfill variants, and lookup throttling.

    Lookups route by XOR distance over the 256-bit hash space; floodfill routers store the closest third of the keyspace so the network stays reachable without a central authority. Not for use by apps, clients or plugins.

    See also: Kademlia paper.
