Class MessageWrapper

        Create a single key and tag, for receiving a single encrypted message, and register it with the client's session key manager, to expire in the time specified. The recipient can then send us an AES- or ChaCha- encrypted message, avoiding full ElGamal or ECIES.
        Parameters:
        ctx - the router context
        localDest - the local client destination
        expiration - time from now
        forceElG - if true, force ElGamal even if ratchet is available
        Returns:
        null if we can't find the SKM for the localDest

        Garlic wrap a message from a client or this router, destined for a router, to hide the contents from the OBEP. Caller must call acked() or fail() on the returned object. ELGAMAL ONLY. Both from and to must support ElGamal.
        Parameters:
        from - must be a local client with a session key manager, or null to use the router's session key manager. SessionKeyManager MUST support ElGamal.
        to - must be ELGAMAL_2048 EncType
        Returns:
        null on encrypt failure
