    class RefreshRoutersJobextends JobImpl
    RefreshRoutersJob performs router info refresh operations periodically.

    After startup, refetches router infos, prioritizing floodfill routers, to keep the network database fresh and healthy. This class tries to balance load and avoid overload by controlling timing and refresh intervals.

      • getRouterAgeThreshold

        private int getRouterAgeThreshold(boolean uninteresting, boolean refreshUninteresting, int netDbCount, long _uptime, boolean isFloodfill)
        Returns the router age threshold in milliseconds for refresh decision.
        Parameters:
        uninteresting - true for a router flagged unreachable, low bandwidth, or old version
        refreshUninteresting - the router.refreshUninteresting property, true to refresh those routers on the normal schedule
        netDbCount - the routers we know, a larger NetDb gets a longer threshold
        _uptime - unused, the caller has already applied the uptime gate
        isFloodfill - true if we are a floodfill, which uses the longer thresholds
        Returns:
        the age in milliseconds a router must exceed before it is refreshed again
