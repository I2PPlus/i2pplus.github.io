      • flush

        public void flush()
        Signal the write loop to exit.

        Sets the quit flag and wakes the writer so it leaves waitForNextCycle(). The loop writes the batch it already drained before it re-checks the flag, so entries queued before the call are written; anything queued concurrently with or after it is not.
