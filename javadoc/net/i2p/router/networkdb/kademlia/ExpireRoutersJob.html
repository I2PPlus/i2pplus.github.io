    Job
    class ExpireRoutersJobextends JobImpl
    Go through the routing table pick routers that are out of date, but don't expire routers we're actively connected to.

    The normal path uses _facade's validate(), a sliding expiration based on netdb size. When the netdb is over the size limit, eviction is profile-weighted (see dropProbability(int, long, long)) — peers with no recent contact evidence go first, recently-attested peers are kept — instead of a flat random drop.

      • dropProbability

        static int dropProbability(int base, long lastSeen, long now)
        Profile-weighted drop probability (chance in 128) for the size-pressure eviction path. Peers with no contact evidence are dropped harder than the flat probability; peers attested within PROTECTED_ATTESTED are skipped entirely, so netdb size pressure evicts known-dead entries before useful ones. Pure function — directly unit-testable.
        Parameters:
        base - the flat probability, 10-80 in practice
        lastSeen - newest contact evidence for the peer, 0 if never attested
        now - current context time
        Returns:
        adjusted chance in 128, 0 to protect the peer this cycle
