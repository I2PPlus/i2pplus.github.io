    public class SearchJobextends JobImpl
    Base class for iterative network database search operations.

    Searches for a specific key by querying peers iteratively until either the value is found or all available peers are exhausted. Manages search state, timeout handling, and peer selection with configurable concurrency levels.

    Note that this is rarely used directly and primarily serves as a base for ExploreJob. FloodOnlySearchJob and FloodSearchJob do not extend this class. Does not update peer profile statistics.

        public SearchJob(RouterContext context, KademliaNetworkDatabaseFacade facade, Hash key, Job onSuccess, Job onFailure, long timeoutMs, boolean keepStats, boolean isLease, long msgIDBloomXor)
        Create a new search for the routingKey specified.
        Parameters:
        context - router context supplying the clock, log and job queue
        facade - network database the search reads peers and entries from
        key - hash being searched for; a null hash, or one with no data, is rejected
        onSuccess - job queued once the value is found, may be null
        onFailure - job queued once the search is abandoned, may be null
        timeoutMs - milliseconds before the search gives up; the expiration is computed as now plus this
        keepStats - true to record this search's outcome and duration in the success/failure rate stats
        isLease - true when the target is a LeaseSet, selecting the wider breadth, tunnel-routed queries and LeaseSet storage on success; false for exploratory searches
        msgIDBloomXor - value XOR'ed with the message ID of each outgoing message, so it does not match the peer's bloom filter
        Throws:
        IllegalArgumentException - if the key is null or has no data
