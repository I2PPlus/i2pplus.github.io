    Base class for flood-based search operations with fallback to Kademlia.

    Implements flood-based search strategy sending queries to floodfill peers. If no successful match is received within the allowed timeout, falls back to standard Kademlia iterative search through normal channels. This reduces spurious lookups caused by response delays from floodfill peers.

    Note: Unused directly - see FloodOnlySearchJob extension which overrides almost everything. This does NOT extend SearchJob.

      • FloodSearchJob

        public FloodSearchJob(RouterContext ctx, FloodfillNetworkDatabaseFacade facade, Hash key, Job onFind, Job onFailed, int timeoutMs, boolean isLease)
        Prepares a flood search for one key: records the target, the callbacks and the lease-set flag, then derives the deadline from the requested timeout, applied in full. (IterativeSearchJob extends this class, so any shortening here would halve every iterative search's deadline as well.).
        Parameters:
        ctx - router context supplying the clock and log manager
        facade - floodfill database the key is looked up in
        key - the hash being searched for
        onFind - may be null
        onFailed - may be null
        timeoutMs - search timeout in ms, applied in full to the flood deadline
        isLease - true to search for a lease set rather than a router info
