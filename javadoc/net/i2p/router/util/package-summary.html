    package net.i2p.router.util

    Router utility classes: CoDel active queue management, time-decaying collections, a diagnostics ring buffer, CIDR matching, and password management. Not for use by apps, clients or plugins.

    The main classes are CoDelBlockingQueue, CoDelPriorityBlockingQueue, DecayingBloomFilter, DecayingHashSet, EventLog, MaskedIPSet and RouterPasswordManager.

    See also: RFC 8289 (CoDel).
