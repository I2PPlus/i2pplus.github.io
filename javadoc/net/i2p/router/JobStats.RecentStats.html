        Recent stats.
        Parameters:
        runs - the number of runs in the window
        totalTime - the summed run time across those runs, in milliseconds
        maxTime - the longest run in the window, or -1 if none
        minTime - the shortest run in the window, or -1 if none
        totalPendingTime - the summed queue wait across those runs, in milliseconds
        maxPendingTime - the longest queue wait in the window, or -1 if none
        minPendingTime - the shortest queue wait in the window, or -1 if none
