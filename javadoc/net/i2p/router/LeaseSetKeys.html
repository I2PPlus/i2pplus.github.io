      • LeaseSetKeys

        public LeaseSetKeys(Destination dest, SigningPrivateKey revocationKey, List<PrivateKey> decryptionKeys)
        Client with multiple keys

        The ONLY valid combinations are X25519 + ElG or X25519 + (MLKEM512 OR MLKEM768 OR MLKEM1024). Other combinations will throw IllegalArgumentException.

        Parameters:
        dest - not read; the LeaseSetKeys constructor shares its signature with the server-side variant
        revocationKey - unused, may be null
        decryptionKeys - non-null, non-empty
        Throws:
        IllegalArgumentException - if the list is empty, holds two keys of the same encryption type, mixes ElGamal with a PQ key, or holds an unrecognized type

      • getDecryptionKey

        public PrivateKey getDecryptionKey()
        Decryption key which can open up garlic messages encrypted to the LeaseSet's public key. This is used because the general public does not know on what router the destination is connected and as such can't encrypt to that router's normal public key.
        Returns:
        ElGamal key or null if the LS does not support ElGamal
