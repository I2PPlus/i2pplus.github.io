    Runnable
    public class RouterTimestamperextends Timestamper
    Periodically query a series of NTP servers and update any associated listeners. It tries the NTP servers in order, contacting them using SNTP (UDP port 123).

      • queryTime

        private boolean queryTime(String[] serverList, int perServerTimeout, boolean preferIPv6) throws IllegalArgumentException
        Query the NTP servers, compare the results, and stamp the time if they agree.
        Parameters:
        serverList - the NTP servers to query, tried in random order
        perServerTimeout - how long to wait for each server's reply, in milliseconds
        preferIPv6 - true to query the server's IPv6 address first
        Returns:
        true if the time was stamped, false if the queries did not agree
        Throws:
        IllegalArgumentException - if none of the servers are reachable
