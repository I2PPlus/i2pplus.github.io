    net.i2p.time.BuildTime
    public class BuildTimeextends Object
    The build date as set in i2p.jar, and reasonable min and max values for the current time, to be used as sanity checks.

    Idea taken from Chrome, which assumes any clock more than 2 days before or 1 year after the build date is bad.

    Not maintained as a public API, not for use by plugins or applications.
