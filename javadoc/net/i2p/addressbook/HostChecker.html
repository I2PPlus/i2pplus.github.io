      • performLeaseSetLookup

        private HostChecker.PingResult performLeaseSetLookup(String hostname, Destination destination)
        Perform LeaseSet lookup as the first check Any cached LeaseSet marks the host up directly — even an expired one proves the host exists. Only when no LeaseSet is cached locally do we trigger a fresh remote fetch. If the lookup fails, responseTime is set to -1 and we skip ping/eephead.
        Parameters:
        hostname - hostname to test
        destination - destination for the hostname
        Returns:
        PingResult; responseTime preserves the existing value on success, -1 if the lookup failed

      • lookupLeaseSetRemotely

        private HostChecker.PingResult lookupLeaseSetRemotely(String hostname, Hash destHash, long startTime, long existingResponseTime)
        Perform remote LeaseSet lookup via floodfill network and record the result. A found LeaseSet marks the host up, keeping the previously known response time; a failed lookup retains a recent up-result or records a down-result with response time -1.
        Parameters:
        hostname - the host being checked, used as the result cache key
        destHash - hash of the destination whose LeaseSet is fetched
        startTime - test start time in ms, used as the result timestamp
        existingResponseTime - last known response time in ms, or -1 if never measured
        Returns:
        the recorded PingResult: up if a LeaseSet was found or a recent up-result retained, down otherwise
