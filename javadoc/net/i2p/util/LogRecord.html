    • Constructor Details

      • LogRecord

        public LogRecord(Class<?> src, String name, String threadName, int priority, String msg, Throwable t)
        Captures one log entry, stamping it with the current time.
        Parameters:
        src - the class the entry was logged from
        name - the display name of the logger that wrote the entry
        threadName - the name of the thread that logged it
        priority - the message priority, one of the Log.WARN-style constants
        msg - the unformatted message text
        t - the associated exception, or null if the entry carries none
