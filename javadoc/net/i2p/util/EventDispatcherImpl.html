    public class EventDispatcherImplextends Object implements EventDispatcher
    An implementation of the EventDispatcher interface. Since Java doesn't support multiple inheritance, you could follow the Log.java style: this class should be instantiated and kept as a variable by each object it is used by, ala: private final EventDispatcher _event = new EventDispatcher();

    Deprecated - Used only by I2PTunnel
