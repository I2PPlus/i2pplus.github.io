    net.i2p.util.ByteCache
    public final class ByteCacheextends TryCache<ByteArray>
    Cache the objects frequently used to reduce memory churn. The ByteArray should be held onto as long as the data referenced in it is needed.

    For small arrays where the management of valid bytes in ByteArray and prezeroing isn't required, use SimpleByteArray instead.
