    net.i2p.util.SSLEepGet
    public class SSLEepGetextends EepGet
    HTTPS only, no retries, no min and max size options, no timeout option As of 0.9.45, supports redirect to https (redirect to http will still fail). Fails on bad certs (must have a valid cert chain) Self-signed certs or CAs not in the JVM key store must be loaded to be trusted.

    Since 0.8.2, loads additional trusted CA certs from $I2P/certificates/ssl/ and ~/.i2p/certificates/ssl/

    Since 0.9.33, HTTP proxies (CONNECT) supported. Proxy auth not supported.
