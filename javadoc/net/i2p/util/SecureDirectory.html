      • setPerms

        protected void setPerms()
        Tries to set the permissions to 700 (or 770 when this directory was requested group-accessible), ignores errors.

        Uses the PosixFilePermission API rather than File.setReadable(boolean, boolean): the File setters take an ownerOnly flag, so there is no way to grant the group without also granting others — setReadable(true, false) yields 777, not 770. SecureFileOutputStream.setGroupPerms() sets file permissions the same way for the same reason.

        The execute bit matters as much as read here: a group can read a file inside a directory it cannot traverse, so a group-traversable parent is what actually makes group-readable log files reachable.
