    public class ReusableGZIPOutputStreamextends ResettableGZIPOutputStream
    Provide a cache of reusable GZIP streams, each handling up to 40 KB output without expansion.

    This compresses to memory only. Retrieve the compressed data with getData(). There is no facility to compress to an output stream.

    Do NOT use this for compression of unlimited-size data, as it will expand, but never release, the BAOS memory buffer.
