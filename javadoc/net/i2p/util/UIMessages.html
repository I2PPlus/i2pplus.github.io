net.i2p.util

Class UIMessages

  • java.lang.Object
    • net.i2p.util.UIMessages

  • public class UIMessages
extends Object
    A queue of messages, where each has an ID number. Provide the ID back to the clear call, so you don't erase messages you haven't seen yet. Thread-safe.
