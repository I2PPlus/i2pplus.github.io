    Closeable, Flushable, AutoCloseable
    public class SecureFileOutputStreamextends FileOutputStream
    Same as FileOutputStream but sets the file mode so it can only be read and written by the owner only (i.e. 600 on POSIX). Best effort: on filesystems without POSIX permission support, such as Windows, only the read-only attribute can be affected.

        static boolean canSetPerms()
        Whether it is worth trying to tighten the mode of a file this class opens. False on a pre-1.6 JVM, and false when the router is configured with i2p.insecureFiles, since the setting is then left alone.
