    SimpleTimer2
    public abstract static class SimpleTimer2.TimedEventextends Object implements Runnable
    Base class for timer events. Extend this and use schedule()/cancel() directly instead of going through SimpleTimer2.

    Synchronization is on this to avoid queue duplicates. schedule() is idempotent if already scheduled. reschedule() and forceReschedule(long) replace the existing timer.
