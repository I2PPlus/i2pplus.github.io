      • post

        public boolean post(Map<String,Object> fields,
                    long headerTimeout,
                    long totalTimeout,
                    long inactivityTimeout)
        Submit an HTTP POST to the given URL (using the proxy if specified), uploading the given fields. If the field's value is a File object, then that file is uploaded, and if the field's value is a String object, the value is posted for that particular field. Multiple values for one field name is not currently supported. Large files will be copied to a temp file. For large String content, consider the post(File) method. Note: param field values must be String or File.
