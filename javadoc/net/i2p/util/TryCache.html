Class TryCache<T>

  • java.lang.Object
    • net.i2p.util.TryCache<T>
  • Type Parameters:
    T - type of objects cached
    Direct Known Subclasses:
    ByteCache

    public class TryCache<T>
extends Object
    A thread-safe, lock-free-ish object cache that reuses objects to reduce allocation overhead. Designed to avoid object loss due to lock contention.
