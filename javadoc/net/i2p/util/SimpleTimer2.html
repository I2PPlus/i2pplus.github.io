net.i2p.util

Class SimpleTimer2

  • java.lang.Object
    • net.i2p.util.SimpleTimer2

  • public class SimpleTimer2
extends Object
    Scheduled event executor backed by ScheduledThreadPoolExecutor. Replaces the legacy SimpleTimer (deleted; had lock contention issues). Supports cancel and reschedule. Events must NOT block. All timer events should extend TimedEvent and use schedule()/cancel() directly.
