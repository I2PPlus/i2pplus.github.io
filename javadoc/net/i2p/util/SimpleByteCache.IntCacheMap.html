    private static final class SimpleByteCache.IntCacheMapextends Object
    A set of SimpleByteCache, keyed by array size. Open addressed with linear probing: lookups are lock-free and unboxed, and only putIfAbsent and the occasional growth take the lock.

    Values are read through an AtomicReferenceArray, which both marks the occupied slots - every int is a legal key, so there is no value to spare as an empty-slot sentinel - and publishes each cache's fully built internals.
