    public class VersionComparatorextends Object implements Comparator<String>, Serializable
    Compares versions. Characters other than [0-9.-_] are ignored. I2P only uses '.' but Sun Java uses '_' and plugins may use any of '.-_' Moved from TrustedUpdate.java.
