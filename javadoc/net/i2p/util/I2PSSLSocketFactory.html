        public static final List<String> INCLUDE_PROTOCOLS
        Java 7 does not enable 1.1 or 1.2 by default on the client side. Java 8 does enable 1.1 and 1.2 by default on the client side. 1.3 in Java 11, but it requires: ChaCha20/Poly1305 in Java 12 (we could add a provider) X25519 in Java 13 but may be pulled in to 12 (can't use our unsigned provider) Ed25519 in Java 13 (but we can use our provider) ref: https://openjdk.java.net/jeps/332

      • createSocket

        public Socket createSocket(String host, int port) throws IOException
        Returns a socket to the host.

        A host argument that's an IP address (instead of a host name) is not recommended, as this will probably fail SSL certificate validation.

        Hostname validation is skipped for localhost addresses, but you still must trust the certificate.

        Parameters:
        host - the hostname to validate the certificate against, not an IP literal
        port - the TCP port to connect to
        Returns:
        an SSL socket with the protocol, ciphers and hostname already checked
        Throws:
        IOException - if the connection cannot be established

      • createSocket

        public Socket createSocket(InetAddress host, int port) throws IOException
        Returns a socket to the host.

        An InetAddress argument created with an IP address (instead of a host name) is not recommended, as this will perform a reverse DNS lookup to get the host name for certificate validation, which will probably then fail.

        Hostname validation is skipped for localhost addresses, but you still must trust the certificate.

        Parameters:
        host - the address to connect to, reverse resolved for certificate validation
        port - the TCP port to connect to
        Returns:
        an SSL socket with the protocol, ciphers and hostname already checked
        Throws:
        IOException - if the connection cannot be established

      • initSSLContext

        private static SSLSocketFactory initSSLContext(I2PAppContext context, boolean loadSystemCerts, String relativeCertPath) throws GeneralSecurityException
        Loads certs from the ~/.i2p/certificates/ and $I2P/certificates/ directories, or from the absolute path given.
        Parameters:
        context - the app context, source of the log, the config and base directories, and the randomness for the SSL context
        loadSystemCerts - true to start from the JVM's default trust store, which also lets the result stand when no I2P certificates are found
        relativeCertPath - e.g. "certificates/i2cp"; as of 0.9.41, may be absolute
        Returns:
        a socket factory trusting the certificates that were loaded
        Throws:
        GeneralSecurityException - if the key store cannot be created, or no trusted certificates were found at all
