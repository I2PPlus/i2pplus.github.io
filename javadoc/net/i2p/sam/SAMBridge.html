    net.i2p.sam.SAMBridge
    All Implemented Interfaces:
    Runnable, ClientApp
    public class SAMBridgeextends Object implements Runnable, ClientApp
    SAM bridge — listens on TCP, dispatches each client to a SAMHandlerFactory handler via SAMHandlerPool, and tracks sessions in SessionsDB. Entry point for all SAM v1/v2/v3 STREAM/DATAGRAM/RAW/MASTER sessions.

      • SAMBridge

        public SAMBridge(String listenHost, int listenPort, boolean isSSL, Properties i2cpProps, String persistFile, File configFile)
        Build a new SAM bridge. NOT recommended for external use.

        Opens the listener socket but does NOT start the thread, and there's no way to do that externally. Use main(String[]), or use the other constructor and call startup().

        Deprecated for external use, to be made private.

        Parameters:
        listenHost - hostname to listen for SAM connections on ("0.0.0.0" for all)
        listenPort - port number to listen for SAM connections on
        isSSL - true to serve SAM connections over TLS
        i2cpProps - set of I2CP properties for finding and communicating with the router
        persistFile - location to store/load named keys to/from
        configFile - location of the config file to load settings from
        Throws:
        RuntimeException - if a server socket can't be opened
