      • sendBytes

        boolean sendBytes(String dest, byte[] data, int proto, int fromPort, int toPort, boolean sendLeaseSet, int sendTags, int tagThreshold, int expiration) throws DataFormatException, I2PSessionException
        Send bytes through a SAM message-based session, with per-message extended options.
        Parameters:
        dest - the base32 destination or .b32.i2p hostname to send to
        data - the bytes to send
        proto - the I2CP protocol to send under
        fromPort - the I2CP from port, 0 for the default
        toPort - the I2CP to port, 0 for the default
        sendLeaseSet - true to include the LeaseSet in the message
        sendTags - the number of tunnels to include, 0 to leave as default
        tagThreshold - the build success ratio below which no tunnel is sent, 0 for default
        expiration - the lease lifetime in seconds from now, 0 to leave as default
        Returns:
        True if the data was sent, false otherwise
        Throws:
        DataFormatException - if dest is not a valid destination
        I2PSessionException - on serious error, probably session closed
