Search page
    package net.i2p.sam

    The SAM bridge: a simple text protocol server letting applications in any language use I2P streaming and datagram sessions without implementing the Invisible Internet Client Protocol (I2CP). Started from clients.config as sam.jar.

    See also: SAM specification.
