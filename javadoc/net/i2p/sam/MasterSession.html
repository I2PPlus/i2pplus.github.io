    class MasterSessionextends SAMv3StreamSession implements SAMDatagramReceiver, SAMRawReceiver, SAMMessageSess, I2PSessionMuxedListener
    The primary (mux) session for a SAMv3 client, sharing a single I2P destination across multiple protocol subsessions (STREAM, DATAGRAM, RAW).

    Extends SAMv3StreamSession to inherit the I2PSession setup; the streaming acceptor thread (StreamAcceptor) accepts I2P connections and dispatches them to the correct subsession by protocol and port, via SAMv3StreamSession.queueSocket(I2PSocket).

    The master session itself is not directly usable for data transfer. All streaming, datagram, and raw operations are delegated to registered subsessions. Calling connectAsync(SAMv3Handler, String, Properties), accept(SAMv3Handler, boolean), or startForwardingIncoming(Properties, boolean) on this instance throws unconditionally.

    Under heavy tracker traffic, the accept loop may see thousands of connections per minute. Overflow logging is rate-limited to avoid flooding the router log when subsession queues fill faster than clients can consume.

      • add

        public String add(String nick, String style, Properties props)
        Add a protocol subsession (STREAM, DATAGRAM, or RAW) to this master session. The subsession gets its own protocol/port binding and is registered in the global sessions database so incoming connections can be dispatched to it.

        Sessions are mutually exclusive on (protocol, port) — two subsessions may not listen on the same protocol and port.

        Parameters:
        nick - unique nickname for this subsession
        style - protocol style: "STREAM", "DATAGRAM", or "RAW"
        props - session properties (PORT required for DATAGRAM/RAW; LISTEN_PORT, LISTEN_PROTOCOL optional)
        Returns:
        null on success, or a descriptive error message
