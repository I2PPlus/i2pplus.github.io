net.i2p.sam

Class SAMHandlerPool

  • java.lang.Object
    • net.i2p.sam.SAMHandlerPool

  • class SAMHandlerPool
extends Object
    Shared NIO selector-based handler pool for SAM v3 control connections. Replaces the thread-per-connection model for SAM v3 handlers with a single selector thread reading all handler sockets and dispatching complete command lines inline. Commands are processed serially per-connection in the order they arrive. PING/PONG keepalive and idle timeout are handled at the pool level so individual handlers do not consume threads while waiting for input.

      • getConnectors

        ThreadPoolExecutor getConnectors()
        Thread pool for blocking STREAM CONNECT operations. Fixed pool of 4 daemon threads with an unbounded work queue. Limits concurrent connects to prevent overwhelming the streaming layer while keeping pool workers unblocked. Excess CONNECTs queue up and are dispatched as connector threads become available.
