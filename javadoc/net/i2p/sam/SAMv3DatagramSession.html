        Build a DatagramSession according to informations registered with the given nickname

        Caller MUST call start().

        Parameters:
        nick - nickname of the session
        dgServer - the datagram server that dispatches datagrams to this session
        Throws:
        IOException - declared on this constructor, but not raised by the body
        DataFormatException - likewise declared, but not raised by the body
        I2PSessionException - if the session registered under nick cannot be rebuilt from the record's destination
        SAMException - if the nickname is no longer registered

      • SAMv3DatagramSession

        public SAMv3DatagramSession(String nick, Properties props, SAMv3Handler handler, I2PSession isess, int listenProtocol, int listenPort, SAMv3DatagramServer dgServer) throws IOException, DataFormatException, I2PSessionException
        Build a Datagram Session on an existing i2p session registered with the given nickname

        Caller MUST call start().

        Parameters:
        nick - nickname of the session
        props - session properties read from the SESSION CREATE command
        handler - handler used to send DATAGRAM replies back to the client
        isess - the existing I2P session this datagram session runs over
        listenProtocol - datagram protocol number to listen for, 0 for any
        listenPort - local port to listen on, 0 for any
        dgServer - the datagram server that dispatches datagrams to this session
        Throws:
        IOException - declared on this constructor, but not raised by the body
        DataFormatException - likewise declared, but not raised by the body
        I2PSessionException - declared on this constructor, but not raised by the body
