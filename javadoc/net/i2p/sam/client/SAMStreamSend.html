    net.i2p.sam.client.SAMStreamSend
    public class SAMStreamSendextends Object
    Swiss army knife tester. Sends a file (datafile) to a peer (b64 dest in peerDestFile).

    Usage: SAMStreamSend [options] peerDestFile dataFile

    See apps/sam/doc/README-test.txt for info on test setup. Sends data in one of 5 modes. Optionally uses SSL. Configurable SAM client version.

        Negotiates a SAM session and connects it to the destination stream.
        Parameters:
        version - the SAM protocol version to negotiate, at least 3.2 for user and password
        isSSL - true to connect to the bridge over TLS rather than plaintext
        mode - the stream connect mode, one of STREAM, PACKET or STREAM_RAW, optionally or'ed with MASTER to use a master session
        user - the bridge username, or null when the bridge requires no authentication
        password - the password matching user, or null for no authentication
        sessionOpts - space separated session options appended to the STREAM CONNECT command

        private String handshake(OutputStream samOut, String version, boolean isMaster, SAMEventHandler eventHandler, int mode, String user, String password, String opts)
        Send the HELLO and log in.
        Parameters:
        samOut - the stream to write the HELLO and session commands to
        version - the maximum SAM version to request, e.g. "3.5"
        isMaster - is this the control socket
        eventHandler - the handler that waits for the HELLO reply and later events
        mode - the session mode, one of the STREAM, DG, V1DG or V1RAW constants, with the MASTER bit added for a master session
        user - the SAM user name to log in with, null if no authentication
        password - the SAM password to log in with, null if no authentication
        opts - extra SESSION CREATE options to append, may be empty
        Returns:
        our b64 dest or null
