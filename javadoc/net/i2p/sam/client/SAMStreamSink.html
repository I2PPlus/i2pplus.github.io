    net.i2p.sam.client.SAMStreamSink
    public class SAMStreamSinkextends Object
    Swiss army knife tester. Saves our transient b64 destination to myKeyFile where SAMStreamSend can get it. Saves received data to a file (in sinkDir).

    Usage: SAMStreamSink [options] myKeyFile sinkDir

    See apps/sam/doc/README-test.txt for info on test setup. Receives data in one of 7 modes. Optionally uses SSL. Configurable SAM client version.
