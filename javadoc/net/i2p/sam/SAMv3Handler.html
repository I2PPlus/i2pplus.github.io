        protected boolean execStreamConnect(Properties props)
        Parse and execute a STREAM CONNECT message. Dispatches the blocking I2P socket connect to a shared connector pool so the caller's worker thread is never blocked. Error responses (CONNECTION_REFUSED, CANT_REACH_PEER, TIMEOUT, etc.) are sent asynchronously by the ConnectTask. Supports SILENT mode to suppress status messages.
