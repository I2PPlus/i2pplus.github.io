    public class IBSkipSpan<K extends Comparable<? super K>, V>extends BSkipSpan<K,V>
    Memory-efficient SkipList span implementation (I2P version).

    Stores only first key in memory to reduce memory usage. Loads keys and values from disk on-demand during operations.

    Comparison with BSkipSpan:

    • BSkipSpan stores all keys and values in-memory, backed by file
    • IBSkipSpan stores only first key, and no values, in-memory

    For get(): performs linear search through span in file and loads only found value (super() does binary search in-memory).

    For put() or remove(K, SkipList): loads all keys and values for span from file, makes modification, flushes out keys and values, and nulls out keys and values in-memory.

    Recommended span size is 16.
