    public class BSkipLevels<K extends Comparable<? super K>, V>extends SkipLevels<K,V>
    SkipList level management for multi-level indexing.

    Manages hierarchical structure of SkipList levels to provide efficient search paths through data structure.

    On-disk format:

       Magic number (long)
   max height (unsigned short)
   non-null height (unsigned short)
   span page (unsigned int)
   height number of level pages (unsigned ints)

    Always fits on one page.

      • blvlfix

        private boolean blvlfix()
        Fix the levels. Only call from the first level. Primarily to fix nulls in levels caused by previous SkipLevels bug. This should handle dups and loops and out-of-order levels too, but those may cause problems before this in the constructor. This is fast enough to call every time the skiplist is opened.
        Returns:
        true if the levels were modified.
