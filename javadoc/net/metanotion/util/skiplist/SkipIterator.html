    public class SkipIterator<K extends Comparable<? super K>,V>
extends Object
implements ListIterator<V>
    A basic iterator for a skip list. This is not a complete ListIterator, in particular, since the skip list is a map and is therefore indexed by Comparable objects instead of int's, nextIndex and previousIndex methods are not really relevant. To be clear, this is an iterator through values. To get the key, call nextKey() BEFORE calling next().
