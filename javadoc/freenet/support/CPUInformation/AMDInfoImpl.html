      • identifyCPUByModel

        String identifyCPUByModel(int family, int model, int extFamily, int extModel)
        Sets the instruction-set compatibility flags from the raw CPUID family and model numbers, and returns the microarchitecture guessed from them. The flags are static, so they are cleared first: this runs more than once per JVM (the jbigi probe and the router's processor-change check), and a second call must not inherit the first result.

        Package visible and parameterised so the family and model table can be tested without a CPU to probe. A few pre-Zen families also consult live CPUID feature bits, so only the Zen ranges are fully reproducible.

        Parameters:
        family - the CPUID base family
        model - the CPUID base model
        extFamily - the CPUID extended family, added to a base family of 15
        extModel - the CPUID extended model, folded into the model in that case
        Returns:
        the microarchitecture name, or null if the family is unknown
