freenet.support.CPUInformation

Class CPUID.CPUIDResult

  • java.lang.Object
    • freenet.support.CPUInformation.CPUID.CPUIDResult
  • Enclosing class:
    CPUID

    protected static class CPUID.CPUIDResult
extends Object
    Holds the four 32-bit register values (EAX, EBX, ECX, EDX) returned by a single CPUID instruction call.

    For CPUID leaf 1, the EAX register contains:

    • Bits 3:0 - Stepping ID
    • Bits 7:4 - Base Model
    • Bits 11:8 - Base Family
    • Bits 15:12 - Processor Type (Intel only)
    • Bits 19:16 - Extended Model
    • Bits 27:20 - Extended Family
