    class Tcpbw100.TestWorkerextends Object implements Runnable
    Class to start tests in a thread. Starts by disabling all buttons, and invokes the Tcpbw100.dottcp(StatusPanel) method. This thread is stopped when the number of tests that was configured to be run have all completed, or if the user stops it by interrupting from the GUI. Once the tests have been run, the buttons are enabled so that results can be viewed in detail.
