miniGraph

Renders a mini bandwidth graph in the console sidebar. Loaded as a classic script from the sidebar markup so the first frame draws at parse time, independent of page load. When routerconsole.graphNewRenderer is enabled, uses the dual-baseline client-side canvas renderer; otherwise falls back to the SharedWorker- based RRD4J SVG image renderer.
