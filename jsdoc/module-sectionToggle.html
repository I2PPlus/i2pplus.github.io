sectionToggle

Provides sidebar section toggle functionality for the I2P+ web console. Manages expand/collapse state persistence and the click listeners for the sidebar toggles. State application and storage are delegated to the sidebarState.js classic script (window.applySidebarState / window.setSidebarSectionState / window.readSidebarState / window.saveSidebarState), which runs as soon as the sidebar markup is parsed so collapsed sections never flash expanded, with a cookie fallback when localStorage is unavailable.
