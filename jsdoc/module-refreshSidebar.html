refreshSidebar

Manages the sidebar auto-refresh system for the I2P+ console. Uses a SharedWorker for background fetches, applies differential DOM updates, monitors connection status, and coordinates sidebar components (section toggles, sticky positioning, new hosts, and mini graph). Consumes the sidebar response prefetched at parse time by refreshKick.js so the refresh cadence is independent of page load.

(inner) handleStatus() → {void}

  • Handles online/offline/visibility events by triggering a forced sidebar refresh. Reports the page's visibility to the SharedWorker so the fetch worker can suspend the client while the tab is hidden. While the tab is hidden, all refresh activity is paused (refresh interval and status interval) so the browser never accumulates throttled timer events to replay on regain. On regain, the in-flight guard is released and any stale response discarded before refreshing with fresh data.

(inner) refreshSidebar(forceopt) → {void}

  • Triggers a sidebar refresh by posting a fetch request to the SharedWorker. Sets the in-flight guard for the duration of the request; the guard is released when the response is applied (or when the request fails), and a watchdog in updateConnectionStatus clears it if no response arrives within REQUEST_TIMEOUT.
