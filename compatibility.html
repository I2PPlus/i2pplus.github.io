I2P+ Compatibility

Note: I2P+ has not yet transitioned to Jetty 12. To sidegrade from I2P to I2P+, you must stop I2P, rename your .i2p configuration folder, then start I2P+ so a new config folder is created. You will then need to reconfigure your router. The transition to Jetty 12 is expected soon.

Understanding how I2P+ works with the existing I2P network ecosystem.

Network Compatibility

I2P+ maintains 100% compatibility with the standard I2P network. The changes relate to user interaction and enhanced presentation of the console and webapps, in addition to network performance improvements, leaving the underlying crypto untouched.

On the network, an I2P+ router will identify as a normal I2P router. This means:

  • Full Interoperability: I2P+ routers can connect to and communicate with standard I2P routers seamlessly
  • Standard Protocols: All I2P protocols and services work exactly as expected
  • Network Participation: I2P+ routers participate fully in the I2P network routing and tunneling
  • Crypto Compatibility: No changes to cryptographic implementations ensure complete compatibility

Update Process Compatibility

I2P+ does not interfere in any way with the normal I2P update process. When a new official release is made available, you can easily restore your installation to vanilla I2P by installing the update.

If you'd like to try out I2P+ with the option to change back to your existing I2P installation, the easiest way is to make a copy of your I2P application folder, and then copy the update to the working I2P application folder and restart the router.

In the event that you wish to restore normal I2P, shutdown I2P+ and then restore the backup after renaming/deleting the working I2P app folder. This will ensure that your official I2P installation will be exactly as you left it!

Configuration Compatibility

I2P+ maintains compatibility with standard I2P configuration files and settings:

  • router.config: All standard configuration options are supported and respected
  • Address Book: Standard I2P address book format and subscriptions work perfectly
  • Torrents: I2PSnark configuration and torrents are fully compatible
  • Certificates: Existing SSL certificates and keys are preserved
  • Plugins: Standard I2P plugins work without modification

Performance Enhancements

While maintaining full compatibility, I2P+ includes several performance improvements:

Network Performance

  • Improved Routing: Enhanced router algorithms for better network performance
  • Firewall Optimization: Significantly increased participating traffic for firewalled routers
  • Better Responsiveness: Improved network responsiveness and reduced latency

I2PSnark Enhancements

  • Faster Downloads: Performance improvements in certain contexts for the resident BitTorrent client
  • Better Resource Management: More efficient use of system resources
  • Enhanced UI: Improved user interface for torrent management

User Interface Compatibility

The enhanced user interface in I2P+ builds upon the standard I2P console:

Enhanced Features

  • Updated Themes: Multiple theme options including Dark, Light, OceanBlue, and Charcoal
  • Collapsible Sections: Better organization with collapsible sidebar sections
  • Improved Diagnostics: Easier to understand configuration and diagnostic information
  • Visual Enhancements: Better visual indication of peer status and network health

Backward Compatibility

  • Standard Layout: Maintains familiar I2P console structure
  • Existing Features: All standard I2P console features are preserved
  • Plugin Support: Standard I2P webapps and plugins integrate seamlessly

Migration Guide

From Standard I2P to I2P+

  1. Backup your existing I2P installation
  2. Download and install I2P+ using the installation guide
  3. Copy configuration files from backup if needed
  4. Start I2P+ and verify functionality

From I2P+ to Standard I2P

  1. Shutdown I2P+ router
  2. Download official I2P update package
  3. Install update to restore standard I2P
  4. Verify all services are working correctly
