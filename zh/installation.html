I2P+ 安装指南

本综合指南将帮助您在系统上安装和配置 I2P+。

开始之前

重要：如果您通过 Easy Installer bundle 安装了 I2P，则需要先卸载它并在安装 I2P+ 之前删除或重命名 %appdata%\i2p 文件夹。您可能还需要手动下载并安装 Java JDK 或 JRE — 推荐使用微软最新版本。

安装方法

方法 1：通用安装程序

下载与 Windows、Linux、BSD 和 macOS 兼容的通用 I2P+ Java I2P 安装程序。

安装步骤：

  1. 从下载部分下载安装程序
  2. 从命令提示符运行 Java GUI 安装程序：java -jar ./i2pinstall.exe
  3. 无头安装（无 GUI）：java -jar ./i2pinstall.exe -console
  4. 安装到操作系统的默认目录位置
  5. 使用适合您系统的方法启动 I2P+

如果在尝试安装时看到 Exception in thread "main" java.awt.AWTError: Assistive Technology not found: org.GNOME.，请尝试运行：sudo sed -i -e '/^assistive_technologies=/s/^/#/' /etc/java-*-openjdk/accessibility.properties

方法 2：更新现有安装

如果您运行的是从 Java 安装程序手动安装的 I2P 版本（不是仓库或 .deb 安装版本），更新很简单：

  1. 下载 i2pupdate.zip 文件
  2. 将 zip 文件复制到 I2P 应用程序文件夹
  3. 重新启动路由器

注意：不要解压缩 zip 文件，只需将其复制到 I2P 应用程序文件夹并重新启动 I2P... I2P 将自动解压缩 zip 并更新。

默认安装位置

（非仓库安装的）I2P 应用程序文件夹的默认位置因操作系统而异：

  • Windows：Program Files\i2p\ 或 Program Files (x86)\i2p\
  • Apple：/Applications/i2p/
  • Linux：~/i2p/

Linux 仓库安装

如果您从软件仓库安装了 I2P，则需要禁用 I2P 服务并下载 I2P+ Linux Java 安装程序：

  1. 下载通用 I2P+ Java I2P 安装程序
  2. 运行 Java GUI 安装程序：java -jar ./i2pinstall.exe
  3. 安装到默认目录：$HOME/i2p
  4. 检查是否存在 $HOME/.i2p 目录并更改所有权：sudo chown -R yourusername:yourusername ~/.i2p/
  5. 停止并禁用仓库 I2P 服务：sudo service i2p stop && sudo systemctl disable i2p
  6. 启动手动安装的版本：~/i2p/i2prouter start
  7. 验证 I2P+ 是否在 http://127.0.0.1:7657 上运行

启动选项：

  • 将 /bin/su yourusername -c "/home/yourusername/i2p/i2prouter start" 添加到 /etc/rc.local
  • 将 ~/i2p/i2prouter start 添加到会话启动配置
  • 运行 ~/i2p/i2prouter install（取消注释 ~/i2p/i2prouter 中的 #RUN_AS_USER= 并添加您的用户名）

HTTPS 配置

从 0.9.46+ 开始，完整安装将默认启用 https:// 访问控制台；在访问路由器控制台之前，您需要允许（自签名）证书。

要禁用从 :7657 上的 http:// 自动重定向到 :7667 上的 https://，请在 router.config 文件中添加以下行：

routerconsole.redirectToHTTPS=false

设置文件夹位置

I2P 设置文件夹的位置（用于非仓库安装的 I2P）：

  • Windows：%APPDATA%\I2P\
  • Apple OS X：/Users/username/Library/Application Support/i2p
  • Linux/*BSD：~/.i2p/

故障排除

Windows 服务问题

注意：在 Windows 上，将安装用于控制 I2P 的 Windows 服务，这需要管理员权限。服务控制快捷方式可能需要以管理员身份运行才能正常工作。

无头安装

通过 -console 参数无头安装 I2P+ 时，安装程序将默认安装到当前工作目录。请先创建所需的安装目录（通常是 ~/i2p/）并将 install.jar 文件移动到该目录，然后再开始，或者在提示时手动指定安装路径。
