I2P+ 兼容性

注意：I2P+ 尚未过渡到 Jetty 12。要从 I2P 侧载到 I2P+，您必须先停止 I2P，重命名 .i2p 配置文件夹，然后启动 I2P+ 以创建新的配置文件夹。之后您需要重新配置路由器。预计即将过渡到 Jetty 12。

了解 I2P+ 如何与现有 I2P 网络生态系统协作。

网络兼容性

I2P+ 与标准 I2P 网络保持 100% 兼容。相关变更涉及用户交互以及控制台和 Web 应用的增强呈现，此外还有网络性能改进，底层加密保持不变。

在网络上，I2P+ 路由器将被识别为普通 I2P 路由器。这意味着：

  • 完全互操作性：I2P+ 路由器可以与标准 I2P 路由器无缝连接和通信
  • 标准协议：所有 I2P 协议和服务按预期工作
  • 网络参与：I2P+ 路由器完全参与 I2P 网络路由和隧道
  • 加密兼容性：加密实现没有更改，确保完全兼容

更新过程兼容性

I2P+ 不会以任何方式干扰正常的 I2P 更新过程。当新的正式版本发布时，您可以通过安装更新轻松将安装恢复为原版 I2P。

如果您想试用 I2P+ 并保留切换回现有 I2P 安装的选项，最简单的方法是复制 I2P 应用程序文件夹，然后将更新复制到正在运行的 I2P 应用程序文件夹并重新启动路由器。

如果您希望恢复正常的 I2P，请关闭 I2P+，然后在重命名/删除正在运行的 I2P 应用程序文件夹后恢复备份。这将确保您的正式 I2P 安装与离开时完全一致！

配置兼容性

I2P+ 与标准 I2P 配置文件和设置保持兼容：

  • router.config：支持并尊重所有标准配置选项
  • 地址簿：标准 I2P 地址簿格式和订阅完美运行
  • 种子：I2PSnark 配置和种子完全兼容
  • 证书：保留现有的 SSL 证书和密钥
  • 插件：标准 I2P 插件无需修改即可运行

性能增强

在保持完全兼容性的同时，I2P+ 包含多项性能改进：

网络性能

  • 改进的路由：增强的路由器算法以获得更好的网络性能
  • 防火墙优化：显著增加防火墙路由器的参与流量
  • 更好的响应性：改善网络响应性并减少延迟

I2PSnark 增强

  • 更快的下载：在某些情况下为内置 BitTorrent 客户端提供性能改进
  • 更好的资源管理：更高效地使用系统资源
  • 增强的 UI：改进的种子管理用户界面

用户界面兼容性

I2P+ 中增强的用户界面建立在标准 I2P 控制台之上：

增强功能

  • 更新的主题：多种主题选项，包括 Dark、Light、OceanBlue 和 Charcoal
  • 可折叠部分：通过可折叠的侧边栏部分实现更好的组织
  • 改进的诊断：更易于理解的配置和诊断信息
  • 视觉增强：更好地视觉指示节点状态和网络健康状况

向后兼容性

  • 标准布局：保持熟悉的 I2P 控制台结构
  • 现有功能：保留所有标准 I2P 控制台功能
  • 插件支持：标准 I2P Web 应用和插件无缝集成

迁移指南

从标准 I2P 迁移到 I2P+

  1. 备份现有的 I2P 安装
  2. 使用安装指南下载并安装 I2P+
  3. 根据需要从备份复制配置文件
  4. 启动 I2P+ 并验证功能

从 I2P+ 恢复到标准 I2P

  1. 关闭 I2P+ 路由器
  2. 下载正式 I2P 更新包
  3. 安装更新以恢复标准 I2P
  4. 验证所有服务是否正常运行
