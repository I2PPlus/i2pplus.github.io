I2P+ 常见问题与支持

I2P+ 的常见问题、故障排除指南和支持资源。

常见问题

什么是 I2P+？

I2P+ 是 Java I2P 匿名网络平台的增强版本，提供卓越的用户体验和改进的网络性能，同时保持与上游 I2P 的完全兼容性。

I2P+ 与标准 I2P 兼容吗？

是的，I2P+ 与标准 I2P 100% 兼容。它保留所有加密协议和网络标准，允许与普通 I2P 路由器无缝通信。

如何更新 I2P+？

下载最新的 i2pupdate.zip 文件并将其复制到 I2P 应用程序文件夹，然后重新启动路由器。I2P 将自动提取并安装更新。

我可以切换回标准 I2P 吗？

是的，您可以通过安装正式的 I2P 更新轻松恢复标准 I2P。建议在切换之前备份 I2P+ 安装。

系统要求是什么？

I2P+ 需要 Java 8 或更高版本。推荐的最低系统规格：

  • 内存：最低 512MB，推荐 1GB
  • CPU：1GHz 处理器或更高
  • 存储：100MB 可用空间用于安装
  • 网络：宽带互联网连接

更新管理

启用控制台内更新

要获取 I2P+ 的发布更新，推荐的方法是将 I2P 专用种子 URL 添加到 I2PSnark，下载后手动将 i2pupdate.zip 文件复制到应用程序文件夹。

开发更新

建议在路由器更新页面上启用 使用未签名开发构建更新 选项，并可选地将默认发布版本 URL http://skank.i2p/i2pupdate.zip 替换为开发分支 URL http://skank.i2p/dev/i2pupdate.zip 以获取滚动发布版本。

注意：为避免更新到原版 I2P 版本，请在更新页面上将 更新策略 设置为 仅通知。当 I2P+ 更新可用时，您将在控制台侧边栏中收到通知。

故障排除

浏览器缓存问题

安装 I2P+ 更新后，您可能需要刷新浏览器缓存以确保加载更新的 CSS 文件和资源。在 Firefox 和 Chrome 中，使用 CTRL+SHIFT+R 强制重新加载当前页面的资源。

安装问题

Linux 上的 AWT 错误：如果看到 Exception in thread "main" java.awt.AWTError: Assistive Technology not found: org.GNOME.，请运行：

sudo sed -i -e '/^assistive_technologies=/s/^/#/' /etc/java-*-openjdk/accessibility.properties

权限问题：确保您对安装目录具有适当的权限，并且 Java 已正确安装且可访问。

网络连接

防火墙问题：确保端口 7657（控制台）、7667（HTTPS 控制台）和您的 I2P 端口在防火墙中正确配置。

性能缓慢：检查路由器配置中的带宽设置，确保没有超出可用带宽。

地址簿配置

订阅设置

为避免手动解析 I2P+ 中链接的新 I2P 域名，请将 http://skank.i2p/hosts.txt 添加到 I2P 地址簿的订阅列表中。

导入主机

您可以通过导入功能将 hosts.txt 文件导入到 SusiDNS 中。

分享 I2P+

要向地址簿中没有 skank.i2p 域名的用户推广 I2P+，请分享此助手链接。

开发支持

源代码访问

I2P+ 在 GitHub 上提供。如果您有希望包含的修改，请 fork 代码并创建合并请求。

从源代码构建

对于想要从源代码构建 I2P+ 的开发者：

  1. 从 GitHub 克隆存储库
  2. 安装所需的构建依赖项（Java JDK、Ant）
  3. 按照存储库中的构建说明操作
  4. 在使用前彻底测试您的构建
