Руководство по установке I2P+

Это руководство поможет вам установить и настроить I2P+ в вашей системе.

Перед началом

Важно: Если вы установили I2P через Easy Installer bundle, вам нужно удалить его и удалить или переименовать папку %appdata%\i2p перед установкой I2P+. Вам также может потребоваться вручную загрузить и установить Java JDK или JRE — рекомендуется последняя сборка Microsoft.

Методы установки

Метод 1: Универсальный установщик

Загрузите универсальный установщик I2P+ Java I2P, совместимый с Windows, Linux, BSD и macOS.

Шаги установки:

  1. Загрузите установщик из раздела загрузок
  2. Запустите установщик Java GUI, набрав в командной строке: java -jar ./i2pinstall.exe
  3. Для установки без интерфейса (без GUI): java -jar ./i2pinstall.exe -console
  4. Установите в каталог по умолчанию для вашей операционной системы
  5. Запустите I2P+ соответствующим способом для вашей системы

Если при попытке установки вы видите Exception in thread "main" java.awt.AWTError: Assistive Technology not found: org.GNOME., попробуйте выполнить: sudo sed -i -e '/^assistive_technologies=/s/^/#/' /etc/java-*-openjdk/accessibility.properties

Метод 2: Обновление существующей установки

Если вы запускаете вручную установленную версию I2P от установщика Java (не из репозитория или .deb), обновление просто:

  1. Загрузите файл i2pupdate.zip
  2. Скопируйте zip-файл в папку приложения I2P
  3. Перезапустите маршрутизатор

Примечание: Не распаковывайте zip-файл, просто скопируйте его в папку приложения I2P и перезапустите I2P... I2P автоматически распакует zip и обновится.

Места установки по умолчанию

Место по умолчанию папки приложения I2P (для установки не из репозитория) зависит от операционной системы:

  • Windows: Program Files\i2p\ или Program Files (x86)\i2p\
  • Apple: /Applications/i2p/
  • Linux: ~/i2p/

Установка из Linux репозитория

Если вы установили I2P из программного репозитория, вам нужно отключить службу I2P и загрузить установщик I2P+ для Linux Java:

  1. Загрузите универсальный установщик I2P+ Java I2P
  2. Запустите установщик Java GUI: java -jar ./i2pinstall.exe
  3. Установите в каталог по умолчанию: $HOME/i2p
  4. Проверьте наличие каталога $HOME/.i2p и измените владельца: sudo chown -R yourusername:yourusername ~/.i2p/
  5. Остановите и отключите службу I2P из репозитория: sudo service i2p stop && sudo systemctl disable i2p
  6. Запустите вручную установленную версию: ~/i2p/i2prouter start
  7. Проверьте, что I2P+ запущен на http://127.0.0.1:7657

Параметры запуска:

  • Добавьте /bin/su yourusername -c "/home/yourusername/i2p/i2prouter start" в /etc/rc.local
  • Добавьте ~/i2p/i2prouter start в конфигурацию запуска сессии
  • Запустите ~/i2p/i2prouter install (раскомментируйте #RUN_AS_USER= в ~/i2p/i2prouter и добавьте ваше имя пользователя)

Конфигурация HTTPS

Начиная с версии 0.9.46+, полная установка по умолчанию включает доступ https:// к консоли; вам нужно разрешить (самоподписанный) сертификат перед доступом к консоли маршрутизатора.

Чтобы отключить автоматическое перенаправление с http:// на порту :7657 на https:// на порту :7667, добавьте эту строку в файл router.config:

routerconsole.redirectToHTTPS=false

Места расположения папки настроек

Расположение папки настроек I2P (для установки не из репозитория):

  • Windows: %APPDATA%\I2P\
  • Apple OS X: /Users/username/Library/Application Support/i2p
  • Linux/*BSD: ~/.i2p/

Устранение неполадок

Проблемы со службой Windows

Примечание: В Windows будет установлена служба для управления I2P, для которой потребуются права администратора. Ярлыки управления службой может потребоваться запуск от администратора.

Установка без интерфейса

При установке I2P+ без интерфейса через аргумент -console установщик по умолчанию устанавливает в текущий рабочий каталог. Сначала создайте нужный каталог установки (обычно ~/i2p/) и переместите файл install.jar в этот каталог перед запуском, или вручную укажите путь установки при запросе.
