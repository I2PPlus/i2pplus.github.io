I2P+ FAQ и поддержка

Часто задаваемые вопросы, руководства по устранению неполадок и ресурсы поддержки для I2P+.

Часто задаваемые вопросы

Что такое I2P+?

I2P+ — это улучшенная версия анонимной сети Java I2P, обеспечивающая превосходный пользовательский опыт и улучшенную производительность сети при полной совместимости с апстримным I2P.

Совместим ли I2P+ со стандартным I2P?

Да, I2P+ на 100% совместим со стандартным I2P. Он сохраняет все криптографические протоколы и сетевые стандарты, обеспечивая беспрепятственное взаимодействие с обычными маршрутизаторами I2P.

Как обновить I2P+?

Загрузите последний файл i2pupdate.zip и скопируйте его в папку приложения I2P, затем перезапустите маршрутизатор. I2P автоматически распакует и установит обновление.

Можно ли вернуться к стандартному I2P?

Да, вы можете легко восстановить стандартный I2P, установив официальное обновление I2P. Рекомендуется создать резервную копию установки I2P+ перед переключением.

Каковы системные требования?

I2P+ требует Java 8 или более поздней версии. Рекомендуемые минимальные характеристики системы:

  • ОЗУ: минимум 512 МБ, рекомендуется 1 ГБ
  • Процессор: 1 ГГц или выше
  • Хранилище: 100 МБ свободного места для установки
  • Сеть: широкополосное подключение к интернету

Управление обновлениями

Включение обновлений в консоли

Для получения релизных обновлений I2P+ рекомендуемый способ — добавить URL I2P-специфичного торрента в I2PSnark, а после скачивания вручную скопировать файл i2pupdate.zip в папку приложения.

Обновления разработки

Рекомендуется включить опцию Обновление неподписанными сборками разработки на странице обновлений маршрутизатора и при необходимости заменить URL релизной версии по умолчанию http://skank.i2p/i2pupdate.zip на URL ветки разработки http://skank.i2p/dev/i2pupdate.zip для сборок с滾ающимися обновлениями.

Примечание: Чтобы избежать обновления до релизов стандартного I2P, установите Политику обновлений на Только уведомлять на странице обновлений. Вы будете уведомлены в боковой панели консоли, когда станет доступно обновление I2P+.

Устранение неполадок

Проблемы кэша браузера

После установки обновлений I2P+ может потребоваться обновить кэш браузера для загрузки обновлённых CSS-файлов и ресурсов. В Firefox и Chrome используйте CTRL+SHIFT+R для принудительной перезагрузки ресурсов текущей страницы.

Проблемы установки

Ошибка AWT в Linux: Если вы видите Exception in thread "main" java.awt.AWTError: Assistive Technology not found: org.GNOME., выполните:

sudo sed -i -e '/^assistive_technologies=/s/^/#/' /etc/java-*-openjdk/accessibility.properties

Проблемы с правами доступа: Убедитесь, что у вас есть соответствующие права на каталог установки и что Java правильно установлена и доступна.

Сетевое подключение

Проблемы файрвола: Убедитесь, что порты 7657 (консоль), 7667 (HTTPS-консоль) и ваш порт I2P правильно настроены в файрволе.

Низкая производительность: Проверьте настройки полосы пропускания в конфигурации маршрутизатора и убедитесь, что вы не превышаете доступную полосу пропускания.

Конфигурация адресной книги

Настройка подписки

Чтобы избежать ручного разрешения новых доменов I2P, связанных с I2P+, добавьте http://skank.i2p/hosts.txt в список подписок вашей адресной книги I2P.

Импорт хостов

Вы можете импортировать файл hosts.txt в SusiDNS через функцию импорта.

Распрранение I2P+

Для продвижения I2P+ среди пользователей, у которых нет домена skank.i2p в адресной книге, поделитесь этой вспомогательной ссылкой.

Поддержка разработчиков

Доступ к исходному коду

I2P+ доступен на GitHub. Если у вас есть модификации, которые вы хотели бы видеть включёнными, сделайте форк кода и создайте запрос на слияние.

Сборка из исходного кода

Для разработчиков, желающих собрать I2P+ из исходного кода:

  1. Клонируйте репозиторий с GitHub
  2. Установите необходимые зависимости для сборки (Java JDK, Ant)
  3. Следуйте инструкциям по сборке в репозитории
  4. Тщательно протестируйте свою сборку перед использованием
